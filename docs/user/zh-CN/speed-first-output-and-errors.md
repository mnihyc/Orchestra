# 速度、首次输出和错误

打开用量 → 性能比较模型，或打开请求跟踪单次调用。三个视图保留范围、日期和筛选。
提供方页也显示最近七天数据，每个请求可打开产生它的轮次。

账号菜单中的用量可选择自己、组织、部门或项目及日期范围。上周指前一个星期一至星期日。
报表日期按 UTC，在日期范围中标明；请求时间按你的时区。能读线程报告时可使用按线程页。
轮次按不同轮次计数，包括没有令牌报告的轮次；同轮多个请求不重复增加轮次。

## 数字的含义

首次输出从请求模型算到第一个输出到达，包括可见文字前的思考。速度是生成期间流式
输出的每秒令牌数；程序报告的流式思考会计入，可单独识别的隐藏推理会减去。
工具执行和等待人不算生成时间。流未报告独立的隐藏思考计数时，速度保持未知。
请求时间到模型最终输出为止，不含随后工具执行。

数字显示中位数，一半测量请求的值不超过它。模型表还显示第 90 百分位，帮助比较较慢的请求。
百分位来自固定对数桶，以桶的几何中点估计，分辨率约 4.5%；真正的零仍是零。

随时间变化的速度、首次输出和错误率以折线显示，每个分组一条线；没有测量的区间留空。
每张图有自己的间隔选择。此设备记住视图选择和预设日期范围，地址中的选择优先；
筛选条件和自定义日期只保留在地址中。

错误率为提供方失败数除以结果已知的请求数，旁边显示失败数量。程序、会话或工具环境
失败仍在请求页，不归咎于提供方。人的取消显示已取消，不计错误。错误行显示代码和
提供方说明，可筛选全部失败或单个代码。

## 为什么未测量

短横线表示没有测得值，数字旁问号解释原因。

- 速度至少需要半秒生成和 32 个流式输出令牌。短回复仍可有边界已报告的请求时间和首次输出。
- 隐藏思考且不报告独立令牌数的程序，可有首次输出和请求时间，不能测流式速度。
- 有些子代理报告令牌，但不报告请求时间。
- 未证明请求边界的程序或版本可报告数量而不报告时间，旧记录也可能没有测量。

缺失观测不会变为零，也不进入百分位。选项最近七天至少有 20 个符合条件的测量请求，
才会显示性能提示。

## 找到一轮的时间

打开轮次页脚详情。模型时间是已计时主流请求之和，工具时间是总耗时减去它，包含
子代理和未测时段，并在存在时说明。没有已计时主流请求时，两者都未测量。首次输出
来自第一个请求，速度是符合条件请求的中位数。本轮请求打开筛选日志。

生成期间，如果程序尚未报告输出令牌，实时状态也可以显示估算的输出数量和速度。
估算使用当前模型的数据并标记 **≈**；没有数据时不显示估算。重新打开的大消息也可能
缺少实时计数，此时等待程序报告用量后再显示。已报告的令牌数优先。

## 跟踪请求

请求按最新在前到达。暂停保持行位置，新请求在计数下等待；恢复或点击新行数量显示它们。
更早请求用于分页，导出把当前筛选存为 CSV。进行中的请求会标记直到结果到达。

统计权限与用量相同。位置汇总可包括他人总量，明细只显示你有权读取的记录。
实时投递会再次检查权限。

线程提供方在十五分钟至少十个请求且至少 20% 错误时，状态栏显示异常；或近期首次输出
中位数超过自身七天中位数三倍，且两段都有至少十个测量样本时显示。点击打开该提供方
失败请求，恢复正常后消失。

## 内置程序

### Codex

数字使用程序及其已检查版本报告的请求边界和令牌数。

### Claude Code

支持的流会报告独立思考数。子代理报告令牌，但不报告请求时间。

### DeepSeek Harness

数字使用程序及其已检查版本提供的观察结果。缺少计数或请求边界时，相关数字保持未测量。
