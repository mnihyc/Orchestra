# 语义搜索

语义搜索还会查找含义相近的文字，初始为关闭。
关闭、暂不可用或仍在建立索引时，文字搜索继续工作。
[查找内容](finding-things.md#words-and-similar-meaning)说明搜索列表的行为。

## 启用语义搜索

管理员打开**管理 → 语义搜索**。表格列出各组织的索引，下面是系统默认设置。
组织可以使用自己的设置和继承的锁。打开**语义搜索**，再指定**嵌入模型**。
指定提供方的人承担使用和费用，需要一直保有该提供方和模型的使用权限；共享用量上限仍适用。

## 选择嵌入

先选择提供方，再选择已启用的模型和维度。
提供方需要一个能从其运行环境连接的 Embeddings 地址，凭据、请求头和秘密请求头仍由普通提供方管理。
**未设置**表示尚未选择生成嵌入的提供方和模型。
**托管**表示设置使用了你不能查看的提供方，不是加载失败；锁仍由普通设置行显示。

查询前缀和文档前缀也是模型选择的一部分。按模型要求填写。
文档前缀中的 `{title}` 会替换为来源标题，没有标题时使用 `none`。修改前缀会重建索引。

## 本地嵌入

**添加本地嵌入**打开普通的**添加提供方**对话框，并选中 Local embeddings 示例。
它填入 Embeddings 协议、运行环境的回环地址、`embeddinggemma-2`、256 维和运行模板。
像添加其他提供方一样选择所属位置、机器和运行环境，然后创建。
创建后会提供嵌入设置编辑器；需要单独保存设置才用于搜索。创建提供方不会改写该设置。

随附模型可以使用以下前缀，每个前缀末尾加一个空格：

- 查询：`task: search result | query:`
- 文档：`title: {title} | text:`

**模板 · Local embeddings**打开提供方实际使用的模板，也可在**资源 → 模板**中找到。
模板编辑器显示 Dockerfile，可以修改，也按普通模板规则移除。
移除后再次添加该示例会创建新的模板，不会恢复已移除的模板；仍有效的模板保留已有修改。
[添加提供方](add-a-provider.md#local-embeddings)说明普通设置流程。

## 索引状态

| 状态 | 含义和操作 |
| --- | --- |
| 未设置 | 选择嵌入，或添加本地嵌入 |
| 正在统计… | 正在发现需要索引的文字，暂时没有整个索引的百分比或时间 |
| 正在索引 | 进度条显示已嵌入的令牌，旁边显示剩余令牌或估计时间 |
| 就绪 | 当前索引已跟上内容 |
| 已暂停 · 提供方已停用 | 启用提供方后继续索引 |
| 已暂停 · 提供方已移除 | 选择其他嵌入提供方 |
| 已暂停 · 已达磁盘上限 | 提高限制、缩短向量或调整索引方案 |
| 需要选择 · 新模型 | 先看新索引估计的磁盘和时间，再选重建或保留当前模型 |
| 缺少 pgvector | 请运维人员使用带 pgvector 的数据库 |

提供方、模型、权限、用量上限或机器的问题会在同一行显示，文字搜索继续可用。
搜索中的不可用原因支持悬停、聚焦和轻点查看。
首个索引从第一批完成的向量开始回答，不会把尚未完成的整个语料说成就绪。

### 提供方暂停

停用嵌入提供方会取消当前批次并暂停索引。进度行显示**提供方已停用**。
这是暂停，不会重试或增加失败次数。启用提供方后会自动继续索引，移除时显示**提供方已移除**。
已经保存的向量会保留。

查询向量仍在缓存中时，搜索可以继续使用语义结果，并显示**索引已暂停**。
新查询需要已停用的提供方生成向量时，只搜索文字；**语义搜索暂不可用**处可查看原因。
提供方恢复后，重新搜索可包括新完成索引的内容。

## 磁盘限制

**磁盘限制**是索引相对于已索引内容存储大小的上限，随附值为 **100 %**，留空表示**无限制**。
每行会标明估计的磁盘用量和上限。下一次分配会超限时，索引先暂停。
很短的文字所需索引可能比原文大，提高限制前先看估计。

## 切换模型

新的索引在后台建立时，当前模型继续回答。
新前缀、不同分块大小、更长的向量或不同模型需要重新嵌入内容。
换地址提供同一模型时，先用保存的探测文字检查。
兼容的 MRL 向量缩短后重新建索引，不需要把全部内容重新嵌入。

磁盘不能同时容纳两代索引时，会先要求选择。
**重建**移除当前索引，开始建立所选索引；期间语义结果覆盖已经完成的片段。
**保留当前模型**恢复生成当前索引的提供方、模型、维度、前缀和分块大小。
普通设置权限和继承的锁仍适用。
旧搜索游标不能中途换到新的嵌入空间，修改后需要重新搜索。

## 索引与排序

**索引与排序**控制分块、批次、候选窗口、扫描预算和查询等待时间。
这些是可以修改的默认值，不会授予权限。
**文字检索**在可访问范围较小时优先从该范围读取。名称和标题、描述、标题块和文件、正文
可以分别设置候选数；未设置时沿用**文字候选数**。
**每次请求的窗口数**默认为一个。**显示更多**从该窗口继续，即使该窗口的候选内容均因当前权限而隐藏。
权限树较大时，也使用有界窗口。返回结果或片段前仍检查当前权限。

语义搜索对较小范围的向量进行精确比较，对较大范围使用图索引。
**图扫描**初始为**按距离排序**；未设置**图搜索宽度**时，使用候选数乘以过采样倍数。
**精确筛选候选数**为**0（关闭）**时，对所有范围使用图索引。
索引器先处理较新的内容。
进度和剩余时间取决于地址实测的处理速度。
语义查询只等待配置的预算，超时仍保留文字结果。
智能体搜索返回一次合并答案；语义无法回答时，返回文字结果及不可用原因。
