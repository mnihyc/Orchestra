# 创建资源或对话的副本

打开对象的 **⋯** 菜单，或右键点击它所在的行。**创建副本**会在原位置创建副本，由服务选取新名称，接受后打开新的对象。**创建副本到…**会打开统一的位置选择器，列出你所属的组织；选择目标位置，也可以指定名称。取消不会发送创建请求。

## 哪些内容会跟随

副本采用目标位置的默认值、锁定规则和新的权限页。原有共享、评论、用量和管理历史保留在原对象上。环境副本将可读取的工作区复制到新建且自有的存储中；文档副本复制可读取的内容和文件。技能的普通操作复制已发布版本。在草稿编辑器中，**创建草稿副本**通过独立操作复制未发布草稿。

线程的“创建副本”使用原生分叉操作，仍保留原有的代理权限审查和任务计划。“创建副本到”可通过同一位置选择器选择话题；计划会检查目标位置和将要使用的资源。内置程序线程仍使用自己的“私有”创建流程。

## 凭据和通知

是否为原对象的所有者、能否携带其秘密值，由原生操作判断。其他读取者创建的副本需要自己的密钥。订阅副本初始未登录，使用独立的登录状态。创建副本不会要求浏览器读取并重新提交原对象的凭据。

对于导入的 MCP 定义，**机器**单独选择物理接收方，与共享所属位置分开。保留**原机器**时，只有原接收方在目标位置可用才会继续。被拒绝时应选择可用机器；改变所属位置不会授予机器权限。

群聊副本采用新的权限页，初始成员只有创建者。“创建副本到”会根据原群聊的原生发言者预览提供**通知N人**。不勾选即可静默复制。预览失败或人数超过上限时，通知不可用，仍可静默复制。通知不会授予任何人对新对话的访问权限。

## 目标位置被拒绝时

读取原对象和在目标位置创建该类对象是独立检查。将文档、群聊或线程复制到其他组织，还需要原对象的导出权限，并由源位置的**允许复制到其他组织**策略放行。该策略遵循系统、组织和项目的设置及锁定规则。

位置选择器会保留不可用的目标并显示实际原因。要求按钮可打开权限详情或源策略的设置帮助。有些位置需要先选择环境的放置方式、机器，或检查原生计划，才能继续创建副本。请求被拒绝后，会保留所选位置并显示原生权限或字段问题。可查看缺少的权限，或改选其他位置。接受后的精简回执指向实际的新对象；正常打开时仍可能提示当前读取者无法读取它。丢失响应后，在不改变选择的情况下重试会复用同一次操作，不会再创建一个副本。

## 在组织内移动所属位置

**移动…**使用同一位置选择器，在根组织内改变资源的所属位置。下级组织仍属于该根组织内的位置。原生操作要求管理原对象和目标位置；对象标识和文件保持不变，继承改由新位置决定。群聊通过自己的更新操作使用同一选择方式。私聊不提供移动。

主机和机器提供这种所属位置移动，不提供创建副本。环境的**移至另一台机器…**仍是独立的物理搬迁计划。改变所属位置不会执行该搬迁。


## 移至其他组织

在**移动…**中选择其他根组织下的所属位置后，按钮会变为**复制到 <组织> 后删除原件**。只有原对象的所有者可以执行；复制到其他组织以及删除的全部规则仍然适用。不是所有者的管理者或管理员不能使用此操作。

移动供应方、代理、技能、挂载、模板、主机或机器前，请检查**删除计划**。各行显示实际影响，包括停止关联工作或保留注册。复制和移除原对象由一次操作完成；取消对话框不会改变任何一方。主机和机器保留原注册及标识，不会新建第二个注册。环境和线程在其移动操作就绪前保持不可用。

移动被拒绝后，所选位置和原因会保留。如果原对象或删除影响已变化，可用**重新检查**获取新的计划，再决定是否确认。丢失响应后的重试会复用原操作，不会再创建一个副本。接受后通过正常的读取路径打开回执指向的对象。


文档和文档专用文件夹也使用同一个**移动…**入口。先选择组织或项目，也可以再选该组织内的文件夹。在组织内移动会保留标识；移至其他组织时，先检查完整的原生删除成员及保留期限，再由一次操作完成复制和移除原对象。受保护的预览只显示**删除计划已就绪**，不会暴露隐藏的成员。接受后，如果回执提供原对象与副本的对应关系，会直接打开新根对象；精简文件夹回执没有这种对应关系时，会打开所选目标目录。


移动 MCP 时使用原生的源定义删除计划。对于导入的定义，**机器**选择目标保管方，与共享所属位置分开。只有原生检查允许时，**原机器**才会保留当前接收方；更改机器会重新取得删除影响，再等待确认。自有定义保持原类型，不提供导入定义的机器选择。

移动群聊时，原生操作会检查当前实际管理者及复制到其他组织的规则。先检查**结束此群聊及其历史**，输入显示的群名，再确认这一次移动。**通知N人**使用原群聊的原生成员预览，不会授予对新群聊的访问权限，新群初始仍只有创建者。不勾选即可静默移动。群聊或所审阅的通知对象发生变化时，**重新检查**会清除群名确认和通知选择，等待你重新决定。


移动供应方会使用原生创建及成功删除原对象的路径，计划会显示停止工作和清除原对象的影响。订阅登录状态由同一次操作移交；普通“创建副本”仍会让订阅副本初始未登录。浏览器不会读取并重新提交这些凭据。
