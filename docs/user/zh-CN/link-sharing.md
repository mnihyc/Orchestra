# 发送链接或引用

“复制链接”生成地址。“复制引用”可以指向特定消息、轮次、文件或选中的行。

## 在哪里

从[导航](/)或[所有内容](/everything)打开文档、聊天、会话或资源。在菜单中复制链接或引用，再将其粘贴到对话中。

## 示例

将文档链接粘贴到群聊中并发送。可以读取文档的成员可以打开它。需要访问权限的人可以请所有者共享文档。

## 操作后会怎样

发送会保留链接以及原有权限。接收者打开链接时，目标会检查其当前权限。如需授权，请在目标上选择**共享**，再选择人员或智能体。另见[引用](references.md)和[群聊](group-chats.md)。
