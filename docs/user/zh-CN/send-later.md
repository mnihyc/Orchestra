# 稍后发送消息

在线程中写好消息，打开发送菜单并选择**稍后发送…**。正在运行的线程也有这个入口。表单保留完整消息、文件、引用和所选原生命令。打开表单不会发送任何内容。

## 选择时间和位置

**一次**的日期和时间初始为空。请选择未来的日期、时间及显示的时区。若时钟使同一分钟出现两次，需明确选择哪一次。**重复**提供每天或每周、明确的本地时间和时区；每周还需至少选择一天。下次时间按该时区显示。重复计划遇到时钟跳过的时间会跳过该次；遇到重复的小时，只在较早的一次运行。

选择**此线程**或**每次创建新线程**。新线程可在执行时使用**话题默认值**，也可通过**配置…**选择已有的线程创建选项。配置只准备选择。保存计划不会立即创建线程或轮次，也不会预留未来额度。

计划以作者身份运行，到期时重新检查该人的权限、可用模型和限额。线程中此前暂停的队列仍保持暂停；新的定时输入遵循普通输入规则。

## 查看和修改计划

在话题的**定时输入**或线程的**定时计划**视图中打开计划。作者可以编辑私有消息、时间和创建选项；其他读取者只能看到元数据和运行记录。作者及目标位置的控制者可暂停或移除未来的执行；作者通过浏览器登录后可继续。继续重复计划只选择下一个未来时间，不补跑暂停期间的日期。已过期的一次计划需要改为新的未来时间。

已进入队列的输入不会因暂停或移除计划而消失；可从运行记录进入对应线程查看队列。失败的执行保留安全的原因及记录。计划不会把旧权限或令牌保留为未来权限。

## 保存失败时

加载中、时间无效、权限被拒绝或保存失败时，消息保持完整。接受后只清除仍与此次接受内容完全相同的草稿；后来输入的文字或加入的文件会保留。编辑版本过期时也会保留你的字段，先明确查看当前版本，再决定保存。含审查评论的草稿需使用当前支持的立即发送方式，直到计划能表示这些评论。

Tab 依次访问时间、时区和目标控件。只有最后的保存按钮会提交；Escape 取消，输入法组合过程中按 Enter 不会保存。
