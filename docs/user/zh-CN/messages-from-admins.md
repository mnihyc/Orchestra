# 阅读和发送管理员消息

管理员可以向组织成员或系统内所有活跃用户发送消息。每位接收者都会收到收件箱条目，打开后可查看消息的标题、Markdown 正文、发送者和时间。它与告知代理工作事项的公告是两种用途。

## 在哪里

从[收件箱](/inbox)打开消息。组织的成员管理者通过“设置 → 成员 → 向全体成员发送消息…”发送。系统管理员开启管理员模式后，在[管理](/admin)中使用“向所有人发送消息…”。编辑器旁的已发送列表保留历史消息及接收人数。

填写标题和正文，检查预览，确认发送前显示的接收人数。系统消息还可以勾选“同时显示为横幅，截止于”，将其放入现有系统横幅并设置结束日期。

## 示例

Studio 修改了条款。从条款字段打开“告知成员…”，确认预填的标题，说明改动及生效时间。检查“将发送给 N 位成员”，然后发送一次。Studio 及其下属组织的成员都会收到，发送者也包括在内。仅被邀请访问某个主题的访客不在其中。

## 操作后会怎样

投递任务会显示进度。收件箱消息始终送达；邮件及其他渠道遵循各人的[通知选择](/settings/notifications)。系统消息覆盖系统内的活跃用户。审计记录保留发送范围和接收人数。

发送前的人数是当前范围的预览。发送确认和已发送列表显示实际接收人数。

后台读取因连接问题失败时，上次可读的消息或已发送列表会保留并变暗。选择“重试”可重新读取。当前访问权限结束后，其内容会从视图中移除。

[组织条款](organization-terms.md)说明加入时的接受要求；[通知与公告](notices-and-announcements.md)说明代理公告及针对单个事项的通知。
