# 查找内容

Orch 有一个输入框，可以前往任何有名称的东西、运行任何命令并回答问题。围绕它的是一个搜索已说内容的页面、一个在单个会话内搜索的功能，以及在问题出现的地方给出回答的帮助。

## 查找器

在任何地方按 **Ctrl+K**（Mac 上是 **Command+K**），或按侧栏里的放大镜，然后输入几个字母。

输入时会列出你可以打开的所有东西的名称：组织、项目、文件夹、话题、会话、文档和聊天，然后是人员，再是你能看到的资源（提供方、智能体、环境、主机、模板、MCP 服务器、挂载和机器）。每个名称下面写着它在哪里：从它的组织往下的路径（“Web › Checkout”），或它的地址。你加星标的东西和最近去过的位置排在最前面。

输入框开头的符号会把答案限制在某一类：

| 符号 | 限制在 |
|---|---|
| `>` | 命令：在这里可以做什么，例如新建话题或切换主题 |
| `@` | 人员，按姓名、用户名或地址 |
| `:` | 设置，按它们的作用；以及权限页的行，按它们允许什么 |
| `?` | 帮助：文章，按标题和小节标题 |
| `/` | 已说的内容：符号之后的词会在会话、聊天和文档里搜索 |

输入框下面的按钮写出同样的符号。方向键沿着各行移动，**Enter** 打开选中的一行。**Ctrl+Enter** 在浏览器的新标签页里打开它。你无权使用的命令会被列出，处于关闭状态并写明原因。你看不到的东西不会被列出。

什么都没输入时，查找器列出你加星标的内容和你最近去过的位置，并提供你在这个屏幕上能做的事及其帮助。最后一行**高级搜索**会用你输入的词打开搜索页面。

## 搜索

按 **Ctrl+/**（Mac 上是 **Command+/**），或在查找器里使用 `/`。搜索会读取你有权阅读的会话、聊天和文档。在搜索页面上一个字符就够了，包括中文。分开的词可以按任何顺序出现。把短语放在双引号里可以让它保持在一起。

**在哪里查找。** 搜索从左栏显示的**在该组织内**开始，包括其中你能阅读的部门和项目。从侧栏找到的名称和内容使用同一个根。

- 打开组织的标签并选择**我的所有组织**，可以包括你的个人组织和你能阅读的其他所有组织。**位置**在这个选择之内进一步收窄，更换组织会清除较窄的位置。
- 地址保留对组织的选择，用于共享和重新加载。新的搜索再次使用当前所见的组织，选择**我的所有组织**不会让它成为你下一次的默认值。
- 来自所有组织的结果带有组织的标签，只有在多于一个组织给出回答时才有组织的标题。
- 在一个组织里空的搜索会提供**搜索我的所有组织**。它的数字是目前已收到的你能阅读的结果，**+** 表示可能还有更多。

**怎么排序。** **最佳匹配**把名称和标题放在最前，然后是说明、标题行和文件名，再是正文。在一个字段内，出现次数多的在前，然后是最新的。**最新**按时间给文字匹配排序。

**结果。** 打开一个结果可以阅读它的条目、消息或文档的块。人员的标签会打开他的卡片，结果的标签会打开那样东西的卡片。时间旁边的一行写出匹配是在哪里找到的，例如**在名称中**或**在聊天消息中**。

### 文字和相近含义

文字的结果在输入时、短暂停顿之后开始出现。如果组织使用**语义搜索**，含义相近的结果会通过同一次搜索到达。先回答的来源填满列表，服务器在其他回答到达时发送合并后的顺序。没有高亮文字的命中会标为**含义相近**。

- 来源在运行时，**正在搜索…**和数量保持显示。结果仍可使用。
- **含义相近的搜索不可用**表示那个来源无法回答。悬停、聚焦或点按状态可以看到原因。文字的结果保留。
- **索引已暂停**表示在建立索引等待它的提供方期间，已存储的查询向量仍然可以回答。提供方关闭期间，新的查询无法调用它。
- 带引号的短语、**正则表达式**或**最新**只使用文字，并说明原因。

含义会等待输入停顿或按下 **Enter**。更改查询会取消之前的搜索。重复的查询可以重用它所在组织的查询向量。它不会为每个按键发送嵌入请求。

### 保持阅读位置

在你还没有开始阅读时，列表可以按服务器给出的最新顺序稳定下来。悬停在结果上、聚焦它或打开它的卡片，会让新的顺序保持不变，直到你离开它。在你滚过第一屏、使用**显示更多**，或稳定的时间结束之后，各行保持在原位，之后的结果添加在它们下面。只来自含义的结果位于**含义相近**之下。

### 显示更多

第一次**显示更多**会显示已经从两个来源收到的所有结果。它不发送新的搜索。之后再按会继续同一次搜索，并添加它接下来的结果。如果模型改变了，文字继续。请开始一次新的搜索来使用新的语义索引。搜索及其筛选保留在地址里，所以可以加书签或发给别人。他们看到什么，仍取决于他们有权阅读什么。

### 筛选和仅搜索文字

使用标签页来搜索会话、聊天、文档或带有文件的结果。在宽屏上，筛选在左边。在较小的屏幕上，打开**筛选**可以得到同样的控件。生效的筛选显示在结果上方。可以在那里移除其中一个，或选择**清除**。

- 选择位置、所有者、创建者、最后编辑者，或写出匹配部分的人。
- 选择**创建**或**编辑**来设定日期范围。文档和会话使用它们自己的时间，聊天使用匹配的消息的时间。较早的、带日期但没有日期选择的链接使用**写作时间**，即匹配部分的时间。
- 限定在某种文件类型、标题、提到你的内容、共享的条目，或你参与的内容。会话的种类和**作者**对更窄的搜索仍然可用。
- 与某个文件有关的文档结果会显示匹配的当前文件。会话的某些文件没有记录类型。选择**任何**可以包含它们。打开一个结果，可以到达只存在于它的会话工作区里的文件。

搜索会在这台设备上记住你的标签页、排序、筛选和已打开的筛选分组。它不会保留你输入的词。带有自己排序或筛选的地址优先。你保存过、但已无法再搜索的位置、聊天或文档，会退回到默认视图。同样的选择适用于文字和含义。筛选绝不会给予访问权限。直接聊天和群聊只对其中的人出现。检查它们并不会把它们加入搜索。

**正则表达式**使用正则表达式而不是字面的词。无效的表达式会保留在输入框旁边。带引号的短语、正则表达式、**仅标题**和**最新**只使用文字。[语义搜索](semantic-search.md)说明它的设置、索引的状态和模型的选择。

## 名称和活动记录

**所有内容**列出你可以打开的位置、人员、文档和资源。它的筛选收窄列表，选择一行会打开那样东西。人员的公开资料显示他们自己的话、固定的工作和你能阅读的活动。固定并不给予对其目标的访问权限。

位置的审计记录写下谁在什么时候更改了什么。可以按人员、操作、种类或日期筛选，或按天或种类给条目分组。阅读记录的权限是针对那个位置检查的。打开某个人的资料并不给予它。保留的内容在你的权限允许时，可以在只读的检查中打开，而不必先恢复内容。

## 在会话中查找

在会话里，它的菜单包含**在对话中查找**。标题下方会出现一个带有输入框和两个箭头的栏。第一个命中会被带入视野并高亮。**Enter** 前往下一个较旧的命中，**Shift+Enter** 前往较新的命中。词会在绘制出来的行里被标出。

## 帮助和提示

术语或选项旁边的问号会在原处打开一张卡片：它是什么、根据你想要什么选择哪一个、在哪里设置，以及指向论述它的文章的链接。**F1** 会在你面前的屏幕旁边打开它的帮助：这个屏幕有什么用、上面的提示、属于它的文章，以及现在绑定的按键。没有被请求就显示的提示，例如你第一次打开查找器时的那一条，可以永久关闭。它在你使用的每台设备上都保持关闭。

位于 `/dev/ui` 的界面图库只在开发构建里可用。它显示共享的控件及其状态，不创建任何工作和权限。生产构建不提供这个图库。
