# Model-call status

Status.tsx owns the compact recovery sentence for the thread live line, attention banner and job
activity line. Controllers use the existing query/act and permission boundaries; status never starts
a call. Known duration and count use the common formatters, and missing values remain unknown.

Model.tsx displays configured model references with the central resource chip and its lazy inspection
card. Rule rows, live recovery and timeline markers use that same model role.

Help.tsx uses the shared question card for recovery terms. It opens the matching section of the
authored English or Chinese guide and coalesces repeated destinations within each reading surface.

History.tsx authors causal history sentences from the recorded attempt limit and links to the topic's recovery rules. Old history keeps its unknown denominator. Automatic input headers retain the author and keep rule details in their tooltip.
