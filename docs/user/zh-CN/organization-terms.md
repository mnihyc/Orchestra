# 接受组织的条款

组织可以要求受邀者在加入前接受条款。受邀成为组织内位置或群聊的访客时也适用。先显示根组织的条款，再显示各级下属组织补充的条款。

## 在哪里

打开邀请链接，阅读可滚动的“条款”框，勾选“我接受……的条款”。这一个选择会启用“加入”，也会随注册或身份提供方登录一起提交。使用已有账户登录后，会回到邀请页面。

编写条款时，打开组织的“设置”，找到“加入者须接受的条款”。编辑此组织自己的 Markdown 内容，使用“预览”查看它与上级条款合并后的效果。权限、锁定和保存方式与其他设置相同。从[组织入口](/)打开相应组织的设置。

## 示例

Studio 根组织的条款要求客户材料留在组织内，Research 下属组织补充了保密截止日期。Research 的邀请会依次显示两段内容。阅读后勾选唯一的复选框，再加入。成员管理者可以在成员行查看“已接受条款”及记录的日期。

## 操作后会怎样

接受的是页面上显示的那一版文本。如果加入前条款有变，会显示新文本并要求重新勾选；已经填写的注册字段会保留。如果身份提供方登录往返期间条款有变，请返回邀请，阅读后重新开始登录。

没有条款的组织不显示复选框。修改条款不会要求现有成员再次接受；如需告知他们，请发送[管理员消息](messages-from-admins.md)。系统邀请没有组织条款。
