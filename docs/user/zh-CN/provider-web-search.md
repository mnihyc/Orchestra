# 提供方网络搜索

线程的“参数”视图在各项能力旁展示所选程序的访问方式事实。Claude Code 的转发连接
不使用仅限原生主机的测试版选项、缓存主动保活、托管模型目录以及原生 WebSearch 的
引用和模式选项；普通转发生成和线程选择的缓存时长不受影响。在“分离”安排下，
原生 WebFetch 从提供方运行时读取网页，线程会注明此位置。这些是当前路径的说明，
不会额外授予权限或增加工具。

直接登录的原生搜索用量按模型在轮次边界报告。Orch 只记录一次增量，先扣除已在
真实请求中记录的数量，再按配置的单位价格计价，与词元价格和处理速度分别计算。
恢复会话后，若此前累计值未知，首次报告只建立基线；未报告的数量不会被当作零。
转发连接继续使用转发器的计量。

Codex 的独立网页操作只有在保留的原生结果证实成功时才计量。搜索计入网页搜索；打开网页或查找网页文字计入网页读取。
搜索结果为空也可能是成功调用。程序的结束事件或分析计数本身不能证明成功；失败或无法匹配证据的尝试会明确显示，不计次、不计费。
缺少证据保持未知；解码只使用已验证的原生版本，不根据消息措辞猜测。重放和接管展示历史结果，不会再次计费。

**网页操作失败。**（`native_web_action_failed`）表示保留的结果报告失败。
**无法核实此次网页操作。**（`native_web_action_unproven`）表示无法匹配结果、原始归属、模型或受支持的格式。
操作仍保留已报告的查询、页面和原始来源，不会让已完成的文字轮次变为失败。在该操作的原始视图中打开**完整输出**，可查看原生结果和已报告的结果。


在**用量 → 请求**中，**原生能力用量**标明这些汇总数量，并链接到原始轮次。
它们不会额外增加模型请求、词元费用、尝试次数或耗时。明确报告的零保留为零；
未报告的模型词元份额显示为**未测量**，未知的单位价格保持未计价。

提供方可以向代理、摘要和目标检查提供模型的原生网络搜索。提供方管理者决定允许哪些模式，以及新的使用默认选择什么。来源列出支持的模式不会自动启用它。

在提供方的“模型”页面启用支持的模式并选择默认值。线程随后在“参数”中选择提供方允许的模式。“关闭”移除托管搜索工具；“缓存”在协议支持时仅使用索引内容，不实时读取外部页面；“实时”允许模型按需搜索公开网络。默认值仍可覆盖；固定值显示其来源。

协议兼容不代表每个模型都支持搜索。DeepSeek 文档明确说明 Responses 接口的 Pro 模型支持服务器端搜索；忽略搜索选项的模型不能算作实际运行了搜索。Google 的 OpenAI 兼容文档仅在 Images 端点列出搜索工具，没有说明 Chat 的搜索映射。因此 Google 搜索 grounding 需要原生协议或声明相应映射的翻译器。

## 配置托管工具

先在提供方模型上启用模式。Responses 端点的请求默认值示例：

```json
{"web_search":{"mode":"live","search_context_size":"low","filters":{"allowed_domains":["example.com"]}}}
```

Messages 使用其自身的选项：

```json
{"web_search":{"mode":"live","max_uses":3,"allowed_domains":["example.com"]}}
```

允许列表与屏蔽列表不能同时使用。每次使用的“关闭”选择覆盖默认值。端点默认值只配置代理已选择的工具，不会启用运行程序未列出的工具。摘要和目标检查通过相同的提供方模型限制解析其选择。

## 设置搜索价格

模型费率和费率表支持“每次网络搜索的额度”（`web_search_per_call`）。它与令牌费率使用相同的额度单位。如果额度以美元计，文档中的基本搜索费为 OpenAI 和 Anthropic 的 `0.01`，以及 DeepSeek 每次成功搜索的 `0.00075`。搜索费用不乘以令牌的服务档位倍率；搜索内容本身仍可能产生模型令牌费用。

每个请求保留来源实际报告的搜索次数。一次可见的 WebSearch 工具调用可能包含多次后端搜索，不能直接当作计费次数。缺少次数或价格时，完整费用为未知。重复的累计报告不会增加使用量。这些是按配置计算的估算，不是账单。

明确选择的搜索引擎可以同时按请求收费，并对计费结果另收费用。Orch 会随实际请求保留这些声明的价格项。请求的结果上限和展示的引用链接不是实际测量的计费结果；缺少任一必需数量时，完整估算仍为未知。自动和原生引擎选择的价格取决于提供方，除非实际报告了总额。单位一致的报告总额只替代目录估算；提供方和费率表明确设置的额度价格保持计费依据。

原生网络搜索查找公开网页。Orch 的 `search_shared` 查找代理有权读取的共享文档、聊天和线程，两者独立。

来源：[OpenAI 网络搜索](https://developers.openai.com/api/docs/guides/tools-web-search)、[Anthropic 网络搜索](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool)、[DeepSeek Responses](https://api-docs.deepseek.com/guides/responses_api/)、[Gemini grounding](https://ai.google.dev/gemini-api/docs/google-search)。

## 在哪里

打开[提供方](/resources/providers)，选择提供方，再进入模型和选项。提供方管理者在此启用支持的搜索模式并设置默认值。线程的“参数”可以为本次使用选择允许的模式。[用量](/usage)将实际报告的搜索次数及配置计算的费用，与其他请求用量一起显示。

## 示例

某个提供方模型支持实时搜索。为它启用实时模式，不改变其他模型的上限。在线程中选择这个模型和实时模式，请代理检查发布者最新的版本公告。查看代理给出的来源链接及本次请求实际记录的搜索用量。搜索设置代表可以使用工具，不代表模型已经使用；来源没有报告次数时，用量保持未知。下一次不需要查询网页时，选择关闭。

## 能力的运行方式

打开线程的“参数”视图，查看“能力”。每一行都来自服务器使用的同一份能力声明和当前设置，说明由模型原生工具、程序原生工具、已选择的提供方服务或委派会话执行。不可用的能力显示当前原因，例如模型停用、模式不受支持、缺少权限或尚未选择服务。程序未报告默认行为时，显示“程序默认”。

只有你有权查看时，才显示提供方及每次调用的报价。报价保留声明的货币和单位；缺少价格表示未知。查看方式不会预留用量或授权之后的调用：执行时仍会检查当前访问权限、提供方设置和用量上限。仅配置提供方后端不会启用付费服务。保留“程序默认”以继续使用程序当前的行为，或在提供服务选项时明确选择它。

例如，打开一个使用提供方搜索服务的线程的“参数”。“网页搜索”行显示该提供方及每次搜索的声明价格。权限被撤销后，同一行显示不可用及其原因。Orch 不会自动改用另一个提供方。后续扩展声明的新能力也会出现在相同列表中。

托管搜索和网页抓取使用所在位置现有的调用规则。配置的重试保留工具最初的截止时间。配置的回退会对每个明确指定的候选重新检查权限、供给限制和用量上限；无法使用的候选会被跳过，候选以不同原因失败时仍继续同一规则链。恢复成功后，线程记录原因和规则，不改变配置的后端。每次尝试只记录实际测量的用量。等待人工处理或重置时间超过工具截止时间时，工具返回暂停结果；在线程现有的恢复操作中处理，或等待所报告的重置，再由代理发起下一次调用。


## 网页抓取

**网页抓取**（`agents.page_fetch`）与网页搜索分别设置。未设置时保留程序现有的网页读取行为。**关闭**不提供此能力。**原生**使用所选程序或模型声明的网页读取工具。**服务**使用明确选择的抓取供给，并在下一会话关闭其声明的原生对应工具。启用托管网页搜索不会同时启用托管网页抓取。

组织的“网页搜索后端”选择提供方及模型，或该提供方上分别提供搜索和抓取的服务。接口后端的抓取服务为可选项；后端不支持抓取时，这项能力保持不可用，Orch 不会用搜索摘要冒充网页正文。提供方管理者在提供方“设置”中分别启用服务，并可配置其分组和精确额度价格。每次运行都需要当前使用权限、所有适用供给策略以及剩余用量上限。

例如，保留网页搜索已选模式，在所在位置的设置中将网页抓取设为服务并保存。开启新会话后使用更新的工具集合。读取网页时，线程以与原生网页打开相同的卡片显示实际地址和返回正文。用量记录网页抓取用途、实际后端和报告的计费页数，不会将搜索结果链接数当作抓取页数。改为关闭后，即使先前会话仍展示旧工具，也不会再发起付费抓取。

提供方报告的总额只有在单位一致时才可替代目录估算。提供方管理者或费率表明确设置的 Orch 额度价格保持计费依据；上游报告总额在旁显示，供比较。

## Codex 端点支持

部分 Codex 模型使用单独的原生搜索请求。这类模型需要端点明确声明支持，同时模型本身已启用搜索。只有当前能力解析允许时，才提供“缓存”“索引”和“实时”。端点不提供所需的原生工具时，可以明确选择搜索服务；保留“程序默认”不会自动选择付费服务。

一次成功的独立搜索计为一次搜索操作；打开网页或在网页中查找文本计为单独的网页操作。多个查询或来源链接不会增加操作次数。失败或无法证明成功的结果不按这些数量收费。仅搜索的回复不提供生成令牌的测量值。

主模型不支持原生搜索时，只要托管后端可用，Codex 的普通“网络搜索”控件仍可提供“服务”。打开控件或保持未设置不会选择付费服务。选择“服务”会关闭原生搜索，并在重新打开会话时生效。高级代理配置中的原始 `web_search` 键仍是 SDK 原生选项，只能在提供方允许的范围内使用关闭、缓存、索引或实时模式；托管服务通过线程的普通控件选择。
