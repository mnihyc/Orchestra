# 语义搜索

语义搜索还会查找含义相近的文字。它默认关闭。语义搜索关闭、不可用或仍在建立索引时，文字搜索继续可用。[查找内容](finding-things.md#words-and-similar-meaning)说明搜索结果的列表。

## 启用语义搜索

1. 管理员打开**管理 → 语义搜索**。表格显示每个组织的索引。它下面的设置是系统的默认值。组织可以有自己的设置和继承来的锁。
2. 打开**语义搜索**，然后指定它的**嵌入**。

指定提供方的人要为它的使用和费用负责。这个人必须保留使用该提供方和模型的权限，共享的用量限制仍然适用。

## 选择嵌入

先选择提供方，再选择已打开的模型及其维度。提供方需要一个它的容器可以访问的嵌入端点。它的凭据、标头和秘密标头是提供方通常的那些。

- **未设置**表示还没有选择用于嵌入的提供方和模型。
- **托管**表示这项设置使用了你可能看不到的提供方。这不是故障。
- 锁显示在这项设置通常的行里。

查询和文档的前缀是模型选择的一部分。请使用模型期望的前缀。在文档的前缀里，`{title}` 会变成来源的标题，或 `none`。更改前缀会重建索引。

## 本地嵌入

**添加本地嵌入**会打开通常的**添加提供方**对话框，并选中这个示例。它填入嵌入协议、容器的回环地址、`embeddinggemma-2`、256 个维度和它容器的模板。像对任何提供方一样选择所属位置、机器和运行时，然后创建它。之后会出现嵌入编辑器。请单独保存这项设置，才会用这个提供方做搜索。创建提供方不会改变这项设置。

随 Orch 附带的模型可以使用这些前缀。每个都以一个空格结尾：

- 查询：`task: search result | query:`
- 文档：`title: {title} | text:`

**模板 · 本地嵌入**会打开提供方的模板。它也在**资源 → 模板**里，那里显示并可以编辑它的 Dockerfile。它可以按与任何模板相同的规则被移除。移除之后再添加这个示例，会创建一个新的，不会带回被移除的模板。已有的模板会保留你对它所做的编辑。[添加提供方](add-a-provider.md#local-embeddings)说明通常的设置。

## 索引状态

| 状态 | 怎么做 |
|---|---|
| 未设置 | 选择嵌入，或使用**添加本地嵌入** |
| 正在计数… | 索引正在查找文本。整个索引没有百分比，也还没有时间 |
| 正在建立索引 | 仪表显示已嵌入的令牌，这一行给出令牌或估计的剩余时间 |
| 就绪 | 当前的索引已经赶上 |
| 已暂停 · 提供方已关闭 | 打开提供方以恢复建立索引 |
| 已暂停 · 提供方已移除 | 选择另一个嵌入提供方 |
| 已暂停 · 达到磁盘限制 | 提高限制、选择较短的向量，或更改建立索引的方案 |
| 需要选择 · 新模型 | 阅读新索引估计的磁盘和时间，然后选择**重建**或**保留当前模型** |
| 缺少 pgvector | 请运维人员使用带有 pgvector 的数据库 |

提供方、模型、访问权限、限制或机器的问题会显示在同一行里。文字搜索仍然可用。**搜索**里不可用的来源会在悬停、聚焦和点按时保留它的原因。第一个索引会根据最早完成的向量开始回答，并且绝不会声称整个语料已经就绪。

### 提供方暂停

关闭嵌入提供方会取消它当前的批次并暂停建立索引。进度行会写**提供方已关闭**。这是一次暂停，没有重试，也不计失败次数。打开提供方会让建立索引自动恢复。移除它会写**提供方已移除**。已存储的向量保持原样。

搜索可以使用仍在缓存里的查询向量。它保留按含义得到的结果，并写**索引已暂停**。需要已停止的提供方的新查询只使用文字，原因写在**含义相近的搜索不可用**上。提供方恢复之后请开始一次新的搜索，以便包括这期间建立索引的内容。

## 磁盘限制

**磁盘限制**是索引大小的限制，以它所索引的已存储内容的百分比表示。它从 **100 %** 开始。留空表示**没有限制**。索引的每一行都写出已用和允许的磁盘（估算值）。在下一次分配会超过限制之前，建立索引会暂停。小的索引可能需要比它的文本更多的字节。提高限制之前请先查看这些估算。

## 切换模型

替换索引是在当前模型继续回答的同时构建的。新的前缀、另一种块大小、更长的向量或不同的模型，需要为内容生成新的向量。从另一个位置提供的同一个模型，会先用已保存的探测文本检查。兼容的较短向量（MRL）会被缩短并重新建立索引，不必再次嵌入所有内容。

如果磁盘限制容不下两代索引，这一行会要求你先做出选择。

- **重建**会移除当前的索引，并开始你要求的那一个。在此期间，按含义搜索涵盖已经完成的部分。
- **保留当前模型**会恢复构成当前索引的提供方、模型、维度、前缀和块大小。

这项设置通常的权限和锁仍然适用。搜索中旧的游标不能在中途在不同的嵌入空间之间切换。更改之后请开始一次新的搜索。

## 索引与排序

**索引与排序**控制块的大小、批次、候选窗口、扫描的预算和查询的等待时间。这些是你可以更改的默认值，它们不授予任何权限。

- **文字检索**选择限制在范围之内的读取，对象是较小的、可以访问的集合。名称和标题、说明、标题行、文件以及正文的可选限制，在省略时采用**文字候选数**。每个请求的**窗口数**默认是一。**显示更多**从那个窗口继续，即使它的所有候选项都被你当前的访问权限隐藏了也一样。较大的访问树使用同样有界的窗口。搜索在返回结果或片段之前，保持对当前权限的同样检查。
- **含义**精确比较小范围的向量。更宽的范围使用图。**图扫描**默认是**按距离排序**。**图宽度**未设置时是自动的：候选数乘以过采样倍数。**精确筛选候选数**为 **0（关闭）**时，所有范围都使用图。
- 索引器从较新的内容开始。进度和时间估算取决于为端点测得的速率。
- 含义只等待它的查询预算，超时后保留文字结果。智能体的搜索返回把两者合并起来的一个答案，当含义无法回答时，则返回文字及原因。
