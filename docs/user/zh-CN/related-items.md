# 相关内容

## 打开相关内容

在文档的检查面板中展开**相关内容**，可查看你能阅读的文档、聊天和线程。
每行用简短文字说明原因：位置相同、语义相近，或两者之间有引用。
两者引用了相同内容时，会显示**共同引用**。没有结果时不显示条目。

悬停或聚焦标签可预览引用卡片，点击或按 `Enter` 可保持卡片打开。
在卡片中选择**打开**、**在旁边打开**或**复制引用**，按 `Escape` 关闭。

展开时读取一次列表，同一文档版本会复用结果。文档变化后重新读取。
引用卡片仍通过普通预览检查目标的当前权限。
修改相关设置或权限会更新已展开的列表。语义尚未索引时，再次展开会重新检查。

## 语义可用性

**语义已关闭**表示语义搜索或语义权重已关闭。
**语义尚未索引**表示当前文档在正在回答的索引代中没有可用的条目向量。
空文档需要先添加内容。
**语义暂不可用**表示向量存储或查询未能回答。
语义无法参与时，位置和引用仍可排序。

相关内容使用已保存的条目向量，展开列表不会请求生成嵌入。
不同索引代或模型的向量不会互相比较。

## 调整排序

文档所在位置会继承**相关内容权重**、**相关位置分值**、**相关内容条数**和**相关候选数**。
管理者可在该位置的设置中修改，上级锁定的值仍然生效。

默认权重为语义 `0.6`、位置 `0.25`、引用 `0.15`，使用零到一的小数字段。
权重为零时不使用该信号。系统会按可用权重归一化，关闭语义不会削弱其他信号。

默认位置分值为同一文件夹 `1.0`、话题 `0.7`、项目 `0.4`、组织 `0.1`。
文件夹可以是文档文件夹，也可以是项目内的子项目。
直接引用得一分，共同引用按各自引用目标的重合程度计分，重复链接不会增加分值。

**相关内容条数**默认显示八条，设为**关闭**可隐藏列表。
**相关候选数**默认为每个信号及引用邻域 200 条，在精确检查权限前限制工作量。
需要扩大候选范围时可以调高。

## 让智能体查找

智能体可调用 `search_shared`，用 `related_to` 替代 `query`：

```json
{"related_to":"docs/Rollout plan.md"}
```

也可使用 `id:` 引用，以 `kinds`、`path`、`names` 缩小列表。
每条结果通过 `related_by` 标明 `meaning`、`place`、`references` 或其组合。
智能体只能看到当前共享给它的范围，与你自己的阅读权限可能不同。


打开时只读取一页，并按文档版本缓存。点击 **更多** 才读取下一页。
访问权限或排序变化后，会清除旧的续页并重新读取。
共同引用按设置限定的不同目标窗口计算；重复引用不会提高分数。
智能体可以用 `max_results` 指定页大小，保留 `related_to` 和筛选条件，带上返回的 `next_cursor` 继续。
排序或权限变化使旧游标失效时，从第一页重新开始。
