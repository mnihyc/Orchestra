# 检查存储内容、会话和令牌

开启管理员模式后，系统管理员可以通过原生视图检查所管理的存储对象。所有者、存放时间、大小、附加位置和活动记录，使孤立数据也能被发现。管理访问或撤销会带有标记并记入审计；清单不会显示凭据密钥值。

## 在哪里

打开[管理](/admin)。在“用户”中查看所选人员的会话和令牌；系统“令牌”列表汇总不同人员的 API 令牌。“存储”列出上传、快照、导出、导入报告及机器存储项，“打开”进入允许访问的原生视图、已记录的导出清单或只读导入报告；检查别人的导入报告不会提供“撤销导入”。未完成或已过期的上传不提供“打开”。

个人设置的[上传](/storage?view=uploads)列出自己未附加的上传。删除未完成的项会取消上传；删除已完成的项会移除自己的保留关系，已附加的文件会保留。

查看自己的浏览器会话可用[安全](/settings/security)，API 令牌可用[令牌](/settings/tokens)。环境的“文件”列出保存的文件快照；机器的“存储”页报告数据目录的组成，凭据存储只列名称和大小。

## 示例

某个上传文件已不再附加到消息。在存储列表找到它，检查上传者、存放时间和大小，再通过标明的管理员访问打开。撤销某人的旧令牌前，先查看所有者、目标、允许操作、最近使用和到期时间。撤销指定令牌后检查活动结果；撤销一个令牌并不代表结束了所有浏览器会话。

## 操作后会怎样

会话行显示浏览器、网络地址、创建时间、最近活动和到期时间。“退出”只结束选中的会话；“全部退出”结束该人员的所有会话。检查自己的账户时也包括当前浏览器，之后需要重新登录。令牌列表只显示范围和活动，不会恢复显示密钥。未完成的机器上传保留真实状态，不会显示成已完成。

导入报告或导出清单不等同于包文件下载。下载包仍使用所有者的正常权限，或经过审计的管理员访问。未知大小保持未知。删除数据前先检查当前状态。另见[存储清理](storage-cleanup.md)、[导入与导出](import-and-export.md)和[账户安全](account-and-profile.md)。
