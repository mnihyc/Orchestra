# 用户指南

从一个人与智能体并肩工作、再有一位同事加入同一项工作开始：[开始使用](getting-started.md)带你走一遍。这些指南说明现有的屏幕、它们要求的权限以及你会看到的结果，并如实说明什么是**暂不可用**。

这份指南也是应用内部的帮助。每一页都属于它所说明的屏幕，可以从这些屏幕的提示和查找器打开。每一页都有一个同名文件的[英文版](../README.md)。

- [开始使用](getting-started.md)：设置、登录、你自己的组织、提供方和模型、第一个话题和邀请。

- [临时环境](temporary-environments.md)：创建、关注截止时间，以及移除之前保留或导出。
