# 文件和附件

消息、代理工具、文档、文件面板、搜索和收件箱使用同一种文件标签和卡片。
悬停、聚焦或点击标签即可打开卡片。能够预览的图片会显示小缩略图。
在文件面板中，点击名称会打开常用的代码视图；悬停或聚焦名称仍可查看卡片。

## 预览和标签大小

卡片显示预览、名称、大小，以及已知的详情。未知的详情显示 **–**。
文本和代码显示简短片段。压缩包在可读取时显示条目数。
音频和视频在可读取时显示时长。没有图片预览时，显示文件类型的图标。

右键点击标签、按菜单键或 Shift+F10，或长按标签，然后选择**显示为**：

| 大小 | 显示内容 |
|---|---|
| 小 | 类型图标和名称 |
| 中 | 图标、名称，以及次要提示或大小 |
| 大 | 放在正文中的卡片，包含预览、标题、说明首行，以及已知的所有者和最后修改时间 |

紧凑行默认使用小标签。消息和其他正文默认使用中标签。文档中单独占一行的引用默认使用大卡片。
在紧凑行中选择大卡片时，会显示为中标签，让行保持紧凑。

在你有权编辑的文档中，这个选择与该引用或媒体块一起保存，其他人也会看到它。
只读文档会说明为什么不能更改大小。在其他位置，选择保存在此设备上你的工作台中，按位置类型分别记住。
重置工作台会恢复默认大小。

## 打开和下载

点击缩略图，或在卡片中选择**打开**。附件与工作区文件使用相同的查看器。
图片可以适应窗口或按实际大小显示。PDF 提供页码、缩放和文本搜索。
音频和视频使用播放器控件。文本、代码、Markdown、差异和压缩包使用各自的查看器。
其他文件可以下载或按文本打开。附件视图只读；可写的工作区文件在代码视图中编辑。

预览使用小副本，**下载**取得原始字节。只有打开查看器且需要内容时，才读取原文件。
启用减少动态效果后，动态图片会保持静态预览，直到你选择**播放动画**。
文档中的外部媒体地址会等待你明确选择播放。
卡片用一行显示主机和文件名，悬停可查看完整地址。

**复制引用**取得可以粘贴到消息或文档中的链接。工作区引用可以包含选中的行号。
尚未保存引用、也没有接收路径的草稿或工具产物，会说明为什么不能复制引用。

## 交给代理的文件

在输入框中添加附件并发送消息。模型和代理工具都支持图片，且图片不超过配置的原生图片额度时，模型会直接收到图片。
图片也会写入线程目录。其他文件以经过检查的工作区路径、类型和大小交给代理。

**此模型将以文件形式接收图片**表示代理将通过路径取得图片。你仍可发送，也可更换模型。
如果文件实际投递失败，输入会被留住，并说明哪个文件失败以及原因。

共享文档中的文件仍然是文件引用。代理可通过 `download_shared` 取得原文件。
转发，以及分叉、切换、移动或导出中选定的文件，都携带原文件，而不是缩略图。操作计划和当前访问权限仍然适用。

## 预览状态

- 骨架占位表示正在加载。预览进入可见区域后才会请求。
- **预览不可用**表示此类型或此文件无法生成预览，仍可下载。
  HEIC、HEIF、AVIF 和 TIFF 目前使用此状态。PDF 和视频卡片显示类型图标。
- **文件已不存在**表示原文件已丢失，不能再打开或下载。
- **无法访问的引用**会在你无权读取文件时隐藏名称和卡片。
- **文件过大，无法预览**仍提供下载。预览限制不会改变原文件。

共享操作见[工作与协作](workflows.md)，搜索和查找器见[查找内容](finding-things.md)。
