# 注册自己的程序

## 使用已安装的代理程序

打开已连接机器的**程序**部分。在机器上找到的代理程序会显示版本和路径。
**版本未知**表示程序没有报告可识别的版本。选择**使用**确认找到的程序；
随后该行显示**已确认**，并提供**移除**。这些操作需要机器的管理权限，
以及本机允许管理代理程序的策略。若本机保留了该权限，请使用页面中这台机器
实际报告的策略命令。**刷新**会重新搜索并读取当前报告。

移除确认会保留程序文件，停止使用该程序的执行器；受影响的线程在运行前会重新检查。
仅被找到、尚未确认的程序不可用于执行。

## 允许环境中程序的版本

在环境的**工具**页面，若已确认的程序为该环境提供工具，**Codex 工具**会显示它的
版本和路径。通常它的版本必须与代理的版本相同。环境管理者可以打开**任意代理版本**；
开关旁会显示当前批准者的姓名。批准仅适用于显示的路径和版本，包括**版本未知**。
路径或版本改变后需要重新批准。关闭开关会恢复版本匹配要求。
此决定在线程下次开启会话时生效。
代理适配器支持的版本范围和环境的其他规则仍然适用。

因版本不同而阻塞的线程会链接到此环境页面。管理者允许当前程序后，线程会重新检查，
符合条件时继续运行。从模板创建的环境仍使用自己的工具构建。

## 1. 选择机器和程序类型

若要注册自己的适配器或提供方数据源，请按以下步骤操作。

打开已连接机器的**程序**部分，选择**代理适配器**或**提供方数据源**，再选择**添加**。
程序必须已在那台机器上可用；你笔记本上的路径并不指向另一台主机的文件。
程序以连接器的账号运行。

**代理适配器**包装任意代理程序，把会话、输入和结果转换为 Orch 的代理接口，并声明
支持的模式、输入格式和登录方式。**提供方数据源**为模型服务报告模型、限额或用量，
不必自己运行模型；它实现提供方数据源接口，声明能够提供的报告。

## 2. 填写名称和命令

填写注册名称，以及程序路径和参数。路径包含空格时加引号。
命令直接执行，不经过命令解释器，不展开管道或命令解释器变量。
选择**注册并读取声明**。Orch 会读取声明，在机器允许的情况下保存注册，并显示返回内容。
失败时修正命令后重试，已填写的名称和命令会保留。

## 3. 使用返回的声明

代理程序在**添加代理 → 机器上的程序**中选择，用它创建配置；提供方数据源在添加或编辑
提供方的**模型、限额与用量**中选择。两种流程都可以直接注册程序，使用同一份注册表。
能力来自程序的声明，注册本身不会让它获得未支持的模式。

**测试**只会再次读取声明，不证明模型调用或代理运行一定正常；还应使用新配置或提供方
完成一次小任务。**移除**会停止程序并删除由 Orch 管理的注册项，但保留程序自己的文件。
仍在使用它的配置或提供方需要先改用其他程序。

## 4. 注册由本机保留时

本机策略可能把注册权留给机器的管理者。Orch 会显示原因，并为已有的本地注册提供
**重新加载**，不会假装“注册”可以覆盖该选择。如需在这里管理，请机器的管理者交出
注册设置。管理员权限也不能覆盖机器的本地决定。

实现细节见[代理适配器接口](/help/agent-adapters)和
[提供方数据源接口](/help/provider-readme)；这些开发文档目前为英文。


## 选择运行方式

新建线程设置中，“代理运行位置”标题旁现有的问号会打开本指南。选择前先了解代理和工具在哪里运行，以及凭据是否离开提供方。可选方式来自程序、提供方和环境的声明；不可用的方式会保留原因。选择运行方式不会授予使用权限，也不会改变提供方限制。系统可以建议排名最前且可用的方式；你明确选择的值会继续保留。

[设置参考](settings-reference.md)列出所有内置设置及结构化字段，[选项字段参考](option-reference.md)解释随产品提供的接口选项，[状态参考](state-reference.md)解释报告的状态，[错误参考](error-reference.md)说明拒绝的含义与处理方式。在“帮助 → 设置”中，每个完整条目还给出默认值、示例和适用范围；从控件打开时，可以查看当前值的实际来源。

## 检测到的配置详情

在**添加代理 → 机器上的程序**中，第一个已确认的程序会填入程序字段。选择**可用的适配器**时，目录中仅有一个选项便会填入；存在多个时由你选择。**来自机器**、**来自目录**和**你的选择**标明来源。刷新会保留已选程序、名称和归属。程序消失时，其名称仍保留，并显示**此程序已不可用**；创建配置前需另选程序。切换程序来源或机器后，会重新确定程序选择。

**版本**是机器报告的已安装代理程序版本，也包括自定义适配器对代理程序的声明；不会采用适配器自身的构建版本，也不会假定目录中的某个版本已安装。**版本未知**表示没有报告可用的版本，**选择机器后检测**表示尚无机器上的观测。该版本仅供查看，不会新增版本固定。

**账号**列出这台机器上为该程序注册的订阅提供方，并显示各自报告的状态。已有登录由连接器现有的发现流程读取。列出的账号不证明刚刚验证过登录，也不会授予使用权限。**尚未报告账号**表示信息未知，不表示机器上没有登录。可打开账号卡片查看详情。

**程序支持**优先使用机器上就绪程序的声明，否则使用目录声明；**机器允许**另行显示机器报告的运行方式策略。**无**表示明确报告了空列表，**尚未报告**表示没有提供列表。**运行方式 → 自动 · 来自线程默认值**保留现有的统一选择逻辑：设置线程时，结合实际提供方、环境、机器和权限，优先考虑已配置的偏好，再采用首个可用且获准的方式。这些配置信息不会选择能力路由、复制凭据或启用服务。在那里明确选择的运行方式仍由你决定。
