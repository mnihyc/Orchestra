# 让代理安排未来的工作

代理可以为自己的线程安排稍后的输入，例如十分钟后检查 CI 运行，或定期做一次简短评审。Orch 会展示这些计划，并提供取消操作。它们与人员的计划共用普通输入队列。

## 启用代理计划

打开线程的“计划”视图。“代理的计划”默认关闭。可以在这里开启，也可以在系统、组织、项目或主题设置中指定继承的选择；通常的设置锁仍然适用。

“代理计划的持续时长”和“代理计划的执行次数”给出周期计划的默认结束条件：24 小时和 20 次。这些是默认值，可以明确选择不同的截止时间或正数次数。修改默认值不会重写已有计划的结束条件。

## 查看待执行的工作

每个待执行的代理计划都会在对话后显示一行：下次时间、便笺和“取消”。“计划”视图将人员和代理的条目放在一起，展示代理代谁执行、重复方式、结束条件、下次执行时间和最近的结果。暂停的计划不会承诺在某一时间继续；失败、暂缓或跳过的执行会保留实际结果。

例如，启用后请代理在十分钟后检查 CI 运行。计划被接受后，就会出现待执行行。之后的输入仍是普通消息，只有与实际执行记录匹配后，才标记为“由自身的计划唤醒”。消息中仅仅提到计划不会得到这个标记；查看较早的执行时，会读取其原生历史记录加以核对。

## 取消或结束

当前具有线程控制权限的人可以一键取消未来的执行。已经进入普通队列的输入会留在那里，需要使用队列自己的控制来处理。关闭代理的计划工具会阻止新调用，不能代替取消已有计划。

每次执行都会重新检查发起者的当前权限和提供方额度。计划不预留权限或额度，默认也不发送通知。这是由 Orch 管理的计划，代理程序自身的私有定时器仍不可用。[运行中的线程视图](running-thread-views.md)说明队列、当前工作和后台任务。
