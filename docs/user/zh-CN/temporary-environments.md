# 临时环境

## 1. 为实验创建环境

在**添加环境**中打开**临时**，选择所属位置、模板和主机。也可从模板或主机页面选择
**添加环境**，预先选中它。在**新建会话**的**运行位置**中选择**新建**后，也可以打开临时选项；
该环境会关联到首先在其中创建的线程，不会成为主题的长期默认环境。

无法运行的代理会停用，并说明原因。**创建会话**会先检查整套配置；如果未被接受，
不会创建环境或会话，你的消息仍留在对话框中。从项目开始时，也只有配置被接受后
才会创建主题。

## 创建失败时

线程会说明哪一步未能完成，并把你的第一条消息保留在队列中。选择**重试**，再次启动
同一个环境；或选择**换个环境运行**，查看并确认切换到其他环境的方案。等待重试时，
仍可选择换个环境。无需重新发送消息，线程能够运行后会继续处理原来的消息。

## 2. 查看删除时间

环境页面显示临时状态和实际删除时间。运行中的任务或正在使用文件的作业会延后清理，
活动结束后重新计算空闲时间。所属位置的**临时空闲时间**默认为 24 小时，可在该位置
的设置中修改；有权限时也可在环境中覆盖。

为线程创建的环境，在创建它的线程被归档或删除后也会安排删除；其他线程的归档不会
触发。归档会先给出一小时警告，不会立刻删除文件。如果 Orch 离线期间错过了截止时间，
恢复后仍会留出完整的一小时。页面显示的是实际截止时间。

## 3. 需要留下时保留，需要副本时导出

删除前一小时，所有者会在**收件箱**收到通知。页面和通知中的**保留**会把环境改为长期
使用，并取消自动删除；应在删除开始前操作。失败时阅读原因后重试。

**导出文件**会复制整个工作区，包括线程起始目录之外的文件；机器必须在线。
导出作为后台作业运行，关闭窗口不会取消。在作业窗口或收件箱的完成通知中下载 ZIP。
这份私人副本在环境删除后仍可供导出者下载。导出期间会推迟清理，并再次留出警告时间。
导出失败不等于已有副本：先保留环境，再处理原因并重试。

## 4. 知道哪些数据会被删除

自动删除会清理环境，以及 Orch 为它创建的工作区、主目录和所拥有的卷或目录，
不会进入普通的已删除文件保留窗口。你选择使用的现有目录、共享挂载和其他环境的文件
会保留，导出副本也独立存在。机器离线或拒绝删除时，清理作业会重试；请连接机器并
处理显示的错误，不要把同名的新目录当成原来的受管目录。
