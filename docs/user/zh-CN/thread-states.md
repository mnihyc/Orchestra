# 线程状态

## 读懂图标

线程在导航树、标签页、页头、列表和引用中使用相同的状态图标。悬停或聚焦图标，
可查看原因、等待消息数或完成时间。实时视图同步更新；搜索结果和引用显示上次读取时的状态。
树形和最近使用相同的状态图标，包括导航抽屉和窄屏下的全部内容卡片。

| 图标 | 状态 | 含义 |
|---|---|---|
| 带问号的盾牌 | 等待批准 | 批准请求、问题、计划或等待授权的消息需要有人处理 |
| 带斜线的圆圈 | 受阻 | 线程暂时无法继续，原因说明需要改变什么 |
| 带感叹号的八边形 | 失败 | 上一轮失败，之后尚未接受新消息 |
| 旋转圆环 | 运行中 | 正在准备或执行一轮工作 |
| 时钟 | 等待开始 | 消息在等待当前工作、限额或计划时间 |
| 暂停圆圈 | 队列已暂停 | 选择继续之前，队列保持暂停 |
| 带勾的圆圈 | 有新结果 | 自你上次查看后，有一轮工作已完成 |
| 对话气泡 | 空闲 | 没有正在处理的工作或未查看的新结果 |
| 归档盒 | 已归档 | 线程或其所在位置已归档 |

需要人处理的事项优先，其次是受阻、失败、运行、等待开始、暂停队列和新结果。
已归档的线程保留归档图标。只有运行图标旋转；开启减少动态效果后，它也保持静止。
两种主题都通过形状表达状态。

自动重试使用时钟图标，并显示等待时间和次数，例如“55 秒后重试 · 第 2 次，共 3 次”。
重试已安排时，无需你作出决定。恢复正在执行时显示运行图标。
自动恢复停止后，失败图标会说明原因，例如“提供方繁忙 · 5 分钟内出现 4 次”。
需要人处理的请求和占用线程的变更仍然优先显示。

## 查看新结果

完成标记代替线程的未读圆点。查看最新轮次后，你的完成标记会消失；其他读者的标记
保留到各自查看该轮次为止。提及次数仍会显示。

位置保留自己的图标，并在行末显示其中最紧急的线程状态。行末的完成标记表示内部有新结果。
无权阅读线程的人不会在私有引用中看到其状态。

队列操作见[消息队列](message-queue.md)。
