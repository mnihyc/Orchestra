# 导航与标签页

导航跟随侧边栏中选中的组织。在手机上，可在导航面板顶部选择组织。

两种密度都保留舒适的列表和表格行高。“紧凑”调整消息间距和头像尺寸。

## 树形与最近

项目标题中的两个按钮切换树形与最近。树形按位置列出项目、文件夹、话题、
线程、文档和聊天；最近跨层级列出相同的可读内容。“打开时间”按你最后一次
访问排序；“活动时间”按任何人（包括智能体）最近更新线程和文档的时间排序。
内容分为今天、昨天、过去 7 天和更早。

行内位置只显示最近的上级，提示中显示完整路径。空间不足以看清位置时会省略它。
时间完整显示：今天用“现在”、分钟或时刻，昨天用时刻，过去一周用星期，更早用日期；
不是今年时带年份。提示中有精确时间。桌面上，悬停或选中时菜单替代整个时间；
手机同时保留时间和菜单，位置优先让出空间。
名称先保留完整宽度，位置只使用剩余空间；只有名称本身超出行内可用空间时才会截短。

起点、筛选文字、显示种类、隐藏已完成和显示已归档同样适用于最近。小型最近
分区的“全部”打开完整列表；项目显示最近时，小型最近分区会隐藏。

行菜单中的“在树中显示”切回树形、展开到该行并短暂标记它。两种视图均支持
方向键和行菜单。每个组织在此设备上分别保留上次使用的视图和最近排序方式。

## 在全部内容中展开查看

在项目菜单选择“在全部内容中打开”，以宽表格查看相同的起点、视图和排序。
树形与最近位于工具栏最前面。最近增加位置、打开时间或活动时间、最后活动或
更新者以及状态列。两种视图均可选择列、排序和筛选。

两种视图分别保留可选列。“最近”默认只显示主要信息。名称列先按内容取宽，位置列使用
剩余空间。长路径从开头省略，保留最近的
位置；提示显示完整路径。额外列放不下时，可通过表格内可见的水平滚动条查看。
平铺的最近行没有树形缩进。

手机上的最近卡片显示名称和状态、最近的上级位置与时间，以及已知的更新者；
勾选可选列后才显示额外的带标签字段。
时间靠右对齐时，位置后不加分隔点。

“选择”显示行复选框，“全部”勾选当前显示的行，“分享”打开已选内容的现有
分享确认界面。支持分享的行可被勾选；更改筛选条件会清空选择。

地址携带视图选项，支持分享链接和返回。链接中的选项会成为列表上次使用的
视图；输入的筛选文字不会被记住。失去读取权限的行会在下次读取时消失。

## 滑出的侧栏

在桌面上，点击侧边图标会将对应视图停靠为侧栏。组织图标打开该组织的导航。
再次点击当前视图的图标可隐藏侧栏；已在组织主页时，再次点击其组织图标可隐藏导航。
点击其他图标可切换视图。标题栏按钮和快捷键也会停靠或隐藏侧栏。
左侧栏快捷键是 Ctrl+\，右侧栏是 Ctrl+Shift+.；Mac 上使用 Command 代替 Ctrl。

将指针移到隐藏侧栏的对应边缘，可让侧栏临时浮在页面上方，不改变页面宽度。

指针离开片刻、打开行或按 Escape 都会关闭临时侧栏，焦点返回原处。
“固定为侧栏”让它重新停靠。减少动态效果时直接显示，不播放滑动动画。
中等宽度下，右侧栏继续使用面板。手机继续使用导航面板和视图面板。

## 固定标签页

在标签页菜单或右键菜单选择“固定”。固定的标签页排在同组最前面，以图钉
代替关闭按钮。可在固定标签页之间拖动排序；越过固定区域边界会固定或取消固定。

“关闭其他”和“全部关闭”保留固定标签页。要关闭固定标签页，使用它自己菜单
中的“关闭”，或先取消固定。重新加载、重置布局和切换布局均保留固定状态。
键盘也能移动标签页：空格拿起，方向键选择位置，Enter 放下，Escape 取消。
