# 跟踪进度并安排状态项目

## 阅读进度

方案可在后台统计文件和字节。计数中显示目前已找到的数量。短横线表示总数未知，
完整统计后的空位置才是零。必须等待计数时，确认按钮显示**等待计数…**。
其他计数可在你检查方案时继续。

复制任务显示阶段、文件、字节、速率和已用时间。带 `~` 的剩余时间是估计值，
带 `≈` 的速率也是估计值。排在其他变更后的任务会说明等待原因。关闭进度视图
后仍可回来查看，不必再创建一次复制。

## 停止或重试

用**停止计数**结束方案测量；取消整个操作要用作业的取消动作。**停止中…**表示
机器仍在结束实际工作。停止较慢时会指出还在等待哪台机器。工作真正停止后，
取消才算完成。

停滞行保留最后的数据，并说明最后变化时间。检查显示的机器和原因。失败的计数或
已停止的可选检查可以重试；重试测量不等于确认方案。作业失败会说明阶段。
重复一个可能已经提交的操作前，先阅读最终结果。

## 安排状态项目

状态栏、线程标题栏和实时行可以显示速度、耗时、令牌、费用、上下文、用量和资源负载。
只显示已报告的数据和明确标注的估计值。提供方限额和模型上下文是不同信息，
可打开相应卡片查看。

在状态项目的右键菜单中隐藏它，或移动到其他位置。选择自定义，或布局 → 状态项目，
打开同一编辑器。选择位置，勾选显示项，通过拖动手柄或 Alt+Up / Alt+Down 排序。
空间放不下的值可从更多状态项目打开。

这些选择属于本设备上的个人布局，不改变代理工作。重置恢复所有三个位置的状态项目默认值；
重置布局会连同其他布局一起恢复。

## 服务器更新期间

重连横幅可显示数据库迁移、已完成步骤、数据库能报告的行数和耗时。未知行数保持未知。
迁移失败会指向服务器更新日志；成功后页面重新连接。运维人员应按升级流程操作并保留日志。
