# 设置中的零

## 零值

零表示关闭某种行为时，字段会显示**关闭**。聚焦字段后可以编辑数字，
输入正数可重新开启该行为。保存仍遵循该设置的权限、继承和锁定规则。

其他零值保留数字含义。修改前可打开设置旁的问号：

- **移除后保留文件：**零表示运行单元移除后即可永久移除其文件，
  不会缩短已经承诺的恢复期限。
- **回收的空闲时间：**零表示不设最低空闲时间。
- **重建等待时间：**零表示立即中断运行中的轮次。
- **位置标签数：**零表示不允许标签。
- **等待轮次完成：**零表示不等待运行中的轮次。
- **文件预览上下文：**零表示只显示引用行，不显示额外上下文。

**恢复为继承值**会移除本地选择，并显示此位置或资源所继承的值。
输入零是另一种选择，不等于恢复继承。

自动保留规则见[存储清理](storage-cleanup.md)。
