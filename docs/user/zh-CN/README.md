# 任务指南

这些文章与产品中的“?”连接，按操作顺序说明工作流。切换语言时，Help 使用同一篇文章的
对应版本，不会在目录中把同一任务列出两次。

每篇用户指南都有与英文版同名的中文文件。文章的 `screens` 前置信息列出它说明的完整路由，
包括详情页和跳转页。文章还需要标题和搜索关键词；屏幕上的问号应打开相关小节。
更新功能时同时更新两种语言，保留相同的小节地址。帮助检查会列出缺少文章的路由、
缺少的译文和失效的链接。
