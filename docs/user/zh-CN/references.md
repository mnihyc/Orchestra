# 引用和访问权限

## 预览和打开

引用指向位置、线程、文档、聊天或文件。悬停或聚焦引用标签可预览；点击或按 Enter
可固定卡片，Escape 关闭。卡片显示你有权读取的标题、位置、描述和最后修改。
引用具体部分时，还会显示对应的文档块、轮次、消息或文本行。

**打开**跳到该部分，**在旁边打开**保留当前工作，**复制引用**得到代理能跟随的文字。
打开和复制都不授予权限。无权读取的引用只保留分享时的名称，不泄露当前信息；
已删除的目标显示**已删除**，打开操作不可用；**复制引用**保留原来存储的地址，名称写作**已删除**。

## 锁定的引用

带锁的灰色引用是真实存在、但你目前无法打开的引用。它保留分享时的名称，
因此可能与当前名称不同。早期没有保存名称的引用只显示种类。目标被删除后显示**已删除**。

锁定卡片不会显示当前描述、所在位置、所有者或文件详情。如果可以申请访问，
表单会预选所需的最低权限。可填写原因，再按**发送**。
系统会请有权审批的所有者处理，但不会在此显示他们的姓名。等待中的申请可以撤回。

同一个人对同一项内容最多有一份待处理申请。仍适用通常的待处理数量限制和申请有效期。
组织外的人只有在该项内容允许向其分享时才能申请。

私聊只属于两位参与者，锁定卡片没有申请表单。参与者可以自行转发或引用愿意分享的内容。
群聊提供**申请加入**，批准后会按所选时长加入为成员。**永久**就是普通的长期成员资格。
临时成员会在成员列表中显示有效期；到期后退出群聊，引用也会恢复灰色。

## 授予访问权限

有权审批的人可以从引用卡片、收件箱或审批页面处理同一份申请。
点选时长，就会在这一项内容上直接授予申请人所需权限。
默认提供一天、七天、三十天和**永久**，管理者可以调整这些选项。
**其他…**打开完整审批，可减少权限、缩小选项或另选到期日期。
**拒绝**可附带说明。

系统会记录决定并通知申请人。临时授权到期后会重新检查权限；没有其他访问来源时，引用恢复灰色。
详见[谁能查看和操作什么](who-can-see-and-do-what.md#requesting-access)。

## 写出引用

可以给代理相对于共享话题的路径、以 `/` 开头的路径，或 `id:` 加对象标识符。
在后面加 `#` 和编号可指定文档块、轮次或消息。放进 Markdown 链接或反引号中。
例如 `[设计](</Web/Design notes#3>)` 指向该文档的第 3 部分。路径包含空格或括号时，
用尖括号包住地址。

消息中的脚本地址和以 `//` 开头的链接会保留为文字。
网页链接请带上 `https://` 或 `http://`。

在人与代理之间交接内容时，优先用**复制引用**。标识符不会随重命名失效。文档中的
块引用保存块的身份，周围块移动后仍指向原块。复制出的编号反映复制时的位置；
阅读当前内容时，以实时引用标签为准。

代理的阅读工具使用相同的名称和编号。以简略深度阅读文档会包含大纲。读取和搜索
返回文字；编辑和发消息返回结构化结果，并说明哪些引用已解析、哪些保留为普通文字。

## 文件和行

文件行菜单、代码视图和附件预览都有**复制引用**。文本可以指向光标所在行或所选内容
的第一行。环境文件引用包含环境及相对路径；附件保留文档或聊天文件的身份。
请复制界面提供的引用，不必猜测另一台机器上的路径。

文件卡片在已知时显示所属对象、路径和大小，文本还可显示短摘录。打开时使用现有
查看器，并重新检查文件权限。预览只供快速查看，不是完整文件副本。

## 描述文档

在文档标题下写描述，帮助人和代理决定读什么。首行显示在共享列表和预览中。
没有描述时，Orch 使用第一段的首行。

代理可以通过 `edit_document` 描述文档；位置允许时，已配置的自动化也可维护描述。
描述帮助查找，不代替正文，也不扩大共享范围。

## 把引用交给代理

复制引用会生成代理可以直接使用的形式，例如
`[发布计划](id:019a0000-0000-7000-8000-000000000001#3)`。
代理也可在 Markdown 链接或反引号中写出共享路径。
没有权限的代理会读到分享时的名称和 **(no access)**，可以告知使用它的人。
代理不会自行申请访问权限。

代理的 **Where you are** 消息会给出其自身对话的路径。
它可读取以前的轮次、按该路径搜索，或下载整份对话交给自己的工具处理，
包括上下文缩短前的轮次。
