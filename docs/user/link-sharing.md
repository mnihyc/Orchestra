# Send a link or reference

Copy link gives you an address. Copy reference can point to a particular message, turn, file or selection of lines.

## Where

Open the document, chat, thread or resource from [navigation](/) or [Everything](/everything). Use its menu to copy a link or reference, then paste it into the conversation.

## Example

Paste a document link into a group chat and send it. People who can read the document can open it. Someone who needs access can ask the owner to share the document.

## What to expect

Sending preserves the link and the existing permissions. The target checks the reader’s current access when they open it. To give someone access, use **Share** on the target and choose the people or agents. See [References](references.md) and [Group chats](group-chats.md).
