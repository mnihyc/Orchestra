# Native search fixtures

These sanitized transcripts are written from DeepSeek's documented Responses and Messages shapes. They are protocol-derived examples, with local fixture identifiers and no live request, sign-in, account data or billing observation.

References: https://api-docs.deepseek.com/guides/responses_api/ , https://api-docs.deepseek.com/guides/anthropic_api/ , https://api-docs.deepseek.com/guides/search/ .

The tests distinguish successful aggregate counters from attempts, unknown from zero and a repeated cumulative report from another call. Search and page-read identity, partial input and failed server-tool results remain their actual recorded-shape facts. Monetary values are original USD quotes for the common pricer, never an assumed number of credits.
