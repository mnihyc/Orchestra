# 阅读管理员消息

## 阅读消息

从[收件箱](notices-and-announcements.md#read-your-inbox)或消息链接打开消息。
标题栏注明消息来自系统还是组织，并显示发件人和发送时间。打开发件人的人员卡片，
可查看你有权阅读的资料。将指针停在时间上可查看准确时刻。

正文保留标题、链接等 Markdown 格式。阅读消息不会再次发送消息，也不会改变
消息所说的工作。使用通常的返回操作可回到先前的列表。

## 消息无法打开时

先查看页面显示的原因。请求失败后可重试；页面要求登录时，请先登录。
消息链接不会授予原本没有的阅读权限。

阅读消息与接收通知是不同的选择。可在
[通知设置](settings-and-usage.md#notifications)中调整 Orch 提醒你的时间和渠道。
