# 文档链接

## 查看链接

在文档的检查面板中打开**链接**，里面有四个标签页。

- **被引用**列出提及本文档的文档、聊天、线程和评论。每行是一个来源，显示它所在的位置和提及次数。展开一行可查看每处提及周围的文字（引用以粗体显示）、作者和时间。
- **引用**按类型和标识的固定顺序列出本文档指向的内容。无权打开的内容显示为带锁的标签，保留作者写下的文字；打开它的卡片可申请权限。
- **相关**按语义、位置和引用列出相关内容，见[相关内容](related-items.md)。
- **关系图**画出文档周围、彼此引用且你有权阅读的内容。

标签页显示目前已读取的行数，后面还有更多时加“+”。提及次数超过统计上限的来源会显示为“至少 100 处提及”之类。没有任何数字、名称或提示会涉及你无权阅读的来源，也不会出现“还有你看不到的更多内容”。

在较窄的栏里，前两个标签页显示为**被引用**和**引用**的短写，完整名称在提示中。

## 跳到提及处

点按一行即可在对应的块、评论、消息或轮次处打开来源。提及多于一页的来源，其列表末尾有**显示更多**。

“链接”中的每个列表都以同样方式增长：**显示更多**始终在末尾，末尾滚动到可见范围时也会加载下一页。按钮保留给键盘使用，也用于重试失败的一页。

## 打开关系图

“关系图”标签页画出文档及一步之内最多四个最近的链接内容，让名称在小视图中清晰可读。点按**打开关系图**可在主区域看到包含其余链接的完整视图。

- **深度**可选一至三步。
- **类型**可把图限定为文档、聊天或线程。
- **语义相关**会用虚线连到语义相近的内容，需要启用语义搜索。
- 点击节点会把它设为中心，按 `Enter` 打开它。
- 名称显示在节点旁的空白处。指向节点可查看完整名称；图中放不下的名称仍保留在“节点”列表中。
- **节点**列表是同一批节点，供键盘和读屏软件使用：方向键移动，`Space` 重新居中，`Enter` 打开。

连线只出现在两个可读的内容之间。如果中间的内容对你隐藏，两侧的内容不会经由它相连。关系图默认最多 150 个节点，并会说明是否省略了节点。

## 关闭标签页

能管理文档的人可以选择它显示哪些标签页：打开文档菜单，选择**链接标签页…**。关闭的标签页对所有读者消失；四个都关闭时整个部分不再提供。这只改变显示，不改变列表、关系图或智能体工具返回的内容。

位置可以为其中的文档设置默认值：在位置设置的“聊天与文档”下选择**链接标签页**。对该设置加锁会决定其下所有文档，此时对话框中的选项为关闭状态。

更改或重置文档的选择会记入文档历史，包含操作者和时间。

## 让智能体查找

智能体可以用 `referenced_by` 代替 `query` 调用 `search_shared`：

```json
{"referenced_by":"docs/Rollout plan.md"}
```

也可以用 `id:` 引用，`kinds`、`path`、`names` 和 `max_results` 可缩小列表。每个结果是智能体有权阅读的文档、聊天或会话，包含路径、提及次数和前几处提及周围的文字（引用放在方括号里）。文档的评论算作该文档的一部分。智能体只能看到自己的可达范围，这可能与你不同。

用 `next_cursor` 和相同的引用、筛选条件继续读取，直到不再返回游标。访问检查预算用尽时，某页可能为空。每次调用都会重新检查智能体当前的共享权限。引擎重启后，若游标被拒绝，请从头读取列表。

## 调整数值

每个数值都是一个设置的默认值，可由位置更改，不是产品的上限。

- **链接每页行数**：**显示更多**之前的行数，默认 20。
- **每个来源的提及数**：一个来源下在**显示更多**之前列出的提及数，默认 5。
- **统计的提及数**：单个来源中统计到多少处提及，再显示为“至少”。默认 100。
- **提及行长度**：每处提及周围显示的字符数，默认 140。
- **链接权限检查数**：每页检查阅读权限的来源数，被大量引用的文档会用游标继续，默认 500。
- **关系图节点数**：关系图最多绘制的节点数，默认 150。
