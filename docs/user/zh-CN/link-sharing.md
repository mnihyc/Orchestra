# 复制链接，并在发送时共享查看权限

“复制链接”生成供人打开的地址；“复制引用”生成代理可以读取的形式，并在可用时定位到准确的消息、轮次、文件或选中行。发送链接时，可以同时提供实际接收者缺少的正常查看权限。

## 在哪里

从[导航](/)或[所有内容](/everything)打开文档、聊天、线程或资源，再使用它的菜单。文件与代码选区可以复制到这些行的链接。引用卡片显示可读取的所属路径；对于你可管理的内容，还显示当前共享摘要和共享操作。人员卡片显示你有权查看的组织角色。

在聊天或线程编辑框中，发送前检查“与 N 位人员和 M 个代理共享查看权限”。人数可打开统一的人员列表，代理列表列出实际接收者。[界面设置](/settings/interface)中有“发送链接时共享查看权限”，所属位置的共享策略也可以决定默认值。

## 示例

在群聊中粘贴文档链接。两位读者已有权限，一位没有。编辑框只会列出缺少权限的人，不会再次向所有人授权。保留开关以连同可授予的查看权限一起发送，或关闭开关只发送引用。编写和预览草稿不会授予权限。

## 操作后会怎样

发送时会重新检查接收者、策略和正常授权选项。接收者有变时需要再次确认；部分完成时会保留已确认的授权，并指出尚未完成的部分。重试前检查剩余操作。受限视图返回的接受回执仍代表写入成功。

未知的接收者访问状态不会被当成缺少权限的证据。群聊选项有时要求成为参与者，编辑框会在发送前说明。人员的正常查看权限和代理允许读取的部分，都沿用各自原有共享控制。无法准确定位的引用保持不可用，不会猜测消息编号。另见[引用](references.md)和[群聊](group-chats.md)。
