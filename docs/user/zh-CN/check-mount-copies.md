# 选择和检查挂载副本

## 选择哪些数据跟随

自有数据、共享存储和同步副本是管理者填写的提示，不会自动复制、同步或改变权限。

移动、分支或切换环境的方案列出每个挂载。按实际可用的选项选择**分离**、**按原样挂载**
或**复制**。默认预选挂载自己的选择，出厂默认是**按原样挂载**。**所有挂载**修改共同选项，每行仍可单独覆盖。
不可用的选择会说明原因。

按原样挂载使用目标位置已有的数据。复制会在工作开始前传输选定数据。目标已有数据时，
选择**替换**或**两者都保留**；后者复制到新位置。确认前，方案说明保留什么以及保留多久。请检查大小、未完成
的计数和所需权限。

## 内容检查

符合条件、以按原样挂载使用的只读同步副本会提供**检查**。它比较来源和目标的内容指纹，
只在你要求时读取两边，不同步或修改文件。新结果显示**内容相同**或**有差异**及检查时间。

挂载行先显示检查来源，再显示检查目标的进度。用**停止检查**结束读取；停止需要等待
实际机器工作结束。已停止或失败的检查没有比较结果。重试会发起一次新的检查。

结果只反映显示时间的观测，之后文件变化可能使它过时。方案选择变化会清除旧观测。
指纹不同不会替你改变挂载选择或授予权限。没有检查按钮时，该方案或挂载不提供这种比较。

## 同时检查工具服务器

同一方案列出 MCP 服务器会保留、失去原机器导入、因何不可用，或变为新可用。
复制挂载不会复制机器私有的已导入服务器及其秘密。开始操作前请同时阅读两份列表。
