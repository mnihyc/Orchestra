# 设置与消耗

设置属于其控制的位置或资源。布局和通知路线属于个人。用量记录运行情况和提供方报告，
Orch 测量消耗，不向团队计费。

## 继承设置

设置页显示本地选择、继承选择、有效结果及来源。值沿组织、项目文件夹到话题和对象解析。
资源也有所属位置和本地设置。重置移除本地覆盖，重新遵循继承。

键旁问号说明用途、示例、允许值和效果；扩展字段由描述符提供帮助。禁用选择说明权限、
策略或能力原因，缺失值不会被编造成事实。

### 锁

支持锁定的设置可约束下级。页面显示锁来源及本地不可覆盖的原因。管理下级不能解除
上级锁；明确确认的管理员越权会记录，也不能越过更高锁或本机策略。

## 模型选择

提供方模型条目决定可用速度、访问计划和上下文，先由管理者开放实际报价。线程独立
选择当前值，不把允许的最大值当成正在用的值。继承遵循位置默认，本地覆盖会显示生效来源。
访问选择和用量报表使用与提供方模型编辑器相同的计划名称。**无**表示不使用访问计划；
提供方提供并开放时，**标准**本身是一个计划。

模型、推理强度和参数从下一轮生效，引导只加文字，不改当前轮参数。要提前应用，停止、
修改再继续。套餐窗口和快速模式冷却按实际报告显示，未知保持未知，管理者填写的值标明来源。

## 子代理

代理程序在本线程提供方用量和环境限制内运行子代理。`agents.subagents_at_once` 接受 1–64，
初始 8；`agents.subagent_depth` 接受 1–5，初始 1。深度 1 允许主代理创建子代理，
子代理不能再创建。参数面板显示有效值、来源和何时生效，不支持会说明原因。

例如组织设同时 4 个且深度 1，层级上最小值生效。文件夹可减为 2，线程设 8 不能放宽
组织的 4。重置回到其余继承边界或初始值，拒绝创建按程序报告显示。

## 代理历史

Orch 保存线程对话。代理程序也在提供方的主目录中保存自己的会话文件，用于原样恢复。
**代理历史保留天数**（`retention.agent_history_idle_days`）默认在线程空闲 **7 天**后
移除这份缓存。设为**关闭**（`0`）可停止自动移除。设置从系统、组织、项目、话题继承到
线程，上级可以锁定。

正在运行的轮次、排队或暂存的消息、待答复的审批或计划，以及延续对话仍依赖的原生历史
都会阻止移除。已归档和最近删除的线程也计算空闲时间。个人自己的代理主目录由其所有者管理。

下一轮按位置的携带、摘要或无历史选择建立新会话。携带优先使用程序的原生导入，
否则提供最近轮次和完整对话文件。摘要使用已配置的摘要；不可用时提供最近轮次的简略文字，
同样附上完整文件。时间线记录移除，以及对话如何进入新会话。

## 常驻指令

常驻指令是继承设置，送入会话并在下一轮刷新。目录指令文件是程序读取的工作区文件，
可继承父级且可为空。修改它们不授予项目配置、钩子、插件或 MCP 服务器信任，
信任是独立环境选择。

## 变量和秘密

环境变量属于环境并从允许来源继承，表单区分本地值和有效结果。秘密保存后只交给需要的
工作，读页面不能看到值。用明确的替换或删除动作，不把遮蔽占位符当新秘密重新提交。
提供方凭据留在提供方运行时。

## 通知

设置 → 通知的例外列出单独选择级别的位置。可在此修改或设默认，跟随最近上级来源；
撤销恢复原选择。无权再看位置会省略，列表按页读取。

组织、部门、项目、文件夹、话题或线程铃铛设置本位置级别，关闭直接写在铃铛上，
菜单以勾选和背景指出当前值。默认不包含自己的选择。聊天可选全部、提及、关闭；
文档可选全部讨论或自己参与的讨论。展开列表解释级别。免打扰时间使用旁边时区。

收件箱是 Orch 内记录。向外只用你开启的邮件、机器人、Webhook 或本设备推送。
推送还需本浏览器权限及订阅，别的设备就绪不代表本设备就绪。机器人按所给代码关联。
可选择未读工作何时发送及频率。暂停推迟外发但保留收件箱。按位置分组的已读与撤销
检查当前权限。失败或不确定投递会显示原因。通知摘录不是离线私有内容缓存。

收件箱默认保留 90 天，已读也相同，系统管理员可改。失败投递保留一个月供重试，
成功投递保留一周。组织或系统管理者配置渠道和模板。项目目的地只收规则允许的工作，
私有后代和人类聊天不自动外流。本版本不提供每周免打扰计划或离线内容缓存。

## 用量

线程用量显示归属其工作的令牌、额度及提供方报告的可用量。个人、位置总量和详细报表
权限不同，隐藏线程不在报告泄露标题、轮次标识符或文字。

提供方事实不同。OpenRouter 可报告密钥限额、预算和重置、免费模型每日请求以及管理密钥
可见的账号余额；其他上游可能无余额，保持未知。没有直接费用时用费率卡或目录估计额度，
保留来源。目录刷新失败保留上个有效版本，不把所有模型估成零。

### 套餐窗口与预测

提供方的用量页在汇总数字下显示**套餐**。**本窗口**用实线表示已测用量，用虚线按当前速度
延伸到重置或达到限额的时间。短于一天的窗口采用最近一小时的速度，其他窗口采用最近一天。
计算不会跨过窗口开始或最近一次提前重置。两种窗口分别需要至少 15 分钟、6 小时的读数；
最新读数超过两小时就不再预测。

**历史**按所选**间隔**显示新增用量，选择小时就显示逐小时柱状图。窗口重置不会扣减
已用量。一天及以上的窗口有**均匀使用**参考线；警示色柱表示曾达到限额的时间段。重置标记
可打开审计记录，说明重置是在 Orch 中使用、在其他地方使用，还是由提供方提前开始新窗口。
此记录不会发送通知。
同一时间段内的多次重置合并为带数量的标记，链接打开最新一条记录。窗口较多时，
用**下一页窗口**和**上一页窗口**翻页；历史摘要仍统计所选的完整时间范围。

有周期的限额按本周期开始以来的平均速度预测。累计限额和同时运行轮数没有预测。
预测反映已观察到的速度，后续工作可能改变结果。

### 请求

轮数数字下也显示已完成且结果已知的请求数。在**随时间变化**中选择**请求**可查看曲线。
一轮可能包含多个请求。请求标签页逐条显示调用及其测量结果。

### 令牌种类

选择**令牌**，再按**令牌种类**拆分，可查看新输入、缓存读取、缓存写入、输出和推理。
缓存读取和写入属于输入，推理属于输出；每个令牌只计一次。**缓存命中**表示输入中从缓存
读取的比例。

### 上下文装了什么，以及一轮用了哪些令牌

标题模型旁的圆环显示代理最后请求占模型窗口多少：低于 60% 绿色，至 85% 琥珀色，
更高为红色，并标出程序缩短对话的位置。例如 142k / 200k、71%、90% 时缩短。
只有程序报告请求大小才显示。

点击可看各部分令牌和比例、空闲空间、缩短保留量、表格数字及最后缩短释放量。
各部分说明计数来源：

- 程序计数或估计：程序报告各部分，面板标明每个数字的来源。
- Orch 估计：程序报告总量但没有划分时，Orch 根据发送或观察到的指令、工具、对话、
  调用、文件和图片估计。文本到令牌的换算使用模型声明的估计数据，其余属于程序自己的
  上下文。总和超过报告值时会按比例缩小并说明；没有观察到的数据保持未知。

轮次页脚令牌条包含新输入、缓存读取、缓存写入、输出及推理、子代理，悬停有数量和命中率。
点击展开按模型、子代理、独立报告的权限审阅器、已知费率计费和结束上下文详情。
线程用量汇总所有轮次，画出上下文和缩短事件、命中率、子代理占比及可导出 CSV 的轮次表。
未报告时不显示环和条，说明程序缺少什么。

### 内置程序

#### Codex

Codex 报告请求大小。Orch 估计可观察的部分，并标明其余程序上下文。

#### Claude Code

Claude Code 报告上下文的划分。轮次结束后的估计和轮间请求的计数均标明来源。

#### DeepSeek Harness

上下文视图使用程序报告的数字，并标明 Orch 的估计。无法报告或估计的数字保持不可用。

## 限额

限额在作用域和周期内约束令牌、额度或并发轮次。阅读覆盖、用量及重置；较窄范围仍遵守
更广限额。管理员也不豁免。限制工作时说明控制的额度或窗口和下一步，输入仍留在队列。

有例外权限的人可读当前用量后，明确确认一个轮次并记录其姓名。代理和自动输入不能给
自己例外。供应商重置是独立动作，只由管理者在浏览器读过将消耗的重置后确认。

## 令牌和安全

安全页管理登录和 API 令牌。令牌权限和位置限制请求，不能携带仅浏览器的系统管理员权限。
在此拒绝只阻止当前范围，在此全部移除按确认说明的更广范围执行。暂停按范围结束访问，
可恢复且不自动转移所有权。

丢失验证器或登录方法时，安装管理员可按运维流程给一次性重置链接。提供方令牌和续期
独立于 Orch 账号。受管运行时可为续期提前启动，默认有效值为五天时提前五天。

## 组织管理

组织管理者在自己的权限内管理成员、角色、组、邀请、标签和默认值，部门也相同。
移动成员会预览域、角色和访问变化，不移动其拥有内容。创建团队组织需要安装策略要求的邀请。

可用某人在此的活动调查其工作及代理代办。按权限只读检查保留删除内容，无需先恢复。
审计不记录每次普通读取、文件内容、终端键入或整页内容。

## 布局

布局保存视图、面板和屏幕偏好。树排序沿用组织默认直到你自选；折叠、最近位置和上次位置
属于个人状态。主题和颜色不改变别人，选择器提供列出调色板及自定义颜色。

## 导出和管理

个人导出列出账号可读的作业和下载。打开可看进度和结果，排队或失败不代表文件就绪。
个人资料和你的页面控制公开介绍，安全和令牌控制账号访问。见[管理账号](account-and-profile.md)。

管理包含系统设置和有权访问的系统列表。需要时先用现有管理员身份开关，分节权限仍检查。
资源所属位置、所有者、位置设置和系统管理是不同权限来源。
