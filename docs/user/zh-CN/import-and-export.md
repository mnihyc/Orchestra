# 导入和导出

## 导入

在某个位置的菜单或“文档”视图中选择 **导入…**。拖放文件，或选择文件、文件夹
或压缩包。Orch 根据清单识别包。Markdown、HTML、Word 和文本文件可以与本地图片
和文件一起导入。文件夹或压缩包会保留文件夹结构。文档和文件夹名称末尾的
Notion 导出 ID 会被去掉；重名时添加编号，链接仍按原始文件路径解析。

选择目标位置，需要时再选择文档文件夹。**浏览文件夹**可以逐页查看该位置的
文件夹；搜索也可以找到单独共享的文件夹。导入包时，可以在目标位置内新建包的根
位置，也可以将其内容放入目标位置。目标位置的权限和设置适用于导入。

## 预览导入

预览不会创建内容。检查“内容”“人员”“冲突”和“不会导入”标签页。为每个
项目选择操作并打开预览。将来源人员匹配到账号，或保留为“导入的人员”标签。
查找账号时至少输入两个字符。跳过位置或文件夹时，也会跳过其中的内容。
管理员可以将内容归属于匹配的账号；否则内容归属于导入者，并保留原作者姓名。
评论、版本和共享分别设置。只有包中包含共享设置且你有管理权限时才能恢复共享。
内容筛选和“冲突”显示当前页中匹配的项目。通过 **下一页** 检查后续项目；
切换标签页会保留已检查的计划。

摘要显示项目总数，以及来源字节数与字节限额的比较。项目数量超出限额时，阻碍项
会显示计入的数量和限额，并说明开始导入前需要更改什么。再次导入可以更新之前
导入的内容；预览会显示冲突和可选操作。

## 查看和撤销导入

开始导入后可以查看进度。关闭对话框后任务继续运行，状态栏会显示进度。如果需要
通知，请勾选 **完成时通知我**；通知会在 Orch 打开时显示。取消或失败的导入会保留已创建的内容，报告会说明
结果。

列表每次显示一页。**下一页**替换当前页；**返回第一页**回到开头。

报告列出每个结果，可以下载为 JSON 或 CSV。请在支持直接保存文件的浏览器中选择
保存位置，报告会逐段写入该文件。不支持直接保存的浏览器会说明下载暂不可用的原因。
**你的导入**保留你的报告。**撤销导入**
会先显示已报告的影响和可以恢复的截止时间。检查完成后，确认计划即可开始撤销。
如果无法检查受影响的内容或其访问权限，撤销暂不可用，计划会说明原因。

## 导出包

打开某个位置的 **导出…** 操作，选择 **Orch 包（可再次导入）**。选择要包含的
内容，检查计划后开始导出。默认包含文件和评论，可以选择是否包含早期版本。包可以
导入到另一个位置。文档包含 JSON 记录和便于阅读的 Markdown、HTML 副本，
本地文件放在副本旁边。

原生智能体会话、工作区、密钥、用量与审计、个人状态和审批不会恢复。网页图片保留
为链接。导入预览和报告会列出这些内容及其他损失。
