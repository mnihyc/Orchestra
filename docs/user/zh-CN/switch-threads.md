# 切换对话

## 批量切换

选择提供方、模型和可选的代理配置。确认前查看每个对话的计划。
受阻的对话留在原处，其他对话可以继续切换。

在提供方页面，全选使用它当前绑定的对话。Orch 只切换你有权切换的对话，
其余只显示数量。取消勾选一个对话后，计划使用明确选中的列表。
看到隐藏对话的数量不会授予修改权限。

代理配置和提供方模型也有**切换其线程…**。模型的操作只选择该提供方中的这个模型。来源关闭时仍可切换出去。停用会保留原有绑定，删除对话框链接到这个独立操作。

在选择框中输入只搜索现有选项。确认目标后才读取目标的事实。
关闭的提供方或环境不能作为新目标。选择其他目标，或先启用它。

计划显示如何传递历史、移动哪些文件。正在运行的工作遵循所选的等待或中断方式。
批次有统一的进度和结果，每个对话也有自己的结果。取消在不可撤销的步骤前停止工作。

## 批量大小

系统管理员可设置**每批对话数**（`switch.batch_threads`），默认 200。
需要更大的切换批次时可以调整。**批量大小**（`switch.batch_parallel`）
另行控制同时运行的任务数。

选择超过当前值时，Orch 会显示对应设置的名称，不会悄悄丢弃所选对话。
