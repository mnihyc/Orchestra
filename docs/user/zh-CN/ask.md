# 就工作内容提问

“问一问”是你的个人只读对话，可以围绕当前页面和你在一个组织中有权读取的工作内容提问。回答会标注来源。

## 打开问一问

在左侧栏的“帮助”上方选择**就此页面提问**。手机上使用查找器旁的同名按钮。也可以按 **Shift+F1**；“帮助”的快捷键编辑器可以更改此按键。

默认在右侧停靠。**弹出窗口**会把同一段对话和草稿移到浮动窗口。拖动标题移动窗口，拖动右下角手柄调整大小。也可以聚焦相应手柄后按方向键；按住 Shift 可以移动更远。**最大化**、**还原大小**和**停靠**用于调整位置。窗口的大小和位置按账号保存在当前设备上。

## 输入问题

输入问题后按 **Enter** 发送，**Shift+Enter** 换行。使用输入法确认文字时不会发送问题。

点击回形针、粘贴或拖入文件即可添加附件。原有附件标签会显示进度，并提供移除和重试。上传未完成时不能发送。输入 **@** 或选择**引用资源**，可以查找此对话所在组织中你有权读取的文档、会话、聊天或资源。选中引用只会加入草稿，不会立即发送。

模型标签列出当前根组织的“问一问模型”设置（`ask.models`）中可用的条目。**默认 · 模型名**跟随此有序列表中的第一个可用条目。你可以通过与普通会话相同的模型与推理强度控件选择其他条目，并指定个人使用的推理强度。未另选时使用模型的默认推理强度。模型没有声明推理强度时，不会出现相应选项。其他已声明选项仍受提供方约束。你的个人选择及其参数会随对话保存。

问一问在“设置 → 自动化”中使用自己的模型策略列表。在系统范围，有编辑权限的人可以添加、移除已启用的 API 模型，或将条目上移、下移。条目只保存提供方和模型。在组织范围，列表继承自上层；编辑者只能移除条目以缩小范围，不能添加或调整顺序，并保留上层的顺序。推理强度和其他参数属于模型标签中的个人选择。仅提供订阅登录的提供方不能用作问一问模型。每一轮仍受组织策略和用量上限约束。

未配置列表、列表为空或没有可用条目时（包括模型策略排除了所有条目），面板会说明原因，并隐藏消息输入区。只有当前有权编辑设置的人才能看到前往该设置的链接。其他人会保留原因说明，可请组织管理员配置可用模型。

回答进行时，**停止**会结束这一轮，之后可以继续提问。发送结果未确认时会保留草稿；重试未改动的问题会沿用同一个输入标识，避免重复发送。停靠或弹出窗口会保留草稿和待处理附件。与普通会话一样，停止输入片刻后会自动保存草稿；小标记会显示正在保存或保存失败。

发送、停止或准备草稿失败时，**重试**会重复失败的操作。重试发送会保留原来的问题和请求标识；即使你随后修改了草稿，后续修改也会保持未发送状态。重试准备草稿不会发送问题。

## 阅读回答和来源

回答会随生成逐步显示。向上阅读较早的消息后，视图不会再把你拉回底部。**加载更早的消息**可以读取更早的记录。

来源使用原有的链接标签。悬停、聚焦或点击标签，可以查看当前有权读取的来源；**打开**和**在旁边打开**会前往来源。引用本身不授予权限。已经无权读取的来源不会泄露当前详情。

悬停或聚焦回答即可使用**复制回答**和**重新回答**，触屏上也能使用。重新回答会基于前一条问题，并按当前设置和权限再问一遍。如果发送结果尚未确认，再次重试同一回答会保留相同的请求标识和原始上下文。确认成功后，再次主动选择重新回答才会生成新的回答。


## 较长的对话

对话接近所选模型的上下文窗口时，Ask 会使用同一个模型归纳最早的消息。**较早的消息已归纳**是一条可展开的可见消息。原消息仍保留在历史中；后续提问会发送该归纳和较新的消息。归纳再次使用前，会重新检查已变更或不再可读的来源。

归纳计入你的 Ask 用量，由这段对话当前的付费人承担，并遵守现有额度。它不会另选归纳模型。

对话的上限就是所选模型的上下文窗口，按该模型的实测估算以令牌计。除回答可能占用的空间 `ask.max_output_tokens`（默认 4096）外，不会预先留出任何空间：请求按窗口减去这个值来安排。管理员可以在系统或组织层设置它和可选的 `ask.context_tokens`，取其中最小值。未设置上下文值时，使用模型自身的窗口；设置后可以仅降低 Ask 的窗口，不影响普通线程。任何一组设置都不会让所有问题都失败：窗口不超过回答上限两倍时，回答占其一半，其余留给对话。没有按消息条数截断的窗口，也没有按字节计的限制。

历史放不下时，会按上文归纳最早的消息。来源到达时，如果窗口剩下的空间比它小，就会被截短到放得下的长度，并以一行说明已被截短及完整来源所在，回答由此继续；打开该链接，或请求更窄的部分，即可读取更多。来源再次检查时的长度与首次交给模型时相同。

未记录窗口的模型不会被当作小窗口：Ask 会原样发送对话。如果提供方回答请求超出了模型的上下文，Ask 会得知窗口小于该请求，先归纳最早的消息再重新提问；补全模型的上下文容量可避免这一轮额外请求。如果连归纳也放不下，Ask 会说明对话超出了所选模型的容量：请新建对话，或选择**保留为线程**。历史内容不会被悄悄丢弃。

读取工具内部的数字同样是设置，默认值与以往相同：`ask.docs_hits`（每次搜索 5 个指南页面）、`ask.docs_excerpt_tokens`（每页 1,000 令牌）、`ask.max_operations`（每次搜索目录 20 个操作）和 `ask.max_links`（一次读取保留 50 个链接）。每个问题的步骤数和工具数分别是 `ask.max_steps`（16）和 `ask.max_tools`（32）。

Ask 无法受理问题时，消息会用自己的话说明原因：模型或提供方不被允许或尚未就绪、已达用量上限，或无法以你的身份打开该组织。无论“以管理员身份”开关如何，Ask 都以你在组织中的本人身份回答；不是某组织成员的管理员可以查看该组织的对话，但不能在其中提问。

## 每段对话只属于一个组织

**范围**标签显示这段对话固定所属的根组织，包括其下的部门和项目。这个边界永远不变。问一问只读取你在该范围内有权读取的内容。由其他组织分享进来的资源只按分享的级别提供，不会开放对方组织中无关的工作内容。

可以询问哪些提供方或智能体配置共享给了一个可读的话题或会话。此类结果只显示该位置的工作共享及其模型、推理强度限制。在其他位置管理资源的权限不会扩大这些共享；资源的私有归属、运行时、用量和无关工作不会进入回答。

当前页面会作为上下文。打开另一个根组织的页面时，会新建或恢复那个组织的对话。在收件箱、帮助等不属于任何组织的页面上，会先使用左栏选中的组织；未选中时才使用你的个人组织。要询问另一个根组织中的来源，请打开那个组织的页面，在相应对话中提问。

**历史记录**按组织列出你的对话。恢复对话时会保留原来的边界。如果它的组织与当前页面不同，就不会传入这个无关页面。恢复后的每一轮都会重新检查较早的工具结果，在范围内重新读取当前页面，并按当前设置确定模型和付费方。即使某个来源已不可用，你自己的历史回答仍会保留在记录中。

对话通常存放在你的个人组织里。关闭个人组织功能时，会存放在其根组织中的未列出位置。无论存在哪里，访问、管理员查看和保留期限都由对话的根组织约束。你失去该组织的访问权限后，这些对话也会对你关闭。

## 隐私、费用和保留期限

问一问使用你的权限读取，不作修改。它可以搜索、打开有权读取的来源、读取其历史，并查阅随产品提供的用户指南。它不会向他人授予访问权限，也不会向正在工作的会话发出指令。

对话所属根组织的管理员可以查看并导出此对话。管理员查看是只读的，不能发送、重新回答、停止或保留别人的对话。先开启原有的管理员身份开关，再打开**历史记录**，选择**查看此组织的对话**，然后打开一行。**导出对话**会将有权读取的对话下载为 JSON。

通常由提问的你付费；生效的“问一问”设置也可以指定使用设置者的提供方权限。面板会显示实际付费方。组织中适用的个人和共享用量上限仍然生效。

默认在**最后一条消息发出 30 天后永久删除**。实际期限会限制在根组织管理员设置的最短和最长期限之间；面板显示生效期限及到期时间。到期后没有第二个恢复窗口。

在到期前选择**保留为会话**，可以在同一根组织中创建永久保留的私有会话。检查目标话题，或使用有权限的默认位置。原对话会标记为已保留；新会话遵循普通会话的访问与保留规则。之后更换代理时使用普通会话控件。

**导出对话**和**保留为会话**暂不可用时仍可聚焦，悬停或键盘聚焦会显示各自的原因。
尚未创建对话、正在读取、读取失败和操作被拒绝会分别说明。保留需要等待回答完成，
管理员只读查看时也不能保留；这两种状态下，有权导出的人仍可导出。

## 开始永久问答会话

在话题中打开**新会话**，或选择输入框下方的**更改**，然后选择**开始只读问答**。检查模型选择和新会话的访问权限：**私有**或**使用此话题的默认访问权限**。可以同时输入首个问题。此程序无需环境或代理配置。

永久问答会话使用普通时间线、文件、已保存草稿和**停止**控件。模型选择器显示已保存的偏好。可以为下一条问题选择另一可用 API 模型，或选择**默认**，在下一条问题被接受时重置偏好。每位提问者当前的权限、模型访问权限和用量上限仍然生效。

## 本部署的地址

从此 Orch 部署的另一个已声明地址复制来的链接，会在你当前使用的地址中打开。配置了公共地址时，**复制链接**会使用该地址。文档块、轮次、消息或文件行选择会继续保留在链接中。

部署管理员可以在 `[system]` 中的 `public_url` 旁配置 `alternate_urls`，声明其他浏览器来源地址。其他 IP 地址及端口必须明确声明。路径相同的其他网站、相似域名或未声明的地址仍是外部链接；识别链接不会分享目标，也不会把你的凭据发给那个网站。

## 问一问、帮助和旁路会话

**帮助**是随此版本提供的书面指南，不调用模型。**问一问**会调用模型，结合指南和你有权读取的工作内容回答问题。**旁路会话**则使用正在工作的会话的代理及其已确认的只读方式，另开一段对话。想询问该代理当前的工作时可以使用它，参阅[关注正在运行的线程](running-thread-views.md)。
