# 工作与协作

话题把相关的会话、一个聊天和文档放在一起。会话是与一个智能体的一段对话，有自己的标题、输入、模型选择和历史。能打开同一个会话的人继续同一项工作，使用会话所显示的权限。

## 与人和智能体交谈

聊天和智能体的输入框有不同的接收者。讨论一项更改请在聊天里进行。想给智能体布置工作，就发给会话的智能体。提及一个人只会通知他。

- **转发**会把你选中的消息和文件发给人、聊天或另一个智能体。会先显示将要送出的内容。它绝不会悄悄共享整个位置。
- **引导。** 智能体正在运行一轮时，如果智能体程序允许引导，你发送的消息可以引导它。消息保持它的位置，只显示一次。
- **设置在下一轮生效。** 模型、推理强度和其他设置从下一轮开始适用；引导消息不会在一轮进行到一半时改变它们。要更快应用其中一项，请按**停止**，更改设置，再用新的输入继续。
- **停止**会结束你看到的这一轮，并保留等待中的输入，这样队列里的下一条输入不会立刻重新开始工作。**继续**会放开被保留的队列。

如果一次取消没能结束智能体程序的某个进程，会话会这样说明。在假定它的影响已经结束之前，请先查看正在运行的工作或终端。

## 阅读对话

对话显示智能体的消息、思考、计划和工具。工具步骤可以展开，看到它的命令或文件更改、结果，以及智能体程序最初的调用。很大的输出会在行内保留有用的部分，并附一个指向完整内容的链接。Orch 不认识的工具会保留它的原始数据。子智能体步骤会写出它的角色、请求和状态。

- 使用**在对话中查找**，或跨多轮选择内容来复制、引用或转发。
- 视图可以显示对话、工作或更多细节。
- 保存的快照，或对已移除内容的查看，是只读的。
- 实时连接状态会说明什么时候新的操作必须等待。重新连接后，页面会从原来的位置接上；你不必重新创建会话。

## 决定请求

待处理的请求会显示将会发生什么，以及智能体程序给出的选项。

- 命令或文件更改可以提供**允许一次**、更宽的许可、**拒绝**或**中止**。
- 向人提出的问题要求逐个回答。先回答必答的问题，才能使用**发送答复**。
- 来自 MCP 服务器的表单会显示它的字段，并按该请求允许的方式让你接受、拒绝或取消。
- 端口或能力的请求有自己的方案和影响。确认之前请先阅读。

只有拥有该请求所需权限的人才能决定它。查看者可以阅读卡片，并看到自己为什么无法回答。失去连接的页面会等待连接。如果同事先回答了，卡片会显示那个结果，你晚到的回答不会覆盖它。

## 共享一个对象或位置

**共享**会显示这个人或智能体将收到什么。会话或文档是一个对象。话题、文件夹、项目或组织可以只共享这个位置本身，也可以连同它的内容一起共享。这两种范围不同，而且位置的默认值适用于以后创建的内容。位置上的角色会涉及它里面的东西，包括文件夹。授予一份文档并不授予它的上级。

- 持有者可以在位置允许的地方共享他们所持有的权限。没有人能给出比自己所持有的更多。
- 每个条目记录谁授予的和任何结束时间。授予者可以收回自己的授权。
- 管理权限页、继承、**私有**、锁定和默认值，需要单独的管理权限。**私有**在应用之前会预览哪些人将失去访问权限。
- 使用**以某人身份查看**和条目的来源来理解访问权限。管理员的越权要经过确认，并在页面和审计记录里留下标记。它不能克服上层的锁定、提供方仅限所有者的策略，或机器自己的策略。

同一个字段指明谁获得访问权限：一个人、你创建的群组、某个位置上的角色、能看到某个位置的所有人，或一个组织的成员。最后两个不同。输入定位符，例如 `dep2.sub3 developer`、`every dep2.sub3`、`members of dep2`、`dep2 reviewers` 或 `@alice`。只有一个匹配时，按 Enter 会变成它的名称和位置。如果有多个位置匹配，请选择你指的完整地址。你看不到的位置不会被提供。

群组可以包含其他群组和角色，它们当前的成员获得授予该群组的权限。出现循环，或嵌套超过五层的群组，会被拒绝。重命名位置会保留它的条目。

## 给智能体团队知识

把文档、聊天、会话或位置共享给应该使用它的智能体。每个区域各自选择：

| 区域 | 选项 |
|---|---|
| 文档 | **可查看**、**可编辑**、**可管理** |
| 聊天 | **可查看**、**可发布**、**可管理** |
| 会话 | **可查看**、**可发送**、**可管理** |

**创建分叉**和**归档**是**高级**下面单独的行，**管理**包含它们。下面的私有位置不会包含在内，除非你单独共享它们。智能体只收到每个授予者现在能共享的内容。当一位授予者失去一项权限，那份贡献就停止，其他的保持不变。

管理让智能体能做什么：

- **文档。** 删除、移动和恢复文档。创建文件夹、复制、移动和恢复会立即执行，不需要确认。只有删除文档需要预览和确认。
- **聊天。** 删除任何人的消息。
- **会话。** 归档、取消归档、分叉和删除。对会话或聊天的每一个动作，智能体先得到一份不做任何更改的完整预览，并带上确认词重复它的参数才会执行。已经改变或过期的方案不会执行任何事。删除会话会处理正在运行的工作，并保留正常的恢复期。
- **分叉**使用源会话的历史、绑定和工作区。它的第一个所有者是授予者，并且一开始没有给智能体的初始授权。授予者必须满足目的地和绑定的常规要求。

智能体从不拥有任何东西，也从不管理位置、权限页或授权。

只共享不会发送任何指示，也不会开始任何一轮。任何能在接收会话里**参与**的人，都可以使用它的全部权限指挥它的智能体。给会话的查看者的**阅读**是另一个单独的选择，默认不勾选。把文档给智能体，不会给它的查看者任何**编辑**或**管理**权限。

智能体的编辑和消息会署上该智能体的名字。它用来发送消息的工具把聊天或会话作为目标，可以附带文件。聊天消息对人可见。发给会话的消息遵循接收话题的投递规则。要唤醒空闲的会话，每次发送都必须明确这样指定，并且话题必须允许唤醒空闲会话（默认开启）。每个发送的会话每小时有自己的限额：12 条公告和 60 条发给单个会话的消息。限额为零则禁止那一类发送。回答会说明消息是已发布、已排队还是已送达。公告和里程碑会记录在对话里，并发给所选的受众。来自另一个会话的推理绝不会作为普通对话共享。

读取和搜索工具返回一份文本答案，会更改东西的工具返回结构化的结果。智能体可以跟随的说明、大纲和链接见[引用](references.md)，带版本的指令和脚本见[技能](use-skills.md)，受众和投递见[公告](notices-and-announcements.md#send-an-announcement)。

## 一起写文档

文档是位于位置或会话旁边、由块组成的一页内容。可以与另一个人一起编辑同一页，添加评论、提及同事或附加文件。如果两个人同时修改同一个块，冲突会保留下来由你解决，第二次编辑不会覆盖第一次。历史会写出人和智能体的名字，并让你经过检查后恢复较早的版本。

- 位置可以选择一份文档作为**先阅读**。
- 导入和复制会保留块的结构。**大纲**帮你在页面中移动。
- **导出**提供 JSON、Markdown、HTML、Typst 源文件和 PDF，并显示真正可用的选项。
- 选择播放时，视频或音频片段的地址会在你的浏览器里加载。

**浏览文件夹**会打开位置旁边的文档。文档文件夹里放文档和其他文档文件夹；它不是项目文件夹，项目文件夹还可以放话题和会话。共享的文档文件夹可以直接打开，而不会授予对它周围项目的访问权限。它的菜单里有**复制链接**和**权限明细**。

## 安排屏幕并编辑文件

**布局**选择视图以及它们摆放的位置：对话、文件、终端、用量、浏览器、显示桌面或其他视图。这是你自己的屏幕。**智能体如何运行**选择智能体程序、工具和凭据存放的位置。这两者互相独立。

- **左侧栏。** 左边的活动栏选择**导航**或**资源**。再次按已选的条目会隐藏或显示这个栏。
- **会话的右侧栏**把它的视图分组为**对话**、**团队**、**代码**、**环境**和**智能体**。每个组都有可以打开、折叠、隐藏和调整大小的部分。**浏览器功能**和**显示桌面功能**在这里列出它们的条目，并在主区域打开查看器。**终端**在下方打开，也可以从状态栏打开。状态栏会写出环境、分支、更改的行数，以及任何需要注意的限制。
- **空的终端**只显示一种状态，原因写在**打开新的终端** 旁边。环境的事实用简短的行显示，点开它们的问题会打开关于网络、凭据和服务器的完整说明。
- **查找。** 页面仍在加载时，**Ctrl+K**（Mac 上是 **Command+K**）就能打开查找。页面出现后，你输入的文字仍然保留。

通过查找器里的**打开视图…**或**添加视图**，可以连同它的组一起显示一个部分。**视图**列表显示每个名称及其所属的组。**资源列表**会打开各类资源的导航。拖动部分的标题，或使用**移至**，把它放到别处。**恢复默认布局**会恢复标准框架，并把主标签页集中到一个组里；它们的内容和草稿保留。

在**显示屏**中选择**连接 VNC 服务**，即可观看本机上已提供 VNC 服务的虚拟机或应用。输入回环端口，如果服务要求验证，再输入 VNC 密码。具有查看权限的人使用自己的 Orch 账号观看。关闭显示屏会保留原有服务。若已连接的 Linux 机器上有可访问的本地 X11 会话并已安装 x11vnc，可以选择**共享这台机器的桌面**。机器已委托 `environment.vnc` 时，其策略管理者可以直接在显示屏页签中选择**启用 VNC**。

空终端显示单个当前状态及新建终端权限说明。环境信息用短行，问号打开网络、凭据和服务器
完整说明。页面仍在加载时 Ctrl+K（Mac 为 Command+K）已可查找，输入在加载后保留。

- 标签页和导航行在需要更多空间时会换行。右侧栏的组名保留在它们的图标旁边。
- 在手机上，各个组共用一行图标。聚焦或按住图标可以读到它的名称；已打开的组会被标记。
- 主标签页和底部标签页有一个列出每个打开标签页的列表，带有未保存标记和**关闭**。
- 组织的图标会从另一个页面打开它的主页和**导航**。当这个主页在视野里时再次按它，会显示或隐藏这个面板。
- 空间较小时，同样的组会作为面板在它们的控件下面打开。再次按已选的组可以关闭它的面板。
- 位置的设置、你的个人设置、**管理**、**帮助**和**用量**把它们的分区导航保留在页面里。全局的**导航**面板保留你选择的视图和宽度。
- 跟随话题自己的链接会回到它的内容。**设置**通过自己的地址打开。**以管理员身份**关闭时，**管理**会先显示**管理员访问**。

打开工作时，如果它的标签页已经打开就会选中它，否则会添加到当前聚焦的组里。**在新标签页中打开**会创建另一个视图，**在旁边打开**会把完整视图放在它的右边。每个主标签页都可以关闭。关闭会话的标签页，会让它的智能体继续运行，并保留它的草稿。同一个会话的两个视图共用草稿，各自保留自己的阅读位置和展开的条目。

地址栏跟随当前聚焦的标签页，它菜单里的**复制链接**会复制那个地址。**刷新**会恢复工作区、目标和可以恢复的草稿。**后退**和**前进**保留其他标签页。**关闭所有主区域标签页**会留下一个空的工作台，带有**打开…**和布局控件。**重新打开已关闭的标签页**会找回你最后关闭的视图。关闭一个组的命令会写出它的组名。

**布局**除了手动拆分，还提供 **2 行 × 4 列**和 **3 行 × 3 列**。多出来的标签页共用最后一个格子，空格子仍然可以作为放置的位置。**专注模式**会隐藏导航和周围的面板，只保留主视图。从标签页菜单、命令面板或空的工作台离开它；面板会按原样回来。

面板可以**跟随当前视图**，也可以保持**固定目标**。把面板从侧栏移出会固定它所显示的资源。它的标签页写出那个目标，并且在对话标签页关闭时保持打开。它的菜单可以更改目标，或回到跟随。

- 页面标签页写出你正在阅读的内容，面包屑只写出它的上级。在手机上，它是回到最近上级的完整链接。
- **主目录**会打开你所选的组织，**导航**里组织的名称也一样。
- **跳至主要内容**是键盘的第一站。**F6** 和 **Shift+F6** 在可见的区域之间移动。
- 左栏里的**团队聊天**会在**团队**里打开现有的聊天，并把光标放进它的输入框，当前页面保持打开。
- **资源**登录页列出每一类及其数量和**添加**。话题的文档在它的**文档**页上。栏里的**帮助**是进入指南的唯一入口。

**文件**显示你可以使用的环境，带有代码和文本以及其他种类文件的查看器。[文件和附件](files-and-attachments.md)说明预览、标签的大小，以及哪些内容会送达智能体。编辑会检查冲突。HTML 以代码显示，预览文件绝不会运行它。

终端属于打开它的人，环境的管理者可以关闭它。如果 Orch 无法结束一个终端，它会报告这一点，并把它保留在列表里。它最后的输出遵循所在位置的记录和遮蔽策略。在 Windows 上，进程列表会略去那些身份无法与被重用的进程号区分的子进程，Orch 会拒绝停止有歧义的进程树。关机期间启动的进程可能逃过最后的检查。同一个环境里的会话共享它的文件、主目录、进程、浏览器配置和显示桌面，所以一个目录并不能把它们的工作分开。

**创建分叉**会创建另一个由创建者拥有的会话。不改变任何东西的分叉使用一次请求的操作。当你想要另一个目的地、历史、文件或安排时，**分叉到…**会打开方案。**切换**保留会话，更改它所运行的对象。**移动**把环境的工作带到另一个位置。确认之前，请先阅读真正的方案：它需要的权限、保留了多少历史、选择的文件和被略去的挂载。历史选**无**，意味着新会话对源会话一无所知。

当目的地能容纳该模式时，复制会把写入带到私有挂载；被略去的挂载会说明原因。正在使用的大目录树需要你选择文件，并显示它们的大小和时间。保留作业页面可以查看进展或取消。方案的提交点决定哪一边继续负责。如果你要求的主目录或私有层无法移动，方案会阻止这个请求；它绝不会悄悄略去所选的内容。

## 保留并查找工作

目录树显示聊天和文档及其位置，让各个分支折叠，并可以聚焦在你的工作或某一个位置上。星标和最近记录帮你回到工作上来。**活动**可以汇总一个位置直接包含的内容，也可以深入它下面的所有内容。**归档**会搁置旧的工作。已删除的内容在保留期结束之前可以恢复。有权限的人可以在不恢复的情况下查看保留的内容。共享搜索和查找器见[查找内容](finding-things.md#search)。
