# Read an administrator message

## Read the message

Open a message from your [Inbox](notices-and-announcements.md#read-your-inbox)
or its link. The header says whether it comes from the system or an
organization, and shows its sender and time. Open the sender's person card
to read the profile you may see. The time has its exact value on hover.

The body keeps its headings, links and other Markdown formatting. Reading
this message does not send another message or change the work it describes.
Use the normal Back action to return to the list you came from.

## If the message cannot open

Check the reason shown on the page. Use Retry after a failed request, or
sign in when asked. A link does not give somebody permission to read a
message they cannot otherwise open.

Reading a message and receiving notifications are separate choices. Use
[notification settings](settings-and-usage.md#notifications) to change when
and where Orch tells you about work.
