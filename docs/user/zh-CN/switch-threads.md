# 切换会话

要把很多会话从一个提供方、配置、模型或环境换到另一个，你先审阅一个批次，再切换其中每个可以切换的会话。

## 批量切换

1. 选择提供方、模型，也可以选择智能体配置。
2. 确认之前先阅读每个会话的计划。被阻止的会话保持原样，其他会话可以切换。

在提供方上，整个选择使用当前绑定在它上面的会话。Orch 只包含你可以切换的会话，其余的以数量显示。取消勾选某个会话，即可改为明确的选择。你看不到的会话永远不会给你更改它的权限。

智能体配置和提供方的模型也有**切换其会话…**。模型的这个操作选择它所在提供方上的那个确切模型。来源关闭时也可以切换离开。**停用**让会话保持绑定，**删除**则链接到这个单独的操作。

输入文字会搜索可选项。提交一个目标会读取它的详情。已关闭的提供方或环境不能作为新目标。请选择另一个目标，或先把它打开。

计划会显示历史如何带过去，以及哪些文件会移动。正在运行的工作遵循你选择的等待或中断选项。进度和结果属于整个批次，每个会话有自己的结果。**取消**会在不可撤销的一步之前停止工作。

## 批量大小

系统管理员设置**每批会话数**，起始为 200。调高它可以规划更大的、经过审阅的批次。**批量大小**另外设置同时运行多少个作业。超出的选择会被拒绝，并写明当前设置的名称。Orch 绝不会悄悄地从选择中丢掉会话。
