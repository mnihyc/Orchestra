# 在组织或部署之间迁移项目

**Orch 包**是 Orch 能够读回的导出文件。把一个位置导出为包，然后把这个文件导入你有权创建内容的任何位置：另一个组织、另一个项目或另一个 Orch 部署。导入会先显示它将做什么，并且不写入任何东西。当你选择继续时，它作为一个你可以跟随、取消和撤销的作业运行。

## 导出项目为 Orch 包

1. 在组织、项目、话题、会话、聊天、文件夹或文档上打开**导出…**。
2. 在**形式**里选择 **Orch 包（可导入）**。**文件**和**评论**默认打开。**版本**由你选择。

包是一个 zip。它包含结构（位置和文档文件夹）、带有文件的文档，以及你选择时它们的评论和版本、聊天，和作为历史的会话。每样东西都有一份 Orch 能读回的记录，和一份人可以阅读的 Markdown 副本。文档还有一份 HTML 副本，保留它们的版面以及指向旁边文件的链接。清单列出每个部分及其校验和，这样导入时就能发现损坏或被改动的文件。导出的限制所舍去的一切，都会在清单里作为舍去列出，并写明原因。

包里提到谁，遵循与任何导出相同的规则。人员以姓名和用户名出现，只有系统管理员导出时才会写出电子邮件地址。只有在你管理其访问权限的地方，包才会带上谁可以看到和做什么。

## 导入 Orch 包

在组织、项目、文件夹或话题的菜单里选择**导入…**，或在文档列表里选择**导入**。共有五个步骤：

1. **来源**：拖入包或选择它的文件。Orch 根据它的清单识别它。
2. **目标位置**：位置，以及对由一个位置制成的包，它是作为你选的位置里的新位置回来，还是回到这个位置里。
3. **核对**：试运行。它显示数量、与限制相比的大小、每个对象及其将采取的操作、人员、冲突和会丢失的内容。在你选择**导入**之前，什么都不会存在。
4. **导入**：一行实时的状态，写出阶段（检查、匹配、创建、报告）、条目和已用时间。你可以关闭对话框，作业会在状态栏里继续。**取消导入**会停止它。它已经创建的内容保留，报告会这样说明。
5. **报告**：每个对象一行（已创建、两者都保留、已替换、未改变、已跳过、失败），用文字写出它的原因，可以下载为 JSON 或 CSV。设置里的**你的导入**保留这些报告。

如果导入在写入任何对象行之前就失败了，报告仍会显示它为什么失败。

你只能带入你本来能在那里手动创建的内容。你无权创建的东西，或不能放在那个位置的种类（关闭了文档的地方的文档、文档文件夹下的聊天），会连同原因显示并被跳过，其余的仍然会带入。每一批都会再次检查你的权限，所以长时间导入过程中角色的变化会被遵守。

包里的组织会作为项目回来。组织的设置、成员和共享不是导入应该创建的。

## 人员会怎样

包里提到的每个人都会被匹配，第一个匹配生效：相同的账号 ID（来自本部署的包）、已确认的电子邮件地址、用户名、你在**人员**标签页里做出的选择，否则是**导入的人员**标签。匹配绝不会创建账号。

- **按账号**把包里说明某个账号写的内容，以该账号写入。只有位置的管理员才会得到这个选项。文档、它们的块和已保存的版本，与评论和消息遵循同样的人员映射。所有权仍属于执行导入的人。
- **由我执行，保留原名**让你成为所有内容的作者，并在内容能显示的地方保留原来的名字：报告中、聊天消息或评论的开头，以及对象上写“最初由……”。不是位置管理员的人使用这种形式，它是安全的默认值。

## 冲突与重复导入

遇到已经存在的内容的对象，有两种判断方式：

- **同一来源**：这样东西以前被带入过，通过同一个包或同一个位置的导入。默认是**替换**。文档得到新版本并保留它的身份，所以指向它的链接仍然有效，没有改变的内容保持不动。聊天和会话会被合并：之前已有的消息不会重复，新的消息会被添加。
- **同名**：那里有另一个同类同名的东西。默认是**两者都保留**。新的会取一个空闲的名称，例如“笔记 (2)”。

**冲突**标签页为每种相遇情形设置默认值。某一行的选择会覆盖它（**创建**、**两者都保留**、**替换**、**跳过**）。跳过一个位置或文件夹，也会跳过它里面的内容。把同一个包两次导入同一个位置，第二次不会改变任何东西，除非包里的内容在这期间被编辑过。

导入的各项之间的引用、提及、文件链接和相对链接，会一次性改写为新的位置。指向包之外某样东西的引用，会把它的标签保留为文字。

## 哪些内容不会恢复

Orch 包是工作的副本，不是一个正在运行的系统的副本。以下内容不会恢复，**未导入**标签页会在你开始之前这样说明：

- 智能体程序的会话（会话作为历史回来，不绑定任何东西）；
- 环境的工作区和其他文件；
- 秘密；
- 用量和审计记录；
- 人们为自己保留的内容（已读标记、固定项、草稿），以及审批；
- 存放在网络上的图片（它们保持为链接）。

导出时舍去的内容（太大、无法导出、没有权限），以及任何回来时有改动的内容，都会连同原因一起计数。

只有当包带有共享、**共享**开关已打开，并且你在目标位置拥有**管理**权限时，共享才会回来。其中指名的每个人，在导入创建的内容上会再次得到他们原来有的权限，就像你亲手授予的一样。你无权给出的、由上层的锁决定的，以及位置不让你指名的人，会被舍去并计数。在这里不是账号的人也会被舍去。原来就在那里的内容保留它自己的共享。

## 设置导入的会话

1. 打开会话，阅读它导入的消息。
2. 在输入框里选择**选择智能体**，然后选择提供方、智能体、模型和环境，再选择**设置**。

导入的消息保留为历史，下一条消息会用这个设置开始本地工作。标题栏会标出**导入的历史**。**需要设置**表示还没有选择本地智能体，标题栏里的**选择智能体和提供方…**会打开同一个选择器。

## 撤销导入

报告里的**撤销导入**会先显示它的方案：导入创建了什么，以及因为之后有人添加或更改而保留什么。如果某项检查阻止**撤销**，对话框里会显示它的原因。没有阻碍时，确认会按通常的方式删除导入创建的内容，仅此而已，所以在显示的日期之前你仍然可以把它找回来。

- 别人更改过的文档会保留。导入的位置或文件夹里之后写入的任何东西，以及容纳它们的位置和文件夹，也会保留。
- 只有你现在有权删除的内容才会被删除。
- 你导入到已经存在的东西里的内容（被替换的版本）不会被回滚。新版本留在它们的历史里。

**撤销**之后，报告保留它的结果和下载，并且不再提供打开被移除的位置。**撤销**之后你可以再次导入同一个包。它会创建一个新的副本，并让被移除的副本保持可以恢复。再次导入那个新的副本会保留它的身份。

## 导入纯文件

同一个向导也接受 Orch 从未写过的文件。

- **文件**带入 Markdown、HTML、Word 和文本。
- **文件夹**把文件夹保留为文档文件夹。
- **归档**接受这类文件及其图片的 zip，或 tar（`.tar`，或用 gzip、bzip2、xz 或 zstd 打包的：`.tgz`、`.tar.gz`、`.tar.bz2`、`.tar.xz`、`.tar.zst`）。包含其他 zip 的 zip（如 Notion 的导出），或一起选择的多个 zip，会被当作一个来读取。

文件之间的相对链接和图片会解析为新的文档和附件。找不到的文件会在报告里写出名称，文本会保持链接原来的写法。运维人员设置一次导入可以带入内容的限制。除非被更改过，它们遵循一次导出可以容纳的内容。
