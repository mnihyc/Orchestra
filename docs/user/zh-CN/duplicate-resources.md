# 创建资源或对话的副本

打开对象的 **⋯** 菜单，或右键点击它所在的行。

- **创建副本**会在同一个位置创建副本，新的名称由服务选取，被接受后会打开新的对象。
- **创建副本到…**会打开跨你的各个组织的共享位置选择器。选择目标位置，如果愿意，也可以填写名称。
- 取消不会发出复制请求。

## 哪些内容会跟随

副本采用目标位置的默认值和锁，以及新的权限页。已有的共享、评论、用量和管理历史留在原对象上。

- 环境的副本会把你能读取的工作区复制到它拥有的新存储里。
- 文档的副本会带上你能读取的内容和文件。
- 技能通常的操作会复制它已发布的版本。在它的草稿编辑器里，**复制草稿**通过另一个操作复制尚未发布的草稿。
- 会话的**创建副本**就是它的分叉。对它的智能体的访问审阅和它的作业方案仍然适用。**创建副本到…**让你在同一个位置选择器里选择话题，方案会检查目标和它将使用的资源。内置程序的会话为私有的创建保留它们自己的流程。

发起线程移动的人在原会话删除后仍可查看已接受的任务。范围受限的凭据仍须遵守该任务实际所属组织和位置的限制。

## 凭据和通知

由资源的操作决定你是否拥有来源并可以携带它的秘密。给其他读者的副本需要它们自己的密钥。订阅的副本以未登录的状态开始，使用它自己的登录。复制绝不会要求浏览器获取并重新发送来源的凭据。

对于被导入的 MCP 服务器的定义，**机器**选择接收它的机器，与共享它的所属位置无关。保留**同一台机器**会在原来的接收者在目标位置可以使用时保留它。被拒绝时会要求选择符合条件的机器。选择另一个所属位置并不授予对任何机器的权限。

群聊的副本以新的权限页和只有它创建者的名单开始。**创建副本到…**会根据来源的贡献者预览提供**通知 N 个人**。不勾选则静默复制。如果预览失败，或人数超过上限，就不能通知，仍然可以静默复制。通知不会给任何人访问新对话的权限。

## 目标位置被拒绝时

读取来源和在目标位置创建这种东西，是两项独立的检查。把文档、聊天或会话带到另一个组织，还需要它的**导出**权限，并且来源的策略**复制到其他组织**必须允许。这项策略遵循系统、组织和项目的设置与锁。

- 位置选择器会让不可用的目标保持可见，并给出真实的原因。它的要求按钮会打开访问的详情，或来源策略设置的帮助。
- 有些位置在复制继续之前，需要为这个对象本身指定放置、机器或方案。
- 被拒绝的请求会保留你选择的位置，并显示访问或字段方面的问题。请检查缺少的访问权限，或选择另一个目标位置。
- 被接受的确认会打开新的对象。打开它仍然可能报告新的对象对这位读者不可用。
- 在不改变你的选择的情况下重试丢失的回答，会重复同一个操作，不会再做一个副本。

## 在组织内移动所属位置

**移动…**使用同一个位置选择器，在资源的根组织之内更改它的所属位置。组织的部门算作那个根之内的位置。这个操作需要有管理来源和目标位置的权限。它保留身份和文件，并使用新的所属位置来继承。群组通过它自己的更新使用同样的选择。直接聊天不提供**移动**。

主机和机器提供这种所属位置的更改，没有**创建副本**。对于环境，**移到另一台机器…**仍然是它自己单独的、实际搬迁它的方案。更改所属位置不会这样做。

## 移至其他组织

在**移动…**里，选择另一个根组织里的所属位置，按钮就会变成**复制到 <组织>，然后删除**。只有来源的所有者才能使用它。复制出去和删除的每一条规则仍然适用。不是所有者的管理者或管理员不能使用这种移动。

移动供应方、代理、技能、挂载、模板、主机或机器前，请检查**删除计划**。各行显示实际影响，包括停止关联工作或保留注册。复制和移除原对象由一次操作完成；取消对话框不会改变任何一方。主机和机器保留原注册及标识，不会新建第二个注册。环境在其跨组织原生移动操作就绪前保持不可用。

移动被拒绝后，所选位置和原因会保留。如果原对象或删除影响已变化，可用**重新检查**获取新的计划，再决定是否确认。丢失响应后的重试会复用原操作，不会再创建一个副本。接受后通过正常的读取路径打开回执指向的对象。


文档和文档专用文件夹也使用同一个**移动…**入口。先选择组织或项目，也可以再选该组织内的文件夹。在组织内移动会保留标识；移至其他组织时，先检查完整的原生删除成员及保留期限，再由一次操作完成复制和移除原对象。受保护的预览只显示**删除计划已就绪**，不会暴露隐藏的成员。接受后，如果回执提供原对象与副本的对应关系，会直接打开新根对象；精简文件夹回执没有这种对应关系时，会打开所选目标目录。


移动 MCP 时使用原生的源定义删除计划。对于导入的定义，**机器**选择目标保管方，与共享所属位置分开。只有原生检查允许时，**原机器**才会保留当前接收方；更改机器会重新取得删除影响，再等待确认。自有定义保持原类型，不提供导入定义的机器选择。

移动群聊时，原生操作会检查当前实际管理者及复制到其他组织的规则。先检查**结束此群聊及其历史**，输入显示的群名，再确认这一次移动。**通知N人**使用原群聊的原生成员预览，不会授予对新群聊的访问权限，新群初始仍只有创建者。不勾选即可静默移动。群聊或所审阅的通知对象发生变化时，**重新检查**会清除群名确认和通知选择，等待你重新决定。


移动供应方会使用原生创建及成功删除原对象的路径，计划会显示停止工作和清除原对象的影响。订阅登录状态由同一次操作移交；普通“创建副本”仍会让订阅副本初始未登录。浏览器不会读取并重新提交这些凭据。


编码会话可从 **⋯** 菜单选择**移动到…**，再选择其他组织的话题。如果原绑定在该处不可用，请在计划中选择替代项。确认前一并检查完整对话副本、目标位置的新权限以及原会话的删除影响。只有实际所有者可以确认；导出权限、允许跨组织复制的策略、目标创建权限和原会话的删除条件仍然适用。计划中列出的未关闭旁支会话须先关闭或保留为独立会话。原生任务仅在副本提交成功后删除原会话；提交前可隐藏或取消任务。原会话消失后仍可查看任务进度，使用**打开已移动的会话**进入新对话。**通知N人**为可选项，并绑定到已检查的发言者范围。内置程序对话使用同一移动入口及原会话删除审阅，保留程序并复制全部历史，采用目标位置的访问默认值，在目标组织中搜索并受其治理，无需编码代理或环境。副本与原会话结束一同提交；回答丢失后重试只确认同一结果。
