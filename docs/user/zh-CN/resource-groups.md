# 按所属位置和来源组织资源

资源分组使用已有事实：所属位置、所有者、机器和标签。显示分组不会创建新资源或授予权限。资源所属位置承载共享策略；来源机器说明它从哪里来，或能在哪里运行。

## 在哪里

打开[资源](/resources)及其中一种资源列表，在排序旁选择“分组 → 所属位置 / 所有者 / 机器 / 标签 / 不分组”。初始按所属位置分组，每个列表会在本设备记住上次选择。[所有内容](/everything)也会将资源列在所属位置下。

资源选择器按可读取的所属路径分组，当前工作位置的组排在前面。输入名称可跨组缩小范围；方向键跳过组标题，在选项间移动；Enter 选择可用项。遇到不可用项时，可先查看原因，再选择其他项。

## 示例

将主机 A、B 的所属位置设为 Guests 项目，并通过该项目的共享策略授予相应人员使用权限。在[主机列表](/resources/hosts)按所属位置分组，就能一起看到它们。另在[MCP 服务器列表](/resources/mcp)按机器分组，查找从 Workstation 导入的副本。

## 操作后会怎样

从机器导入或在机器上创建的资源，初始沿用该机器的所属位置。管理者可以用“移到其他所属位置”覆盖这个默认值；再次导入或注册会保留此项明确选择。

切换显示分组不会移动资源。改变所属位置不会搬迁文件，也不会改变机器限制。导入的 MCP 定义仍只属于原来的机器。[导入和使用 MCP](mcp-import-and-use.md)及[切换和搬迁环境](switch-and-move-environments.md)说明相应操作。
