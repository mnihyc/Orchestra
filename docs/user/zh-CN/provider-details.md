# 选择和阅读提供方详情

在**模型 → 编辑选项… → 模型报告**中，可查看接口报告的输入和输出窗口、能力支持、
模型系列及计划退役时间。计划日期不表示模型已经退役。未报告的事实不会被猜测，
新报告不会自动启用网络搜索、更大上下文或其他付费选项。保存模型时，这些事实与
管理员启用的选项分别保留。

提供方凭据、模型访问、详情、模型列表和运行时分别选择。数据源可为密钥或原生登录报告
窗口、余额、花费和重置。卡片注明详情来源，只展示数据源和凭据保管者知道的事实。
金额使用供应商单位，Orch 计数是另一个令牌和价格表账本。

## 选择数据源

添加提供方先选接口：地址和 API 格式，或程序自身登录，然后选择凭据及能到达它的机器。
示例填同一组字段，密钥之后在登录和密钥添加。创建不等待运行时回应；页面先显示已存配置，
实时连接再带来观测。

设置中的详情来源分别选择信息和模型。默认会说明实际读取者：原生登录使用适配器，
OpenRouter 或 DeepSeek 密钥地址用相应读取器，否则没有可选信息；模型通常来自地址自己的列表。

程序选择保管机器已注册或可信模板自带的程序。字段来自它的声明，秘密只显示已设置并可替换。
更换不会安装程序或导出原生登录；模板必须自带程序及解释器。

地址选择服务 URL 和无认证、Bearer 或指定请求头。授权值只写不读，例如虚构服务
`https://plan.acme.example/provider`。发送此提供方密钥默认关闭，开启要确认实际主机，
原生登录不可用；服务令牌与提供方密钥独立。

`http://` 默认拒绝，只有 `providers.allow_http_upstreams` 在此允许才可用并标为未加密。
例如 `http://plan.internal:41870/provider` 也需要该策略。请求从保管机器发出，其网络白名单
或本地 `provider.upstreams` 也须允许。Orch 不跟随重定向。

无只保留凭据保管者的信息；模型的仅手动让管理者输入路由名而不发现模型。保存读取数据源
声明和首个结果，旁边显示支持成员或安全错误。添加向导也有相同选择和默认值。
添加来源程序使用该机器的程序注册，返回声明提供字段。见[自建提供方来源](../../development/extensions/providers/README.md)。

页面有概览、模型、登录和密钥、用量、设置、活动六节。信息是带读取时间的紧凑列表，
未读取项共用尚未读取和刷新；来源不支持的项目在已报告信息下共用一行“不提供”，标题注明来源。
缺少管理密钥时保留具体说明，未读取的事实不会被猜成零。累计和最近的使用次数也注明单位，例如“轮”。
删除在页面菜单中，即使详情无法显示也可使用，
仍检查权限和占用情况。

## 请求选项

在**登录和密钥 → 端点 → 高级**中，**允许的请求选项**按接口填写 JSON Schema。
在**模型**页打开分组的**选项…**，同一套规则会作用于这个已有分组中的模型。
模型自己的**编辑选项…**保留其单独规则。

字段的表单优先使用模型的规则，其次是模型分组列表中最后一个分组，再向前读取其他分组，
最后使用端点规则。最终请求仍必须同时满足每一层限制。例如，端点允许温度 0 到 1，
分组将上限设为 0.5，模型默认 0.25，最终默认值就是 0.25；请求 0.75 会被拒绝。
模型填写更宽松的表单也不能移除分组上限。程序经转发器的调用和 Orch 自身的模型调用
都遵守这些规则。修改用于下一轮或下一次调用，当前租约保留其已接受的配置快照。

`providers.model_groups_max` 决定在此归属范围内每个模型可新加入多少个分组，默认 8 个，
可以提高。降低数量不会改写已有分组，仍可编辑模型或从分组中移除模型。
设为 0 后不能新加入分组。**添加模型**和模型编辑器都会读取这个设置。

例如，先在端点高级选项中填写通用规则，将相关模型加入 **frontier**，再打开
**frontier → 选项…**填写分组规则。模型的单独规则留空时使用共享表单。
保存一个分组会保留其他分组；JSON 无效或版本已变化时，对话框保留草稿并显示错误。

## 线程选项

Codex 的**访问计划**也可用于转发的 API 端点，前提是该接口支持，并且提供方管理者已为模型启用对应计划。
在线程输入区的**模型与强度**对话框中选择。修改从下一轮生效；该轮的租约在重试或重启后仍保留同一选择。
普通访问不会向 Responses 请求添加计划选择字段。提供方仅报告、尚未由管理者启用的计划不可选择。

打开线程的**参数 → 请求选项**。通过 API 转发的线程按接口显示提供方开放的字段。
枚举值从列表中选择，固定值只读。使用程序自身登录的线程保留程序原有的参数控制。
提供方未声明的字段不会成为线程选项。

每个接口的选择使用已有的**智能体参数**设置，遵守同一套来源、锁定和版本规则。
重置该行即可重新继承上级选择，其他接口和参数的选择不变。
保存遭拒时保留草稿并显示错误；是否能修改仍由线程管理权限和上级锁定决定。

选择在**下一轮**生效。正在运行的轮次保留租约中的值，连接恢复或运行时重启也不改变它。
发生协议转换时，只应用实际发出请求的接口所对应的选择；最终请求仍须符合端点、分组和
模型的每一层规则。例如，可以用提供方开放列表中的详细程度替换程序的值，但不能改写
固定地区，也不能启用提供方关闭的字段。切换模型后，若新模型未开放原来的字段，需要重置
对应接口的选择。

## 确认值

在**模型**页，已保存的模型和待接受建议旁的**报告值**会打开只读小卡片。
每个值分别标明**来自厂商**或**来自目录**，只有厂商实际报告的值才使用前者。
目录中的映射仍是建议；来源未知或旧报告没有来源信息时显示**来源未确认**。
卡片保留模型报告自身的时间，没有时间时显示**未报告时间**。
更新余额或套餐不会把旧的模型报告变成新观测。

**厂商报告不同**会列出与已保存建议或选择不同的字段。卡片显示厂商报告的值，
已保存条目和你的覆盖值继续生效，直到你主动编辑。
查看或刷新不会启用模型、加速、搜索或付费服务。
报告的最大上下文表示可用能力，与管理者向线程开放的上下文不同。
价格保留来源报告的小数精度，未报告不等于零。

厂商报告的**系列**可以在模型旁提供**加入……分组…**。
它会打开原有模型编辑器，保留其他分组，并提出这一项成员关系。
可以修改或移除建议，再选择**保存**；取消不会改动。
只有厂商实际提供、且已符合分组命名规则的系列才会被建议，不会从模型名称猜测分组。
刷新报告不会修改成员关系。配置的分组数量仍有效，包括零；需要时先移除其他成员关系
或这项建议。即使后续报告给出另一系列，已打开的草稿也会保留你选择的系列。

## 理解四种状态

| 显示 | 含义 |
| --- | --- |
| 此来源不提供 | 数据源从未声明或报告该成员 |
| 尚未读取 | 已声明支持，但没有成功观测 |
| 未报告 | 明确报告 null 或空列表 |
| 数值与时间 | 在该时间报告了数值，真正报告零才显示零 |

例如剩余 12.50 USD 是报告值。后来读取省略余额时，保留该金额及旧时间；明确报告无余额
才清除。新窗口不会让旧金额变成新观测。来源错误保留旧值、时间和刷新失败重试，
不会把可用模型凭据变成授权失败。

刷新读取信息和模型报价，新模型只作为待启用建议。报告重置时间后一分钟也会读取。
紧凑说明优先使用约束窗口，再余额，再花费；没有可读信息就不能推测剩余额度。

## 程序退出

设置中的运行时显示每个智能体配置的当前状态。上次程序错误保留最近一次意外退出及时间，
程序报告原因时也会显示。配置重新在线后仍保留这条记录。正在运行的轮次标为已中断，
会话中记录原因。下一轮按线程的历史恢复方式继续。

## 套餐预测

近期读数足够时，每个窗口的用量条下显示预测。窗口标题旁的**随时间变化**会打开提供方
用量页的套餐部分。实线表示测量用量，虚线按已观察到的速度延伸。历史按时间段显示新增用量，
并标出提前重置。参见[套餐窗口与预测](settings-and-usage.md#plan-windows-and-forecasts)。

详情不可见时，用量区仍显示**此视图无法显示用量详情**，不透露来源或金额。
可读来源没有套餐或历史时，显示**此来源不提供套餐或用量历史**。
来源需要管理密钥时，仍保留这个具体原因。

## 使用重置

来源可列出并声明能消耗的重置。只有当前管理者在浏览器得到使用重置。对话框显示确切
重置、当前数量、剩余数量和效果。默认取消，需明确选择使用本次重置。不调用模型，
Orch 限额也不改变。回应丢失后保留相同请求身份，重复确认只消耗一次。

来源限额也可暂存密钥提供方的工作；重置成功或后续报告允许时，按原权限和限额释放。

## 请求选项规则

在“模型”中打开模型编辑器，选择请求格式。文档中的字段有紧凑的规则控制：未单独指定规则、限制或禁止。可以选择允许的值而不选择默认值；默认值需要另行指定。标识字段可以固定为提供方填写的文本，或从请求中移除。规则仍受端点和模型原有的限制约束；服务档位出现在字段列表中，并不表示已启用。

原始 JSON 保留自定义字段、原生代理规则及不认识的模式关键字。未完成的草稿会保留，直到修正。复杂的父级模式继续使用原始 JSON，不会被紧凑控制覆盖。即使没有单独指定字段规则，封闭的父级模式或其他层仍可能禁止它。

端点格式声明“请求选项”时，会显示相同的模式控制。固定的公开请求头使用原有的请求头映射，密钥请求头仍使用单独的控制。“高级”保留其他名称和值。请求体默认值与模式规则彼此独立。

字段列表依据 [Responses](https://developers.openai.com/api/reference/resources/responses/methods/create)、[Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[Messages](https://platform.claude.com/docs/en/api/messages/create) 及已配置端点的扩展文档。文档中列有某个字段，并不能证明模型支持它。


## 服务后端

API 提供方的**设置 → 服务**列出其已保存端点声明的服务。发现服务不会自动启用它。提供方管理员可通过**编辑服务**启用服务、使用声明的分组或自定义服务分组，并按需设置 Orch 点数价格。保存这些选项不会发起搜索、读取网页或请求模型，也不会为线程选择后端。运行环境无法提供的服务会在控件旁说明原因。

目录价格是以原币种记录的估算值。管理员明确保存的 Orch 点数价格决定 Orch 的计数；供应商报告的总费用另行保留以供比较。清除自定义价格会恢复目录估算。编辑会保留其他服务及未来配置字段。提供方版本已变化时，保存会被拒绝，避免覆盖其他管理员的修改。

只有在线程明确选择**服务**模式，并指定已启用的后端后，才会调用付费服务。每次请求都检查原始发起人或原生工作来源的提供方使用权限、服务或模型允许列表，以及按用途设置的额度。模型列表与服务列表相互独立。未设置时保留程序默认行为，不会选择付费回退。
