# 为群聊选择所属位置

群聊有名称、所属位置、可见性和管理者。它可以属于组织、项目、主题或线程。位置本身的聊天仍是该位置的公开交流；另行创建的群聊可以是私密或公开的。

## 在哪里

在组织的“消息”页面使用“新消息”选择人员。只选一人时开始私聊；打开“群聊”开关，也可以与这一人建立群聊。选择多人会自动打开群聊开关。名称可留空，然后选择所属位置和可见性；所属位置默认采用打开对话框的位置。可读取的群聊会出现在所属位置下的导航、按位置分组的消息列表及[所有内容](/everything)中。通过聊天标题的菜单或“共享”查看成员和管理权限。

“公开”允许在所属位置具有聊天查看权限的人发现群聊并自行加入。“私密”需要管理者邀请或批准加入请求。公开列表不会向非成员暴露私密群聊的名称。

“发消息…”只打开会话，不会自动加入；可以自行加入时才会显示“加入”。“共享”展示实际的成员、管理角色、可见性和所属位置。管理者可以在同一个根组织内，将群聊移到其他组织、项目、主题或线程；之后群聊会显示在新的所属位置下。

## 示例

在 Release 主题下建立私密的“发布评审”群聊，加入评审者，交接前先将另一位评审者设为管理者。需要更多人参与时，管理者可以将其改为公开。此时，有权查看该位置聊天的人可以发现并加入；无关的外部用户不会因此获得权限。

## 操作后会怎样

管理者可以增删成员、决定加入请求、修改名称、所属位置和可见性，也可以管理代理发言。最后一位管理者需要先完成交接，才能放弃管理权限。所属位置的管理员仍保留正常的内容管理和管理访问能力。

移动群聊需要当前及目标位置要求的权限。将人员加入群聊会使其成为参与者，确认前应阅读实际的访问选项。[链接共享](link-sharing.md)说明链接的接收者；[资源分组](resource-groups.md)说明资源列表的组织方式。
