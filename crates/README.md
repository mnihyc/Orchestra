# Library layers

- [Foundation](foundation/README.md): Small shared primitives and compiled build identity.
- [Contracts](contracts/README.md): Neutral schemas, catalogues, descriptors and interfaces for every seam.
- [Platform](platform/README.md): Shared configuration, observability, trust, transport and plugin mechanisms.
- [Control](control/README.md): Durable control-plane policy, orchestration and database-backed services.
- [Runtime](runtime/README.md): Machine-side connector, environment host and node services.
- [Tooling](tooling/README.md): Build support, verification, generation, packaging and future behavioral test support.

See [Architecture](../docs/development/architecture.md) for dependency direction.
