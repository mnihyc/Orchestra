# 编写环境模板

模板描述受管环境的镜像、工具和初始配置。保存模板不会启动机器或环境。

## 环境

放在同一环境的线程共享工作区、主目录和进程。为这种工作编写模板时选择环境。

## 提供方

提供方运行时使用相同单元配置保存主目录、工具和凭据，没有环境工作区。为它编写模板时选择提供方。

## 创建第一个模板

1. 打开资源 → 模板 → 新建模板，选择环境、名称和所属组织。
2. 打开从示例开始，选 Node。选择器说明它适合网页项目，填入 Docker 驱动、Node 镜像、
   四核、4 GiB 内存和普通外连的完整起始配置。换示例会替换配置，对话框只问少量初始选择。
3. 保留镜像引用或换成含项目工具的可信镜像。Orch 提供连接器，选模板不安装项目依赖。
4. 创建模板会让服务器检查整个示例及修改。初始字段问题就地显示，成功后立即打开模板，
   初始仅你可用，准备好后从访问页共享。
5. 在配置中按字段名称、含义或值搜索，再选择小节。资源部分设置限额，网络设置连接。
   示例数字是起点，不是最低要求或驱动默认值。检查后选择保存模板。

主机上已安装的程序可从示例选择 Host，填入 Host 驱动、`agent` 账号及启动后执行的
`/usr/bin/printf`。修改账号后，在配置 → 启动后命令中修改程序。必须使用主机已有的账号
和程序，不使用容器镜像。

已注册主机可离线，表单显示它及已知断线时间。离线仍可用最后报告的驱动表单和示例，
启动前要连接匹配主机。没有任何主机报告表单时，先连接一台。页面统一的模板指南覆盖
这些选择和字段。

Python 配 PostgreSQL 示例使用另行管理的数据库。把 `db.example.internal` 换成你的可达
地址，示例不创建数据库。凭据通过位置的秘密名称选择，不放进可见变量。

## 阅读各节

镜像从仓库引用、主机支持的 Dockerfile 构建或上传镜像包三者中选一。标签可变，摘要固定。
Dockerfile 使用经典 Docker 构建器，构建上下文来自上传压缩包或公开 Git 仓库。

隔离选择容器运行时和安全选项，留空使用主机默认。只读镜像仍允许写可写卷。工具隔离
决定代理在容器内的文件访问。KVM 等额外能力还需设备及主机策略或审批，标签本身不授权。

资源设置限额，以及环境管理者以后可提高到的上限。CPU 以千分之一核计，1000 是一核；
内存用 MiB，磁盘用 GB，主机报告可执行哪些限制。需要条件只决定放置所需空闲量，
不预留容量，也不设置消耗限额。

网络选择普通或受限外连。受限只能到 Orch 及 `network.allowed_hosts` 列表；启动前在
位置设置该列表，并选择支持的主机。受限网络不要自定义 DNS。无网络只通过主机代理到 Orch。
不支持的限制会拒绝，不会改成开放。

代理工具说明远端代理可用的工具及可在此运行的代理，要选择镜像或主机实际具备的程序，
还受提供方同意约束。用户可选镜像账号或数字用户、组，留空沿用镜像用户。可写路径要匹配权限。

变量是明文，凭据用秘密名称。启动后命令以单元用户在附着后、就绪前执行，参数按字面
传入，默认期限 300 秒，失败令启动失败。[启动后命令](commands-after-start.md)说明排序、
继承及独立主机钩子。

存储设置工作区、主目录和额外挂载。绝对路径不可互相重叠或覆盖 Orch 目录。命名卷保留
数据，内存存储随容器移除丢失，绑定挂载暴露主机已有目录。提供方只保留状态卷，
没有环境工作区或主目录路径字段；注册程序节说明提供方镜像自带的程序。

每个共享设置行显示含义、值和来源。本模板是显式值，驱动默认是声明的默认值，镜像、
主机或位置表示留给将来单元决定。齿轮只显示一次默认，重置只移除该值，保留其他成员。
问号按需补充范围和示例，列表和结构值在行内打开。只读时仍显示值和来源，并统一说明权限。
插件驱动自己的包提供字段说明和示例。

## 按需使用 JSON

配置 → 详情 → JSON 打开同一配置的行号编辑器。属性补全来自驱动结构，悬停看含义。
短暂停顿后服务器按保存规则检查，错误带行号并可跳转；检查不保存。语法修好再切回。
切换保留值及驱动允许的额外属性，未识别设置列在其他设置 JSON。未完成草稿阻止切换和
保存，修复或丢弃变更回到已存模板。

## 为位置选择模板

在组织、项目或话题设置选择 `env.template_id`，按普通继承，可在文件夹或话题另选。
创建者要有模板使用权及合适主机。直接建环境也有模板选择。受管提供方在单元配置选择
`runtime.template_id`。

从模板选择添加环境会预选它，再选所属位置；可用临时创建一次性工作。
移除通知、保留和文件导出见[临时环境](temporary-environments.md)。

## 修改已使用的模板

配置页可编辑名称、描述和字段。保存只改变以后启动和更新的配方，不立即改正在运行的
进程或文件。现有单元保留记录配置，直到审查并应用更新或重建。见[运行中修改环境](change-a-running-environment.md)。
别人先保存时会重读其版本，保留你输入的值供比较，不自动覆盖。

关闭模板阻止新单元，现有单元继续。仍有单元使用的模板不能删除。
