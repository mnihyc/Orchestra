# 查看主机驱动的功能

## 查看可用操作

打开主机的**概览**，展开**详情**，找到**驱动**。选择某个驱动的**功能**，查看它报告的
操作。每项显示**可用**或**不可用**；不可用时会说明原因。功能列中的短横线表示主机
尚未报告这些信息。

能运行环境的驱动，也可能不支持构建镜像、导入镜像归档、主机目录、私有视图、暂停或
主机端口。保留已安装文件与迁移已安装文件是两项独立能力。工具分发和网关访问说明
新建运行单元可以使用什么。

这些是主机报告的能力。具体请求还受访问权限、机器策略和所选模板限制。查看功能卡片
不会启动任务，也不会修改设置。

## 查看容量和存储

主机是环境的一个运行目标，也可以代表由多台机器组成的资源池。驱动负责选择每个运行
单元所在的机器。容量与负载描述这个资源池，不一定是运行节点程序的那台电脑。

在**存储**页的存储列表中，名称可以代表磁盘或存储类别。尚未测得的容量、可用空间会
显示短横线。未知不代表空闲或没有上限。为新数据配置存储时，选择主机实际提供的名称。
修改选择不会搬动已有数据；已有环境应使用需要审阅确认的移动流程。

有关这些选择，见[命名存储](../choose-machine-storage.md)和
[环境模板](../write-an-environment-template.md)。
