# 在环境运行时修改它

环境管理权控制运行位置和设置。修改旁的生效说明取决于驱动实际支持的在线能力及主机状态。

## 在线修改限额或挂载

Docker 声明支持在线资源修改时，把内存从 2048 MB 提到 4096 MB，或修改 CPU、进程限制，
会更新运行中的容器，原进程继续。降低内存前表单显示当前用量；低于用量可能触发内核
回收或终止进程。创建时固定的磁盘限制仍要重建。

挂载要选择真实位置和只读、私有或共享模式。主机安全支持在线挂载时，可不重启单元而
接入或分离。内核不支持或安全接入失败时，变更保留为待应用并显示原因及立即重建，
不会暗中替换单元。每次启动都会重新应用所需的在线挂载。

代理在下一条接受的输入中只收到变更的上下文行。在线变更不启动轮次，也不发送停止命令。
工作详情可以阅读实际上下文文字。

## 授予 KVM 或 Docker 套接字

允许 KVM 的模板先准备设备权限和组，但授予前不提供 `/dev/kvm`，也阻止创建。
通过有权限的能力决定授予后，会在线暴露设备。Docker 套接字同样可在线挂载。
原进程和磁盘保留，只告诉代理现在可用，不发生重建前后通知。

批准后还需等待应用结果。在线变更失败时不会授予能力，环境可能重启以恢复之前的权限。
批准记录会显示“已批准，但未授予”及失败原因；智能体会在下一条输入中收到同样的失败通知。
请先让宿主机管理者解决原因，再重新申请。节点日志会记录辅助程序的退出状态和末尾错误信息。

收回时移除设备或挂载，并重启同一个容器以关闭旧进程仍持有的句柄。进程停止，卷外
安装和文件仍保留。Docker 套接字可访问主机守护程序，应认真阅读其高风险决定。

## 重启一个工具服务器

环境页和线程的环境面板列出每个 MCP 服务器状态。失败项显示退出状态和已遮蔽秘密的
末尾输出。例如浏览器工具连续三次以代码 1 退出后失败，管理者可以只重启它。
作业清除失败计数并重新启动，环境、其他服务器和活动轮次继续。再次失败仍保留原因，
不可用的服务器仍需满足缺失条件。环境停止时要先启动环境。

支持 MCP 重载的程序会立即刷新工具，否则在下一轮前刷新。重启不改变启用选择或本机策略。

## 重启环境

停止旁的重启会先列出将结束的轮次、终端、浏览器、显示和端口连接。同一个单元和所有
文件都会保留，包括卷外安装。`capability.recreate_grace_secs = 120` 时，按普通重建宽限
等待运行轮次。立即中断立刻停止；等待让轮次在宽限内完成，超时仍会中断，确认前会说明。
作业显示等待、停止、启动，失败会指出步骤。

例如某轮在卷外写了 `/opt/restart-proof.txt`，另一条输入在排队。重启成功后文件仍在，
排队输入按普通检查继续，线程记录谁重启。端口连接结束，开放按通常的停止和启动行为处理。
限制和独占凭据归还检查仍适用。

## 阅读重建方案

ptrace、GPU、网络管理、不限制、特权或主机网络，以及其他存储和创建时磁盘限制，仍可能
需要替换。同镜像 Docker 重建会把已停止单元的文件系统保存为本地层，包括 `/usr`
安装和 `/opt` 文件。方案先显示测得大小和估计时间；未知会明确标出，主机不同估计可不同。

换镜像时，工作区、主目录和状态卷之外从干净镜像开始，确认前说明损失。保留十层后驱动
会展平，额外工作计入估计。不支持保留同镜像安装的驱动会说明。

例如先在 `/opt` 装调试器，再读 ptrace 请求中的进程停止和保留量，成功后安装仍在。
更新到其他镜像会有不同警告；长期需要的安装应放入模板。

保留镜像属于环境，移动会列出并携带其大小，归档保留供恢复，失败替换和过时代际会清理
自己的镜像。删除或清除会连同所属单元和卷一起移除，节点页显示保留层大小。
能力权限见[审批如何工作](how-approvals-work.md)，端口见[开放端口](let-agents-open-ports.md)。
