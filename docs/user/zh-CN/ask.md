# 就工作内容提问

**问一问**是你的个人只读对话，围绕当前页面和你在一个组织中有权阅读的工作提问。它的回答会注明来源。它以你的身份阅读，不改变任何东西。

## 打开问一问

选择左栏里**帮助**上方的**就这个页面提问**。在手机上，使用查找器旁边的同一个按钮。**Shift+F1** 也能打开它，**帮助**里的快捷键编辑器可以让你更改这个键。

问一问起初停靠在右边。**弹出**会把同一段对话和草稿放进一个浮动窗口。

- 拖动它的标题可以移动它，拖动右下角可以调整大小。聚焦其中任一个手柄并使用方向键，可以做同样的操作；**Shift** 会移动得更远。
- **最大化**、**还原大小**和**停靠**会改变它的位置。
- 它的大小和位置保存在你的账号里、这台设备上。

## 输入问题

输入问题并按 **Enter** 发送。**Shift+Enter** 换行。用输入法确认文字时不会发送问题。

- 使用回形针，或粘贴或拖放文件，可以附加文件。标签显示进度，并让你移除或重试某个文件。发送会等待尚未完成的上传。
- 输入 **@**，或选择**提及资源**，可以在这段对话所属的组织里，找到你有权阅读的文档、会话、聊天或资源。选中一个会把它加入草稿。它自己不会发送任何内容。
- 模型标签列出你在这个根组织的**问一问模型**设置里可以使用的条目。**默认 · 模型**跟随这个有序列表里你能使用的第一个条目。选择另一个条目和你的推理强度，使用会话用的同一个模型和推理强度控件。在你选择之前，推理强度跟随模型的默认值，不声明推理强度的模型没有强度选项。其他选择保持在提供方的限制之内。你自己的选择及其参数会和这段对话一起保留。

**问一问模型**在**设置 → 自动化**里有自己的列表。在系统层面，有权编辑它的人可以添加或移除已打开的 API 模型，并上下移动它们。条目只包含提供方和模型。在组织层面，列表来自上层：编辑者可以移除条目来收窄它，但不能添加或重新排序，来自上层的顺序保持不变。推理强度和其他参数保留你在标签里自己的选择。只有订阅的提供方不是问一问模型。组织当前的策略和用量限制适用于每一轮。

如果列表没有设置、为空，或没有你能使用的条目（模型策略可以排除每个条目），面板会显示原因，并且没有输入框。只有在你有权编辑时才会出现指向这项设置的链接。否则说明会保持可见，让你可以请组织的管理员设置一个可以使用的模型。

问一问在“设置 → 自动化”中使用自己的模型策略列表。在系统范围，有编辑权限的人可以添加、移除已启用的 API 模型或受支持的订阅程序，并可将条目上移、下移。条目保存所选路线、账号模型和配置。在组织范围，列表继承自上层；编辑者只能移除条目以缩小范围，不能添加或调整顺序，并保留上层的顺序。推理强度和其他参数属于模型标签中的个人选择。每一轮仍受组织策略和用量上限约束。

使用订阅时，请选择你和付费方都有权使用的账号。展开模型选项下的订阅详情，可以查看提供方报告的套餐用量窗口。每次调用程序模型都会计入该账号的问答用量。程序可以在一次回复中请求读取多个来源。Orch 会按你当前的权限逐项检查，并在对话中显示来源。已保存的订阅不可用时，选择器会显示原因，你可以自行选择其他模型。

提供方的**使用**条目可以允许 **Ask**、**其他工作**，或两者都允许。只想把提供方分享给别人提问时，打开该条目的选项，在**用途**中仅勾选 **Ask**。同一条目的模型和推理强度限制仍一起生效。其他工作包括普通会话、摘要和服务。提问者与设置指定的付费人都需要允许 Ask 的授权；指定付费人本身不授予访问权限。

未配置列表、列表为空或没有可用条目时（包括模型策略排除了所有条目），面板会说明原因，并隐藏消息输入区。只有当前有权编辑设置的人才能看到前往该设置的链接。其他人会保留原因说明，可请组织管理员配置可用模型。

如果发送、停止或准备草稿失败，**重试**会重复那个操作。重试失败的**发送**会保留它原来的问题和它的请求标识，即使你在这之后编辑了草稿；之后的编辑仍未发送。重试准备草稿绝不会发送问题。

## 阅读回答和来源

回答在到达时逐步增长。阅读更早的消息时，视图不会把你拉回底部。**加载更早的消息**会读取更旧的历史。

- **来源**显示为通常的链接标签。悬停、聚焦或点击其中一个，可以按你现在能读到的方式查看它的来源。**打开**和**在旁边打开**会通向那个来源。引用不给予访问权限。你已经无法阅读的来源不会显示它当前的详情。
- 悬停或聚焦在回答上，会出现**复制回答**和**重试回答**。触屏上也有同样的控件。**重试回答**会在你当前的设置和访问权限之下，从它之前的问题重新提问。如果它的发送结果不确定，再次重试那个回答会保持同一个请求标识和原来的上下文。它被确认之后，有意再按一次**重试**会开始一个新的回答。

## 较长的对话

当对话接近你所选模型的上下文窗口时，问一问会用同一个模型把最旧的消息做成摘要。**更早的消息已摘要**是一条可见的消息，你可以展开它。原文保留在历史里，之后的问题发送这份摘要和最近的消息。已经变化或被撤回的来源，在摘要再次使用之前会被重新检查。

做摘要算作你的问一问用量，通过这段对话的付费方和现在适用的用量限制。它不会为摘要另选一个模型。

对话的上限就是所选模型的上下文窗口，按该模型的实测估算以词元计。回答额度为 `ask.max_output_tokens`（默认 4096）。管理员可以在系统或组织层设置它和可选的 `ask.context_tokens`，取其中最小值。未设置上下文值时，使用模型自身的窗口；设置后可以仅降低 Ask 的窗口，不影响普通会话。Ask 预留配置回答额度与已知窗口一半中的较小值，且至少保留一个回答词元。指令和工具也需要输入空间，因此很小的上下文可能让任何问题都无法放入。没有按消息条数截断的窗口，也没有按字节计的限制。

历史放不下时，会按上文归纳最早的消息。已完成的读取优先于当前页面占用空间。来源无法放入时，会按令牌截短，并以一行说明已被截短及完整来源所在，回答由此继续；打开该链接，或请求更窄的部分，即可读取更多。后续每一步都会重新检查当前来源，并按可用令牌安排，包括首次读取后新增的内容。

未记录窗口的模型不会被当作小窗口：Ask 会原样发送对话。如果提供方回答输入与回答额度合计超出了模型的上下文，Ask 会先降低回答额度再试；如果最小回答额度仍被拒绝，才据此降低窗口并归纳最早的消息。补全模型的上下文容量可避免额外请求。如果连归纳也放不下，Ask 会说明对话超出了所选模型的容量：请新建对话，或选择**保留为会话**。如果问题和它读取的内容本身就已过长，归纳较早的消息也无济于事，Ask 会如实说明：请缩小问题范围，或从更少的来源开始。历史内容不会被悄悄丢弃。

读取工具内部的数字同样是设置，默认值与以往相同：`ask.docs_hits`（每次搜索 5 个指南页面）、`ask.docs_excerpt_tokens`（每页 1,000 令牌）、`ask.max_operations`（每次搜索目录 20 个操作）和 `ask.max_links`（一次读取保留 50 个链接）。每个问题的步骤数和工具数分别是 `ask.max_steps`（16）和 `ask.max_tools`（32）。

Ask 无法受理问题时，消息会用自己的话说明原因：模型或提供方不被允许或尚未就绪、已达用量上限，或无法以你的身份打开该组织。无论“以管理员身份”开关如何，Ask 都以你在组织中的本人身份回答；不是某组织成员的管理员可以查看该组织的对话，但不能在其中提问。

## 每段对话只属于一个组织

**在**标签写出这段对话的根组织，包括它的部门和项目。这个边界永远不变。问一问只阅读你在其中有权阅读的内容。从另一个组织共享进来的资源，只在它被共享的层级上可用，不能访问那个组织里无关的工作。

你可以询问你有权阅读的话题或会话里共享了哪些提供方或智能体配置。回答会显示这项工作共享了什么，以及那个位置对模型和推理强度的限制。在别处管理一个资源并不会扩大这些共享。它的私有所属位置、运行时、用量和无关的工作都不会出现在回答里。

当前页面提供上下文。打开另一个根组织的页面，会开始或恢复那个组织的对话。在不属于任何组织的页面上，例如收件箱或**帮助**，问一问使用栏里选中的组织；没有选中时，使用你的个人组织。要询问另一个根组织里的来源，请在那里打开一个页面，并在那段对话里提问。

**历史**按组织列出你的对话。恢复其中一段会保留它原来的边界。如果它的组织不是当前页面所在的组织，页面就不会被传进这段对话。在恢复的一轮之前，问一问会再次检查之前的工具结果，在页面处于范围内时再次读取页面，并找出现在适用的模型和付费方。即使来源不再可用，你自己过去的回答仍保留在你的历史里。

对话通常保存在你的个人组织里。如果个人组织被关闭，它们保存在根组织里一个不列出的位置。根组织仍然管理访问、检查和保留。如果你失去了对它的访问权限，这些对话对你就会关闭。

## 隐私、费用和保留期限

问一问以你的身份阅读，不做任何更改。它可以搜索、打开你能阅读的来源、阅读它们的历史，并查阅随这个版本附带的用户指南。它不会把你的访问权限借给别人，也不会向正在工作的会话发出指令。

对话所属根组织的管理员可以查看并导出此对话。管理员查看是只读的，不能发送、重新回答、停止或保留别人的对话。先开启原有的管理员身份开关，再打开**历史记录**，选择**查看此组织的对话**，然后打开一行。**导出对话**会将有权读取的对话下载为 JSON。

通常由提问的你付费；生效的“问一问”设置也可以指定使用设置者的提供方权限。面板会显示实际付费方。组织中适用的个人和共享用量上限仍然生效。

默认在**最后一条消息发出 30 天后永久删除**。实际期限会限制在根组织管理员设置的最短和最长期限之间；面板显示生效期限及到期时间。到期后没有第二个恢复窗口。

在到期前选择**保留为会话**，可以在有创建权限的目标话题中建立永久保留的私有会话，也可以使用有权限的默认位置。现有审阅行注明新对话将在哪个组织中搜索并受其治理。复制到另一组织时，新对话从第一轮起使用目标组织的知识、工具、模型选择、策略与计费；源对话的固定根组织保持不变。跨组织复制仍须通过源组织的复制与导出规则。原临时对话会标记为已保留；新会话遵循普通会话的访问与保留规则。之后更换代理时使用普通会话控件。

**导出对话**和**保留为会话**暂不可用时仍可聚焦，悬停或键盘聚焦会显示各自的原因。
尚未创建对话、正在读取、读取失败和操作被拒绝会分别说明。保留需要等待回答完成，
管理员只读查看时也不能保留；这两种状态下，有权导出的人仍可导出。

## 开始永久问答会话

在话题里，打开**新建会话**，或者它的发起方下面的**更改**，然后选择**开始只读提问**。请查看模型的选择和新会话的访问权限：**私有**或**使用此话题的默认访问**。你可以包含第一个问题。这个程序不需要环境，也不需要智能体配置。

永久问答会话使用普通时间线、文件、已保存草稿和**停止**控件。模型选择器显示已保存的偏好。可以为下一条问题选择另一可用模型，或选择**默认**，在下一条问题被接受时重置偏好。每位提问者当前的权限、模型访问权限和用量上限仍然生效。

## 本部署的地址

在这个 Orch 部署所声明的另一个地址上复制的链接，会在你已经在使用的地址上打开。已设置公开地址时，**复制链接**使用公开地址。对块、轮次、消息或文件某一行的选择会一直附在链接上。

管理员在备用 URL 的设置里，除公开地址之外声明浏览器的其他来源。备用的 IP 地址及其端口必须明确声明。路径相同的另一个网站、长得相像的主机，或没有声明的地址，仍然是外部链接。识别一个链接绝不会共享它的目标，也绝不会把你的凭据发送给那个网站。

## 问一问、帮助和旁路会话

**帮助**包含随这个版本附带的书面指南，不使用任何模型。**问一问**用模型根据那份指南和你能阅读的工作来回答。**旁路会话**与工作中的会话的智能体开启一个单独的旁路会话，使用它已验证的只读模式。可以用它询问那个智能体当前工作的问题。见[跟随运行中的会话](running-thread-views.md)。
