# 切换线程的环境或搬迁环境

“移到其他环境…”改变一个线程运行的位置；“移到其他机器…”搬迁受支持的环境；“移到主题…”改变线程在组织中的位置。确认操作名称，再阅读计划，选择你真正需要的变更。

## 在哪里

从线程菜单或环境卡片改变运行位置。从[导航](/)打开线程；如需搬迁环境所在的机器，从[环境](/resources/environments)进入。环境总览也可以规划多个环境的搬迁。[切换多个线程](switch-threads.md)说明批量线程变更。

选择已有环境，或创建新环境。有“更改目录…”时可选择工作目录。新环境可以设为临时，并显示空闲或归档后的生命周期。创建前检查由谁管理，以及能否让线程读者进入该环境。

## 示例

将构建线程从笔记本环境移到更大的环境。选择保留文件、复制到已有环境或创建新环境。逐项检查挂载的保留、分离或复制选择，以及 MCP 服务器会保留、新增可用还是不可用。选择等待当前轮次结束或中断，再确认计划。

## 操作后会怎样

计划说明会关闭哪个会话、旧位置留下什么，以及是否移除旧运行单元。进度和最终时间线会明确列出环境与机器。复制文件不会转移导入 MCP 服务器的机器本地密钥。

由模板创建的环境可以使用它支持的机器搬迁路径。涉及个人机器的移动，会在相应计划中说明是切换并复制。当前权限、机器可用性及沙箱就绪状态仍然适用。应阅读不可用原因和需处理的提示，不能因为目标出现在列表中就认为它已就绪。另见[MCP 导入](mcp-import-and-use.md)和[运行中的线程视图](running-thread-views.md)。
