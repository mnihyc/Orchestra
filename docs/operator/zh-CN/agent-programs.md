# 智能体程序

## 已连接机器上的程序

连接器在连接和机器探测时搜索各适配器声明的程序名，检查 PATH、常用用户及系统程序目录和 npm
全局程序目录。每次版本探测最多等待三秒；无法读取的版本显示为未知。发现程序不代表允许运行。
通过程序注册表登记的外部适配器由独立的监督器管理，其额外程序名暂未纳入此搜索。

机器运维人员可在本机的 `agent.harnesses` 中指定程序。交出该设置后，机器管理员可在**程序**页确认
发现的路径或移除确认。连接器每次只修改一种程序，并拒绝已过期的选择。本机明确保留的值始终优先。
已连接环境使用此策略选定的程序；存在受管工具缓存时，仍以该缓存为准。

Codex 提供方配置中的 `initialize_timeout_secs` 是等待初始化回答的正整数秒数，默认 120；超时仍会终止进程，并保留初始化失败和进程退出的原因。
