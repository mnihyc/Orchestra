# 查找内容

用查找器找名称、设置和命令。用搜索查找文字和相近含义。在线程中查找只搜索当前对话。

## 查找器

按 `Ctrl+K`，Mac 上按 `Command+K`，也可点侧栏的放大镜。
输入名称，查找器会列出你可以打开的组织、项目、文件夹、话题、线程、文档、聊天、人员和资源。
位置或地址帮助区分同名条目。已加星标和最近访问的内容会靠前。

| 前缀 | 查找内容 |
| --- | --- |
| `>` | 当前可用的命令 |
| `@` | 人员的姓名、用户名或地址 |
| `:` | 设置和权限行 |
| `?` | 帮助文章和小节 |
| `/` | 对话、聊天和文档中的文字 |

方向键选择条目，`Enter` 打开，`Ctrl+Enter` 在新的浏览器标签页打开。
不能使用的命令会显示原因。不能查看的内容不会列出。
最后一行的**高级搜索**会带着输入的词打开搜索页。

## 搜索

按 `Ctrl+/`，Mac 上按 `Command+/`，或在查找器中输入 `/`。
搜索查找你可以阅读的智能体对话、聊天和文档。搜索页接受一个字符，中文也一样。
多个词可以出现在任意位置。双引号中的短语必须连续出现。

**最佳匹配**依次优先名称和标题、描述、标题块和文件名、正文，再比较出现次数和更新时间。
**最新在前**按时间排列文字匹配。打开结果会定位到相应的条目、消息或文档块。
人员标签打开人员卡片，内容标签打开相应的内容卡片。
时间旁的文字说明匹配出现的位置，例如**在名称中**或**在聊天消息中**。

### 文字和相近含义

输入稍停后开始搜索文字。组织启用**语义搜索**时，同一次搜索还会查找含义相近的内容。
哪个来源先回答就先显示哪个；另一个来源回答后，服务器发送合并顺序。
没有高亮词的语义结果标为**语义相近**。

来源仍在运行时，标题显示**搜索中…**和当前结果数，已有结果仍可阅读。
**语义搜索暂不可用**表示语义来源未能回答；悬停、聚焦或轻点状态可看原因，文字结果会保留。
**索引已暂停**表示索引正在等提供方，仍在缓存中的查询向量可以继续回答。
新查询需要生成向量时，不能调用已停用的提供方，文字搜索仍可用。
语义请求会等输入停顿，按 `Enter` 可以立即开始。修改查询会取消上一次搜索。
相同查询可以复用该组织、该模型的查询向量，不会每敲一个键就请求一次嵌入。

### 保持阅读位置

刚开始显示的列表会采用服务器的最新顺序。
悬停、聚焦结果或打开它的卡片时，新顺序会等你离开后再应用。
滚动越过第一屏、按下**显示更多**或超过重排时间后，已有行就固定。
之后到达的结果加在下面，只有语义匹配的新结果放在**语义相近**分隔线下。

### 显示更多

第一次**显示更多**展开两个来源已经收到的全部结果，不会发送新搜索。
之后每次会继续同一次搜索并追加结果。模型改变后，文字仍可继续；重新搜索才能使用新的语义索引。
查询和筛选保存在地址中，可以收藏或分享。对方仍只能看到自己可以阅读的内容。

### 筛选和仅搜索文字

用标签选择对话、聊天、文档或包含文件的结果。宽屏时筛选位于左侧；小屏时打开**筛选**使用相同控件。
已选筛选显示在结果上方，可以逐个移除，也可以按**清除**。

可以选择位置、所有者、创建者、最后编辑者或匹配内容的作者。日期可选**创建时间**或**编辑时间**。
文档和对话使用自身时间；聊天使用匹配消息的时间。
旧链接若带日期但没有日期类型，会用匹配内容的**写入时间**。还可筛选文件类型、标题、提到我、与我共享或我参与的内容。
**作者**和**对话内容类型**仍可进一步缩小结果。按文件筛选时，文档结果会显示一个符合条件的现有文件。
部分对话文件没有记录类型；选择**任意**可包含它们。打开结果后，可在对话中找到仅存在于工作区的文件。

搜索会在此设备记住标签、排序、筛选和展开的筛选组，不保存输入的搜索词。地址自带的排序或筛选优先。
保存的位置、聊天或文档已无法搜索时，会改用默认视图。
相同筛选同时用于文字和语义，筛选不会授予权限。
私聊和群聊只会出现在参与者的搜索中，查看管理信息本身不会把聊天加入搜索。

**正则表达式**使用表达式语法，不按普通文字解释；无效表达式会在字段旁显示错误。
引号短语、正则表达式、**仅标题**和**最新在前**只搜索文字，标题会说明原因。
[语义搜索](semantic-search.md)介绍提供方设置、索引状态和模型切换。

## 名称和活动记录

“一切”列出你可以打开的位置、人员、文档和资源。筛选缩小列表，打开行会进入对应内容。
人员的公开页面显示其介绍、置顶内容和你可以阅读的活动。置顶不会授予目的地权限。

位置的审计记录说明谁在何时改了什么，可以按人员、操作、类型或日期筛选、分组。
查看人员页面不会授予审计权限。保留内容在权限允许时以只读方式打开，不会先恢复它。

## 在线程中查找

在线程菜单选择**在对话中查找**。输入后定位并标出匹配。
`Enter` 找更早的匹配，`Shift+Enter` 找更新的匹配。

## 帮助和提示

术语或选项旁的“?”打开简短说明，以及相关文章的小节。
`F1` 打开当前屏幕的帮助，列出提示、文章和快捷键。
不再需要的首次使用提示可以永久关闭；关闭状态会跟随账号。

`/dev/ui` 只在开发构建中提供，展示共享控件及状态，不创建工作或权限。
生产构建不提供该展示页。
