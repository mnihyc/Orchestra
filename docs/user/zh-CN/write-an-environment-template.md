# 编写环境模板

模板描述托管环境的镜像、工具和初始配置。保存模板不会启动机器或环境。模板用于两种工作之一，创建时由你选择。

## 环境

当模板用于会话共享的工作时，选择**环境**。放在这种环境里的会话能看到它的工作区、主目录和进程。

## 提供方

当模板用于托管提供方时，选择**提供方**。提供方的主目录、工具和凭据使用同样的容器配置，它没有环境的工作区。

## 创建第一个模板

1. 打开**资源 → 模板 → 新建模板**。选择**环境**、名称，以及模板所属的组织。
2. 打开**从示例开始**并选择 **Node**。选择器说明它适用于网页项目。它给你 Docker 驱动和一份可以编辑的完整配置：一个 Node 镜像、四个核心和 4 GiB 内存，使用普通的出站连接。选择另一个示例会替换这份配置。对话框只询问少数几个起始选择。
3. 第一个模板请保留**镜像引用**，或者选择另一个有项目所需工具的可信镜像。Orch 会提供它的连接器。选择模板并不会安装项目的软件包。
4. 选择**创建模板**。服务器在保留之前会检查整个示例和你的编辑。起始字段里的问题会显示在字段旁边。新模板会立即打开，一开始只属于你私有。它准备好之后，可以在它的**访问权限**标签页里共享它。
5. 打开**配置**查看其他设置。可以按字段的名称、含义或值搜索，然后选择它所在的部分。**它使用什么**包含限制，**网络**包含关于连接的选择。小项目可以调低限制，较大的构建可以调高。示例中的数字是起始的选择，不是最低要求，也不是驱动的默认值。检查你的编辑之后，选择**保存模板**。

对于安装在主机上的程序，请在**从示例开始**下选择**主机**。它会选中主机驱动，填入 `agent` 账号，并在启动之后运行 `/usr/bin/printf`。在对话框里更改账号，然后在你创建的模板上打开**配置 → 启动后的命令**来编辑它的程序。请选择已经安装在你的主机上的账号和程序。它不使用容器镜像。

已登记的主机可能离线。表单会写出它的名称，并在已知时显示它是什么时候离线的。驱动报告过的最后一份表单和示例，在它的主机离线时仍然可以使用。开始工作之前，请重新连接一台匹配的主机。如果还没有主机报告过表单，请连接一台，这样表单和示例才能加载。这个屏幕上的选择和字段由唯一的**编写环境模板**指南按钮涵盖。

对于带 PostgreSQL 的 Python，示例连接到另外管理的数据库。请把 `db.example.internal` 换成你的服务中可以访问的地址。示例不会创建那个数据库。请通过位置的秘密名称选择它的凭据，不要把它们放进模板的变量里，因为任何人都能读到变量。

## 阅读各节

**镜像**选择一个来源：来自注册表的镜像、在提供构建的主机上构建的 Dockerfile，或上传的镜像归档。标签可以改变；摘要则保持同一个镜像。Dockerfile 使用经典的 Docker 构建器。构建上下文提供来自上传归档或公共 Git 仓库的文件。

内置的**默认**和**开发者工具**模板有可以在**镜像**下编辑的 Dockerfile。它们的配方不需要构建上下文。提供构建的主机在第一次需要时创建你选择的镜像，并为之后的环境保留它，作业会显示它的进度。第一次构建需要网络来访问软件包的来源和配方的下载。**开发者工具**包含**默认**的配方，所以不必先构建**默认**镜像。

**限制**选择容器运行时和安全选项。不设置运行时就使用主机的默认值。镜像中只读的文件，仍然允许写入可写的卷。工具限制控制智能体在容器内的文件访问。额外的能力，包括 KVM，需要主机上合适的设备以及主机的策略或批准。仅有主机标签 `kvm` 不会授予任何设备。

**它使用什么**设置资源的限制，对环境来说还有它的管理者可以把它们提高到的上限。处理器时间以千分之一核计：1000 就是一个核。内存以 MiB 计，磁盘以 GB 计。主机会报告它能强制执行哪些限制。**需要**说明放置时必须有多少空闲。它不预留容量，也不对容器的使用量设置限制。

**网络**选择普通访问或受限的出站连接。受限访问可以到达 Orch 以及位置设置里允许的主机列表上的名称。启动环境之前请先设置这个列表，并选择支持限制的主机。受限访问请把自定义 DNS 留空。**无**网络只通过主机的代理到达 Orch。不被支持的限制会被拒绝。它绝不会被悄悄改成开放。

**智能体的工具**描述提供给在别处运行的智能体的工具，以及哪些智能体程序可以在这里运行。请选择镜像里或主机上真正可用的工具和智能体程序。可以设置什么，还取决于提供方的同意。**用户**选择镜像里的账号，或数字的用户和组 ID。不设置就使用镜像自己的用户。请让可写路径的权限与这个用户匹配。

**变量**是任何人都能读的纯文本。凭据请使用秘密名称的控件。**启动后的命令**列出可以重新运行的、带名称的命令。它们在附加之后、就绪之前，以容器的用户在容器内运行。命令的参数原样使用，默认截止时间是 300 秒，失败会让启动失败。[容器启动后运行命令](commands-after-start.md)说明顺序、继承的命令和主机运维人员单独的钩子。

**存储**设置环境的工作区和主目录的路径以及任何额外的挂载。请使用互不重叠、也不与 Orch 的目录重叠的绝对路径。具名卷保留数据。内存中的临时存储在容器被移除时会丢失。绑定挂载显示该主机上存在的目录。托管提供方保留它的状态卷，没有工作区或主目录路径的字段。它的**已登记的程序**部分描述安装在提供方镜像里的程序。

每个字段都是它自己的参考。共享设置的行会显示它的含义、值和来源。**此模板**表示在这里设置的值。**驱动默认**表示驱动声明的默认值。**镜像、主机或位置**表示模板和驱动把这个选择留给将要运行的容器的配置。每一行的齿轮会显示一次默认值，并对在这里设置的值提供**重置为默认**。重置只移除那个值，并保留同级的值和其他设置。字段的问号会在有帮助的地方补充范围和示例。列表、变量和其他结构化的值在它们的行里展开。如果你只能读取模板，同样的行会在关于你的访问权限的同一份说明之下显示值和来源。对于作为插件的驱动，说明和起始示例随该驱动提供。

## 按需使用 JSON

在**配置**标签页里，打开**详情**，然后切换到 **JSON**，就能在带行号的编辑器里看到同样的配置。

- 属性名称根据驱动的模式补全。把鼠标悬停在键上可以读到它的含义。
- 输入停顿片刻之后，服务器会检查配置，规则与保存时相同。问题会写出它所在的行，选择它就会跳转过去。检查不会保存任何内容。
- 切换回来之前，请先修正 JSON 语法。切换视图会保留这些值，包括驱动允许的额外属性。表单会把它不认识的设置列在**其他设置（JSON）**下面。
- 没有完成的 JSON 草稿会阻止切换视图和保存。请在它所在的行里修正它，或用**放弃更改**回到已保存的模板。

## 为位置选择模板

打开组织、项目或话题的**设置**，选择环境模板。这个选择遵循通常的继承设置，所以文件夹或话题可以选择自己的。创建环境的人必须被允许使用这个模板，并且必须有合适的主机可用。直接创建环境时也会提供模板的选择。托管提供方则在它的容器配置里选择它容器的模板。

对于单个环境，请在模板上选择**添加环境**。对话框里已经选中了这个模板。选择环境所属的位置，如果愿意，也可以为一次性的工作选择**临时**。[临时环境](temporary-environments.md)说明移除之前的通知、**保留**和导出文件。

## 修改已使用的模板

打开模板的**配置**标签页，编辑它的名称、说明或字段。保存会更改以后启动和更新所用的配方。它不会改变已存在的环境的进程或文件。已存在的容器保留为它们记录的配置，直到更新或重新创建经过审阅并应用。应用之前请阅读那个环境或提供方上的方案，如[修改运行中的环境](change-a-running-environment.md)所述。如果有人先保存了，Orch 会再次读取他们的修订，并保留你输入的值供你比较。它绝不会自动覆盖他们的工作。

关闭模板会阻止用它创建新的容器，已存在的容器继续运行。仍有容器使用的模板不能删除。
