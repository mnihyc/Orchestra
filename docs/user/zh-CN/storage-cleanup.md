# 存储清理

## 未使用缓存

打开主机的**设置**，找到**清理未使用的缓存**。系统默认保留七天。
系统管理员未锁定时，主机管理者可以设置其他天数。
**恢复为继承值**会重新采用系统设置。

零显示为**关闭**，表示不再自动清理缓存。聚焦字段后可以编辑数字。
运行单元或保留环境仍需使用的缓存会留下。用途不明时，Orch 会先保留，
直到能够确定哪些工作需要它。

节点连接时以及定期报告存储时会检查缓存。每项移除都需要节点确认。
机器没有应答，不会被算作清理成功。

## 保留的数据

用于恢复的文件遵循各自的恢复期限。修改缓存清理设置不会缩短这些期限。
停止的运行单元仍然占用其卷。
**移除后保留文件**设为零时，之后安排的移除可立即永久清理文件，
不会改变已经承诺的保留期限。

大小显示为 **–** 时，表示尚未测量。主机的**存储**分区会显示保留文件和层，
以及它们当前的恢复状态。

## 未使用发布

系统管理员在系统设置中修改**保留未使用的发布**。
每种载荷默认保留三个未使用的发布，当前和上一个发布始终保留。
零显示为**关闭**，表示全部保留。

清理在更新或回退成功后运行。无法读取设置时，所有发布都会保留。
数据库备份不会自动删除，需要人工移除。

## 卸载

在机器上运行 `orch-node uninstall` 或 `orch-connector uninstall`。
命令先列出移除和保留的项目。输入已注册的主机或机器名称以确认。
`--plan` 只预览。`--yes` 跳过输入名称。

不加 `--purge` 时保留数据和身份。加上后，节点移除此系统的运行时对象和数据。
连接器移除自身数据和它创建的目录，保留已有工作目录。
所选数据目录中有其他实例的数据时，该目录的清理受阻。

共享连接器程序保留到最后一个活动实例移除。在 Windows 上，最后一个实例的程序
在命令退出后删除。安装记录确定可移除的文件。旧安装没有记录时，需要先重新运行一次安装程序。

内置部署运行 `deploy/update.sh uninstall`。加 `--purge` 会在清理节点后移除运行目录和密钥。
默认先将最终数据库、清单、内容副本、配置和节点身份保留在 `deploy/backups/`。
执行卷需要单独备份。`--no-backup` 跳过最终备份。输入系统名称以确认。
配置和 `.env` 保留。

## 存储报告

从账号菜单打开“存储”。可选择自己的存储、一个位置、一台宿主机，或管理员模式下的系统存储。统计、分类和记录使用同一组筛选。点击分类行可缩小范围，“清除筛选”回到完整范围。

每条记录说明保留原因和已知期限。“谁在使用”仅显示你有权查看的依赖名称，其余只显示数量。未知大小显示为破折号。离线或不完整的清单显示为不可用来源，不会被当成空清单。

“位置”显示所属位置，以及保存该项的宿主机或机器。打开名称可查看详情。不可见的位置不显示名称。在窄屏上，这些信息位于项目名称下方。

报告合并宿主机对象、移除环境后保留的文件、挂载保留数据和技能归档。系统存储还显示数据库、内容、上传和导出。分类筛选保存在当前设备和页面地址中，选择框中输入的搜索文字不会被保存。

## 清理保留内容

即使最后一项保留数据已删除，挂载的清理结果仍会保留到你关闭为止。

在资源菜单中选择**清理…**，或在存储中选择记录后点击**清理…**，都会打开同一个计划。

每行显示大小、保留原因和恢复截止时间。打开**谁在使用**可查看依赖项。不可见的名称仅显示数量。受阻的项目仍保留在计划中，并显示原因。

按行选择可用的**保留**、**移除**、**停止并移除**或**立即清除**。停止单元会保留其卷，除非也选择了这些卷。**立即清除**会擦除保留数据，需输入计划名称。环境管理者只有在同时管理环境当前所属位置时，才能缩短恢复期限。

关闭对话框后，作业仍继续运行。**取消剩余项**会等待当前移除得到确认，再停止后续项目。结果逐项显示已移除、已保留、受阻或失败。取消后，已经移除的内容不会恢复。

隐藏清理对话框后，保留环境行仍显示已接受任务的进度。保留数据视图会根据服务器确认的结果刷新。

## 服务器文件

系统存储也列出更新程序保留的发布和转储备份集。大小及保留原因来自受保护的服务器记录。尚未记录或不可用的来源会明确显示。

这些项目的清理行提供可复制的命令，需在服务器上运行。Orch API 不擦除这些文件。`update.sh prune` 预览未使用的发布，`--yes` 按发布保留策略执行移除。当前和上一个发布始终保留。“保留未使用的发布”设为零时保留全部发布。

`update.sh dumps remove <name>` 列出一个转储、清单和已记录的本地内容副本。输入转储名称后确认。配对关系未知或发生变化时会阻止移除。转储不会自动移除。运行命令后请刷新存储页。
