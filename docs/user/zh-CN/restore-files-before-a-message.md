# 将文件恢复到某条消息之前

恢复会把已记录的文件还原到所选请求之前的状态。先检查计划：完整状态可用时恢复“整个目录”，只有编辑记录可用时恢复“代理修改过的文件”。对话仍保留发生过的工作记录。

## 在哪里

从[导航](/)打开线程。悬停、聚焦你的消息，或使用触屏操作行，选择“将文件恢复到此消息之前…”。写入前，计划会说明可用的恢复方式和涉及的路径。单个文件的“评审并撤销文件更改…”仍可使用。

## 示例

代理在一轮中修改配置，下一轮再次编辑，并创建了临时文件。从这些轮次之前的请求开始恢复。修改文件方式会使用配置第一次被修改前保存的内容，并移除有记录的新文件。如果你后来又编辑了配置，计划会标记“此后已更改”；先检查，只有确实要覆盖后来的改动时，才明确选择覆盖。

## 操作后会怎样

修改文件方式沿用同一目录中此线程记录的文件更改，包括后续轮次。代理文件工具以外的命令造成的改动不在此方式的覆盖范围内。关闭记录或索引达到限制时，整个目录状态可能不可用；计划会解释原因，并在有编辑记录时提供替代方式。

恢复作为任务执行，为实际改变的路径记录撤销状态。在操作可用时，用“撤销此次恢复”还原这次恢复。冲突不会被静默覆盖。从[环境](/resources/environments)打开环境的文件与索引状态。评审及行评论见[运行中的线程视图](running-thread-views.md)。
