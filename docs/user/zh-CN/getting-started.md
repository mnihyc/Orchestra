# 开始使用

一位同事先与代理处理一个小修复。另一位打开同一线程，阅读经过，回答代理等待的请求，
并在工作旁的人类聊天中讨论。他们可以按权限继续同一代理对话，话题把线程和结论文档放在一起。

## 选择工作位置

在团队提供的地址登录。邀请加入指定组织；个人邀请只供指定地址使用，链接邀请有独立的
有效期和次数。新安装的第一位管理员使用设置页。安装也可能允许公开注册或外部登录，
登录页只显示已开放的方法。部署保留而未实现的方法不可用。

每人都有自己的空间。个人工作选择自己的组织，团队工作选择左栏中的团队组织。
从这里开始属于选中的位置，是可以阅读和查看历史的普通文档。创建另一个团队组织需要
界面指出的邀请或权限。树可以记住上次位置；项目可包含文件夹，话题位于项目或文件夹中。

## 添加提供方

打开资源 → 提供方，或跟随从这里开始的步骤。提供方是模型及其凭据的来源。
API 提供方可使用预设，或填写地址、协议及自己的密钥。订阅选择适配器提供的登录方法，
按代码、浏览器或导入提示操作。文件导入复制内容；运行时路径指运行时里已经存在的文件。

选择提供方可提供的模型。人看到显示名称，供应商收到路由名称。速度、访问计划和上下文
大小先由提供方管理者开放，线程再从已开放范围中选择自己的值。登录成功、保存密钥或
配置地址只证明设置完成；一轮实际成功才证明整条路径可用。页面会指出缺少什么。

提供方有所有者和所属位置。只向应花费该密钥或套餐的人共享使用权。能看线程的人
未必能在它的提供方上启动轮次；模型使用权和线程访问权分别检查。

## 准备环境

环境保存工作用的文件和工具。可以在有权使用的主机上从模板创建，或连接自己管理的
计算机。选择器显示实际可用状态及模板要求。本机策略优先，即使服务器管理员请求也可被拒绝。

同一环境内的线程共享工作区、主目录、进程、浏览器配置和显示。线程目录只是起点；
文件和终端可到达整个环境。需要不同信任边界的工作应使用不同环境。

## 开始线程

在项目或文件夹中打开或创建话题，选择**新建会话**。用标题说明工作，选择可用的提供方、
代理配置、模型和环境。代理运行方式说明程序、工具和凭据在哪里。初始选择遵循位置
的有效默认值；缺失选项会解释条件。

第一次输入前检查目录和常驻指令。目录指令文件是工作区文件，常驻指令是设置。
信任项目配置另行决定钩子、插件和工具服务器。空指令文件仍可能按程序规则继承上级文件。

先发送一个能辨认结果的小请求。线程从启动进入运行，显示代理文字和步骤，最后保留结果
与用量。阻塞或失败会显示原因，不要把已保存的配置当成工作已经完成。

## 一起工作

按所需级别共享线程。可查看用于阅读；驱动代理和决定审批需要权限页上对应的权利。
共享一个线程不共享整个话题或环境。下一条输入需要同事无权使用的模型时，可按页面
提供的方式申请；暂存消息的处理见[消息队列](message-queue.md#messages-waiting-for-model-or-environment-access)。

用人类聊天与同事交流，用代理输入框给代理工作。只有明确发送或转发，讨论才交给代理，
不会自动成为一轮。把结论放入话题文档，再向需要阅读或编辑的其他线程代理共享该文档。

## 试用脚本示例

提供示例代理和脚本订阅的安装可在不用模型的情况下演示相同控件。脚本适配器产生固定
步骤、问题和结果。命令与 MCP 结果是模拟，用于展示协作和控制，不代表真实修复或模型质量。
源码发行中的指令手册位于 `extensions/agents/fake/README.md`。

## 查找帮助和恢复访问

按 Ctrl+K（macOS 为 Command+K）打开查找器，可输入名称、命令或问题。F1 打开当前屏幕
帮助，选项旁的问号就地说明。搜索和键盘导航见[查找内容](finding-things.md#the-finder)，
协作见[工作与协作](workflows.md)，模型和环境选择见[资源](resources.md)。

登录可能要求验证器或邮件验证码。错误证明受到登录策略限制，已知浏览器另有保护。
无法完成第二步时使用恢复页，或请管理员提供一次性重置链接。模型提供方的登录与
Orch 账号独立，在提供方页面管理。
