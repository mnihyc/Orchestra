# 开始使用

Alice 和智能体一起做一个小的代码修复。Bo 打开同一个会话，看到发生了什么，并回答智能体正在等待的请求。他们在工作旁边的聊天里交流，之后 Bo 在同一个会话里继续与智能体合作。他们的话题把这些会话和记录发现的文档放在一起。本页带你走同样的几步：选择工作位置、添加提供方、准备环境、开始会话，以及与同事一起工作。

## 选择工作位置

1. 在团队给你的地址登录。全新安装的系统由第一位管理员使用设置页面。
2. 如果你有邀请，请打开它。它会让你加入邀请所指的组织。个人邀请只适用于它指定的地址；链接邀请有自己的有效期和可用次数。如果邀请显示的账号不对，先在那里退出登录，再以正确的人登录。退出失败时你仍停留在邀请页面，可以再试一次。如果发出邀请的人已经无法再给出邀请所指的访问权，请向他要一份新的邀请。
3. 选择你工作的位置。每个人都有自己的空间，适合单人工作。要做团队工作，请在左侧栏选择你们团队的组织。

登录页只显示本安装提供的登录方式。它也可以提供开放注册，或通过其他提供方登录。没有提供的方式不可用。

**从这里开始**属于你所选的位置。它是一篇普通文档，可以阅读，也有历史记录。要再创建一个团队组织，需要界面所示的邀请或权限。树会记住你上次工作的位置。项目里可以有文件夹，话题位于项目或文件夹中。

## 添加提供方

提供方是模型及其凭据的来源。

1. 打开**资源 → 提供方**，或按**从这里开始**中的提供方步骤操作。
2. 对于 API 提供方，使用提供的预设，或填写端点及其协议，然后填入你自己的密钥。
3. 对于订阅，请选择为该智能体程序提供的登录方式，并按它的验证码、浏览器或导入步骤操作。导入文件会复制其内容。容器中的文件路径指的是该提供方的容器里已有的文件。
4. 选择该提供方可以提供的模型。模型的显示名称是人们看到的名称，路由名称是发给厂商的名称。提供方的管理者需要先在模型上开放速度、访问程序和上下文大小，会话再从提供的选项中选择自己的值。

登录、保存的密钥或你配置好的端点，只能证明设置已经完成；一个成功完成的轮次才能证明整条路径可用。如果提供方需要处理，它的页面会说明缺少什么。

提供方有所有者和所属位置。只把**使用**权限分享给应该花费这个密钥或套餐的人。队友可以查看一个会话，却不一定能在它的提供方上开始轮次：使用模型和访问会话是两项分开的检查。

## 准备环境

环境保存工作要用的文件和工具。可以在你能使用的主机上用模板创建一个环境，也可以连接你管理的电脑（见[连接一台机器](connect-a-machine.md)）。选择器会显示哪些主机和机器可用，以及所选模板的要求。已连接电脑的本地策略优先，它可以拒绝服务器的请求，包括管理员的请求。

同一个环境中的会话共享它的工作区、主目录、进程、浏览器配置和显示。会话的目录是它的智能体工作的地方。打开**文件**或终端会进入整个环境。需要独立信任边界的工作，请使用单独的环境。

## 开始会话

1. 在你的项目或文件夹里，打开或创建一个话题，选择**新建会话**。
2. 给会话起一个能说明工作的标题。
3. 从可用的选项中选择它的提供方、智能体配置、模型和环境。第一次的选择遵循所在位置的默认值，缺少的选项会说明需要什么。**智能体如何运行**一节说明智能体程序、工具和凭据放在哪里。
4. 当环境列表同时包含两类时，**可使用**把你能使用的环境与**申请访问**下的环境分开。选择后者会检查谁能授予访问，并在可行时提供申请，但不会开始会话。请选择你能使用的环境，或等你申请的访问通过后再开始。
5. 在第一次输入之前，检查目录和常驻指令。目录里的指令文件是工作区的文件，常驻指令是一项设置。信任项目配置是针对钩子、插件和工具服务器的另一项决定。即使指令文件为空，它也可能按智能体程序自己的规则继承上级目录的指令。用作会话目录的路径必须是目录，不能是文件、链接或特殊条目。
6. 发送一个你能认出结果的小请求。

会话从启动变为运行，显示智能体的文字和步骤，并以结果和用量结束这一轮。被阻止或失败的轮次会在屏幕上保留原因。不要把已保存的设置步骤当作最终答案。

## 一起工作

1. 按 Bo 工作所需的级别把会话分享给他。**可以查看**让他阅读。向智能体发送消息和决定它的审批，需要权限页面显示的权限。分享一个会话并不分享它的话题或环境。
2. 如果下一次输入需要 Bo 不能使用的提供方或模型，页面会提供申请访问的常规途径。
3. 用聊天的输入框和 Bo 交流，用会话的输入框对智能体说话。同事只有在有意向它发送或转发时才是在回答智能体。人与人之间的讨论不会悄悄变成智能体的另一个轮次。
4. 把发现记录在话题的文档里。当另一个会话的智能体应该阅读或编辑这些发现时，把该文档分享给它。

## 试用脚本示例

提供**示例智能体**和**脚本订阅**的安装，可以不用模型就运行同样的会话控制。它产生固定的步骤、问题和结果。它的命令和 MCP 结果都是模拟的，所以展示的是协作和控制，而不是真实的代码修复或模型的质量。脚本智能体程序的指令手册在源码发行版的 `extensions/agents/fake/README.md`。

## 查找帮助和恢复访问

- 按 **Ctrl+K**（Mac 上按 **Command+K**）打开查找器。输入名称、命令或问题。**F1** 打开当前屏幕的帮助，选项旁的问号会就地解释它。
- 阅读[查找内容](finding-things.md#the-finder)了解搜索和键盘导航，阅读[工作与协作](workflows.md)了解决策和共享文档，阅读[资源与移动](resources.md)了解提供方和环境的选择。

当所在位置允许时，你的登录可能需要验证器或邮件验证码。如果验证码请求失败，页面会显示错误，并让你再试。请求被接受并不表示验证码一定能发出。多次输错会受到登录策略的限制，已知的浏览器与陌生人的猜测分开保护。如果你无法完成第二步，请使用恢复页面，或向安装的管理员要一次性的重置链接。提供方的登录与你的 Orch 账号是分开的，在该提供方的页面上管理。
