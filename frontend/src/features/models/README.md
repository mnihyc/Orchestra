# What a model can be run with: what its two screens share

A model's entry at its provider says what it may be run with: the efforts it takes, the speeds and access
programs its managers switched on, the largest context they opened, and what a thread starts with of each.
What a thread does run with is its own setting, chosen within that. The first is shown on a provider's Models
tab and the second in a thread's model control, and neither is shown as the other. What the two screens say
the same way lives here: how a context is written and which sizes are offered, and how a pattern in a limit
or an allowlist names a model, a family of models or a group of them.

- `context.ts`: A context in tokens as people write it ("1M", "400K"), the round sizes a thread may be given between a model's own window and its largest, and where a size crosses a step of the model's rate.
- `patterns.ts`: How a pattern names models, and the name of a group: the one rule by which a cap, an allowlist or an entry says which models it covers, read the way the server reads it.
