# 注册自己的程序

Orch 可以使用安装在已连接机器上的智能体程序，也可以运行你自己编写的程序。本页说明如何确认已安装的程序、如何在环境里允许它的某个版本，以及如何注册你自己的智能体适配器或提供方数据源。

## 使用已安装的智能体程序

1. 打开已连接机器的**程序**部分。在那台机器上找到的智能体程序会显示它们的版本和路径。**版本未知**表示程序没有报告可以识别的版本。
2. 选择**使用**来确认找到的程序。它所在的行随后会写着**已确认**，并提供**移除**。

这些操作需要对机器有**管理**权限，以及机器本地管理智能体程序的权限。如果这项权限保留在本机，请使用为那台机器显示的策略命令。**刷新**会再次搜索，并读取机器当前的报告。

移除确认会保留程序文件。它会停止使用该程序的执行器，受影响的会话会在运行之前被再次检查。已发现但未确认的程序不能用于运行。

## 允许环境中程序的版本

在环境的**工具**页面上，当 **Codex 工具**在那里提供工具时，它会显示已确认程序的版本和路径。它的版本通常必须与智能体的版本一致。

环境管理者可以打开**任何智能体版本**。当前批准者的名字显示在开关旁边。这会允许所显示的路径和版本，包括**版本未知**。路径或版本发生变化时需要重新批准。关闭它会恢复版本匹配。这个决定在会话下一次打开程序会话时生效。适配器支持的版本以及环境的其他规则仍然适用。

因版本不同而被阻塞的会话会链接到环境的这个页面。管理者允许当前程序之后，会话会被再次检查，并在能够运行时继续。由模板创建的环境保留它们自己的工具构建。

## 1. 选择机器和程序类型

要注册你自己的适配器或提供方数据源，请继续往下看。

打开已连接机器的**程序**部分，选择**智能体适配器**或**提供方数据源**，然后选择**添加**。程序必须已经存在于那台机器上。你笔记本电脑上的路径并不指向另一台主机上的文件。程序以连接器的账号运行。

- **智能体适配器**包装任何智能体程序，并把会话、输入和结果翻译成 Orch 面向智能体的接口。它必须声明它支持的模式、输入格式和登录方式。
- **提供方数据源**报告模型服务的模型、限制或用量。它不必运行模型。它实现提供方数据源的接口，并声明它提供哪些报告。

## 2. 填写名称和命令

输入注册的名称，以及可执行文件及其参数。包含空格的路径请加引号。命令是直接运行的，不经过 shell，所以管道和 shell 变量不会被展开。

选择**注册并读取详情**。Orch 向程序询问它的声明，在机器允许的地方保存这个注册，并显示程序报告的内容。如果失败，请更正命令后重试。你输入的名称和命令会被保留。

## 3. 使用返回的声明

- 对智能体，打开**添加智能体 → 机器上的程序**，并选择这个适配器来创建配置。
- 对提供方数据源，在添加或编辑提供方时，在**模型、限制和用量**下选择它。
- 两种流程都可以在同一个登记处里内联注册程序。

能力来自它的声明，注册无法给程序一个它不支持的模式。**测试**会再次读取它的声明。它不能证明模型调用或智能体的一轮可以工作，所以请用新的配置或提供方完成一个小的轮次。**移除**会停止并注销 Orch 管理的条目，并保留程序本身的文件。请更改仍在使用它的配置或提供方。

## 4. 注册由本机保留时

本地设置可以让注册由机器的运维人员控制。Orch 会显示这个原因，并对本地已有的注册提供**重新加载**，而不是假装**注册**可以覆盖它。如果你想在这里管理它，请让运维人员交出注册。管理员访问权限不能覆盖机器本地保留的选择。

构建它的细节，请阅读[智能体适配器约定](/help/agent-adapters)或[提供方数据源约定](/help/provider-readme)。

## 选择运行方式

会话设置里的标题**智能体在哪里运行**会从它的问题打开这份指南。选择之前，请阅读智能体及其工具在哪里运行，以及凭据是否会离开提供方。提供的方式来自程序、提供方和环境的声明，不可用的方式会保留它的原因。选择一种运行方式并不给予**使用**，也不改变提供方的限制。按排名第一个可用的选择可能会被建议，你自己的选择仍然属于你。

[设置参考](settings-reference.md)列出 Orch 附带的每项设置和结构化字段。[选项字段参考](option-reference.md)列出 Orch 附带的各个接口的选项。[状态参考](state-reference.md)说明报告的状态，[错误参考](error-reference.md)说明拒绝的含义以及如何恢复。在**帮助 → 设置**里，每项设置的完整条目还会给出它的默认值、一个示例和可以设置它的范围。从控件打开它，可以显示它真实的当前来源。

## 检测到的配置详情

在**添加智能体 → 机器上的程序**里，第一个被确认的程序会填入程序字段。选择**可用的智能体程序**时，目录里只有一个选择就会被填入，有多个时则留给你挑选。**来自机器**、**来自目录**和**你的选择**说明一个值来自哪里。刷新会保留你选择的程序、名称和所属位置。如果程序消失，它的名称会保留，并写着**此程序已不可用**。创建配置之前请选择另一个。更改模式或机器会开始一次新的程序选择。

- **版本**是安装的智能体程序的版本，由那台机器报告，对自定义适配器的声明也一样。它绝不是适配器本身的构建号，也不是根据目录假定的构建。**版本未知**表示没有报告可用的版本，**选择机器以检测**表示还没有对机器的观测。版本是一次观测，不是新的版本固定。
- **账号**列出为该程序在那台机器上登记的订阅提供方，以及每个报告的状态。已有的登录通过连接器通常的发现方式找到。列出的账号并不证明有一次新的登录，也不给予**使用**。**未报告账号**让这个事实保持未知，它并不表示这台机器没有登录。打开账号的卡片可以查看它。
- **程序支持**在有就绪的机器声明时来自该声明，否则来自目录。**机器允许**单独显示机器所报告的运行方式策略。**无**是有意留空的列表，**未报告**表示没有提供列表。
- **运行方式 → 自动 · 来自会话默认值**保留共享的选择器。在会话的设置里，它会考虑真实的提供方、环境、机器和访问权限，把配置好的偏好放在前面，并选取第一个可用且被允许的运行方式。配置的这些详情不会为某项能力选择路线、复制凭据或打开服务。你在那里选择的运行方式仍然是你的选择。
