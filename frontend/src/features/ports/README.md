# Ports

One current environment view for observed listeners, safe opening metadata and deliberate access choices.
The API remains the authority for permission, policy, availability and acknowledgement. The view never creates an opening from selecting a row or refreshing it.

- `pending.ts` — the port types the generated contract does not name: a peer row with its assertion, and a port approval narrowed by its kind.
- `model.ts` — current target, transport, acknowledged address, retained-range and bounded-expiry rules.
- `Ports.tsx` — environment snapshot, explicit waiting/Refresh before discovery arrives, unavailable discovery and policy presentation. The live adapter keeps the native full projection and its domain snapshot together; missing observations never become a successful empty page or replace a complete cached view.
- `Policy.tsx` — deciding places and holders supplied by the server.
- `Exposure.tsx` — safe public opening sign linked only for Ports viewers.
- `View.tsx` — permission-gated workbench entry and the same environment panel.
- `Fault.tsx` — safe refused request with the supplied deciding place and holders.

- `Copy.tsx` — a named Copy act with the actual clipboard outcome.
- `Connections.tsx` — viewer counts and bounded manager-only caller/inside-peer details.
- `Opening.tsx` — audience, carriers, persistent service state and revision-guarded Close.
- `OpenDialog.tsx` — one Let more in review for a named place, bounded link or exact host candidate.
- `PlaceChoice.tsx` — the shared keyboard tree and a served current audience preview.
- `Request.tsx` — the request card and explicit destination of an agent-requested link.
- `HostDeclaration.tsx` — three host fields, unsaved proposal, affected allocation review and acknowledgement.
- `preference.ts` — the chosen environment view, kept without content or credentials.

The same Ports view is mounted on the environment tab and is registered beside an authorized thread. A selected environment view is retained. The Browser owner supplies `PortsBrowser` to use its existing profile chooser; without it the view says why Here is unavailable. `portAddressFor(local, servedPorts, environmentId)` maps only explicit loopback or wildcard addresses: HTTP(S) preserves path/query/fragment at the served name; bare/TCP/UDP and no-domain addresses open the environment target. Message and terminal owners keep the original bytes and use this single function.

The host form keeps its proposal out of force until Save and displays unreported acknowledgement honestly; editing an existing declaration waits for actual affected-allocation facts. The request card is mounted in the ordinary approval list and thread timeline. Each administered place has one outside-opening list, including stopped admissions, with current guarded Close and the ordinary explicit bypass.
Request cards keep their reviewed destination and decisions, with guides in the page's shared help home.
A settled standalone request uses the quiet frame instead of continuing to look like a pending warning.

- `presentation.ts` — Compact display values separate from the served contracts.
- `wire.ts` — Wire adapters with honest unknowns and no inferred admission.
- `Program.tsx` — Shared program choices and their revision-guarded repair without an audience change.
- `Entries.tsx` — All ready entry methods and mounted direct once-link replies.
- `Outside.tsx` — The current administrator list of wider admissions and ordinary guarded Close/bypass.
- `Grants.tsx` — Each audience's port capability with its grant, template default or policy, and Grant and Take back.
- `LocalAddresses.tsx` — A local address in a conversation leads a Ports reader to the environment's port.
